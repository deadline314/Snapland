# 原創聲音

本輪音樂及音效由本專案的作曲腳本產生，沒有採樣商業遊戲聲音。主 session 於 2026-10-11 重新產生並檢查 PCM 峰值、長度與資源載入。三首音樂是 88 BPM、16 小節的循環，包含 pluck、柔和和弦與節奏聲部；harbor／plaza／game 對應碼頭、廣場及遊戲。

產生方式：`python game/audio/generate_audio.py`。程式碼與輸出隨 Snapland 專案維護；引用來源圖僅存在 pm／design 的研究資料中，不是音樂採樣。

自動測試能證明切換、音量、循環與暫停狀態；無法取代實際喇叭／耳機的聽感驗收。MIC-1 保留試聽條件未勾選。
