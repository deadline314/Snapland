# 原創潮汐紙劇場素材

`backdrops/tidal-atlas-v3.png` 以使用者指定的原創四格背景及 Snapland 角色配色作編輯參考，由內建圖片生成工具製作，沒有第三方作品圖片作生成輸入。四個象限為海港、溫室廣場、夕陽舞台、月夜碼頭，改用清楚的像素輪廓與有主次的材質色塊。遊戲等比例取景覆蓋操作區，避免橫向拉伸摩天輪、窗框和船帆；中央保留物件與操作提示的可讀性。原圖、修正版及原生畫面比較見 ART-19，提示詞與雜湊見 art-provenance.json。

背景是烘焙光影的靜態圖，四時段套用現有環境配色；不是會隨光源重新計算投影的 3D 場景。主區域的即時日夜光影另由世界場景處理。

美術方向與來源研究見 `design/runtime/visual-polish.md`。第三方參考圖只存於 pm，不匯入遊戲。

`props/tidal-props-v2.png` 為使用者肯定的原創透明圖集；`props/regions.json` 記錄實際 alpha 輪廓範圍，避免等格裁切截斷腳與配件。執行時取圖集區域，不預先裁切或重新繪製生成圖片。包括氣球、郵箱、風箏、海膽、帽子、主角、小角、燈、四位遊客、花喇叭、相機、招牌與長椅。

主角是短深髮、青綠外套、奶油短褲、靴與斜背相機；小角為珊瑚色、奶油小角、青綠圍巾與箭頭尾。遊園像素角色與遊戲插畫以相同身份細節相連。資源來源與 SHA256 見 `art-provenance.json`。
