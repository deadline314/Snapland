# Snapland

以單人遊園為中心的HD-2D拍貼收藏遊戲，預留1–4人同機與P2P。目前可玩 Godot 4.7.2 的上島、迎賓大道十二款及潮汐碼頭「浪間小艇」「潮汐沙路」「燈塔折光」「繩結拖船」「蟹洞彈珠」「船艙配重」「浮標接力」「帆影追逐」「貝殼聽潮」，共二十一款獨立玩法。

## 遊玩

2026-11-13 已輸出包含十三款玩法、參與收藏與免費補拍的 Windows 預覽成品，完成三步補拍的實際鍵鼠、原圖與關閉重開、兩區獨立資源包取卡／讀檔，以及新遊戲／碼頭啟動與原十二款圖資載入檢查；執行檔不隨 repo 提交，結果與來源指紋附 [SG-29](pm/Snapland-small-game/[SG-29]提供免費補拍與參與收藏.md)。「浪間小艇」的實際物理與完整回合驗收見 [SG-28](pm/Snapland-small-game/[SG-28]實作浪間小艇與碼頭收藏.md)。這是程式化操作與資源驗證，角色動作與真人試聽仍依各票驗收。開發環境安裝官方 Godot 4.7.2 後執行 `launch-game.cmd`，或用 Godot 匯入 `project.godot`。WASD／方向鍵移動，E／Space 互動，Esc 返回；滑鼠與鍵盤可操作選單。開場可跳過與重播；收集六張不同普通拍貼後，可從迎賓大道前往潮汐碼頭。潮汐鐘可直接預覽漲退潮，兩端渡船與返回迎賓都免費，重開保留所在園區。

迎賓大道包含十二款獨立小遊戲、十八個普通收藏來源、十二小惡魔收藏、遊戲內成就、任務、設定與存檔。潮汐碼頭可探索燈塔岸線、沙洲與環岸步道，並從遊戲亭或地圖進入「浪間小艇」：W／上划槳、S／下反槳、A／D 轉舵、Q／E 側滑、空白鍵拿箱與交貨。自然結算可取得當地普通卡，浪峰側滑靠岸且不撞箱可取得小惡魔卡；輔助保留資格，練習與取消不取卡。「潮汐沙路」以 WASD 走、Shift 跑，在沙丘與礁石中央按空白鍵插路標；看水位刻度趁退潮連接三礁並回營，第一輪潮內先留高地回路再連三礁可取得小惡魔卡（輔助可按 T 暫停水位）。[SG-30](pm/Snapland-small-game/[SG-30]實作潮汐沙路與碼頭收藏.md) 記錄驗收。「燈塔折光」用 A／D 選鏡、Q／E 轉 45 度、空白鍵開合遮光板、Enter 點燈結算，同時照亮三座航標；只分束一次並照到隱藏側標可取得小惡魔卡，驗收見 [SG-31](pm/Snapland-small-game/[SG-31]實作燈塔折光與碼頭收藏.md)。「繩結拖船」以 W／S／A／D 駕駛、Q／E 收放拖繩、空白鍵掛鉤，把浮台拖過三道狹灣；從側灣通過且不斷繩可取得小惡魔卡，驗收見 [SG-32](pm/Snapland-small-game/[SG-32]實作繩結拖船與碼頭收藏.md)。「蟹洞彈珠」以 A／D 瞄準、按住空白蓄力放開彈出，三顆彈珠撞開三扇蟹門；一顆彈珠反彈後同時撞開兩扇門可取得小惡魔卡，驗收見 [SG-33](pm/Snapland-small-game/[SG-33]實作蟹洞彈珠與碼頭收藏.md)。「船艙配重」以方向鍵移動吊鉤、空白吊放、F 指定繫帶、Enter 出航，讓貨船在側浪中保持平衡並依序在兩港卸貨；四道浪都安全且在航行中移重抗浪可取得小惡魔卡，驗收見 [SG-34](pm/Snapland-small-game/[SG-34]實作船艙配重與碼頭收藏.md)。「浮標接力」只用空白鍵：按住蓄力投浮環、按住拉繩、再蓄力把郵筒拋給中繼浮標或直接上岸；一個浮環同時套住兩個郵筒可取得小惡魔卡，驗收見 [SG-35](pm/Snapland-small-game/[SG-35]實作浮標接力與碼頭收藏.md)。「帆影追逐」以 A／D 轉舵、Q／E 收放帆角，依浮標旗預告的風向追上繞圈燈船三次；順風換舷後六秒內追上可取得小惡魔卡，驗收見 [SG-36](pm/Snapland-small-game/[SG-36]實作帆影追逐與碼頭收藏.md)。「貝殼聽潮」先聽潮聲示範，再用 1–4 或 A／S／D／F 照波紋敲四個貝殼（長音按住、靜默拍不敲），W 可等長浪放慢；三段都完成且靜默都沒誤觸可取得小惡魔卡，驗收見 [SG-37](pm/Snapland-small-game/[SG-37]實作貝殼聽潮與碼頭收藏.md)。其他碼頭玩法、故事與其餘八區依 [完整遊戲接續交付](design/runtime/full-game-delivery.md) 逐項製作。新遊戲從晚風號序章開始，可略過及重播；舊存檔不強迫重播。完整結局、異空間與多人接續擴充。Steam adapter 保留接口，目前沒有連線到正式 Steam 成就。

已開放玩法正常結算即可收藏普通拍貼，成績與勝負如實顯示；練習及中途取消不自動發卡。實際嘗試一次後，可從遊戲亭或相簿免費補拍普通／小惡魔卡：依序觀察示範、調整布景、按下快門。補拍會保存這次安排的布景與取得來源，並與真正達成挑戰分開記錄；重拍不重複發錢，也不覆蓋已收藏的原圖。

## 遊戲驗證

`python tools/run_game_tests.py` 執行真實 Godot 的乾淨匯入、啟動及受影響 runtime 測試，缺少引擎或腳本錯誤會失敗。測試使用獨立暫存 profile，不覆寫玩家進度。

完整 CI 使用四個必要遊戲批次，共用素材來源只檢查一次；本機預設仍跑全部。可用 `--shard-index 0 --shard-count 4` 執行其中一批（索引 0–3）；與 `--only` 不可混用，單批結果只代表該批。分批覆蓋與實測耗時見 [驗證分批](design/runtime/runtime-ci-shards.md)。

原生 GPU 截圖：`godot --path . -- --capture`。驗收時另設 `SNAPLAND_SAVE_PATH` 到測試檔案；截圖模式自動退出。設計研究、來源與驗收限制見 [本輪設計](design/runtime/DESIGN.md) 及 [票券入口](pm/README.md)。

十二款原生自動操作驗收：指定獨立 `SNAPLAND_SAVE_PATH` 後執行 `godot --path . res://game/tests/native_review.tscn`，需要 GPU。它輸入鍵鼠事件並保存結算畫面，屬程式化驗收，不能代表真人的樂趣或音樂聽感評價。

本版原創圖形與聲音沒有使用研究頁的商業遊戲資產。引擎授權見 [Godot license](https://godotengine.org/license)；字型與第三方授權隨預覽包提供。

閱讀 [設計入口](design/README.md)、[需求票](pm/README.md) 與 [工作規範](AGENTS.md)。
