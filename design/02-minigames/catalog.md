# 小遊戲設計目錄（128 個候選）

更新：2026-10-20。以下是**可評估的設計規格**；不是 128 款已實作或好玩的驗收。001–012 有現行單人程式，其他 116 款只在設計。多人、AI 與異空間欄均是目標規格，除非各實作票另有證據。

[機器可讀完整規格](catalog.json) · [來源與修訂決策](revision-notes.md) · [六款原型順序](prototype-order.md)

每款小惡魔必須延伸該款主要操作。異空間不計基本款數。普通／輔助、AI、P2P 與同機的實作另驗；同機不用私密畫面或強制語音。

### game-001 氣球快遞

**掌握** · 斜俯港灣3D · 保留 · 首區單人待整票驗收

| 項目 | 規格 |
|---|---|
| 操作 | 方向鍵／WASD 或滑鼠推動氣球；空白鍵／右鍵煞車。進入亮圈煞停半秒即可投遞。 |
| 普通目標 | 限時內依序送達三封郵袋 |
| 取捨 | 搶順風或提早煞車 |
| 可見回饋 | 投遞圈停留進度與碰撞原因 |
| 重玩變化 | 郵站位置和風道組合 |
| 單人 | 玩家獨立完成主要操作；簡單AI沿安全風道緩行。可暫停、重試及隨時離場。 |
| 多人 | 各自載信，可互相擋風 |
| 簡單 AI | 簡單AI沿安全風道緩行 |
| 小惡魔 | 未開輔助，零失誤送完三站（不撞海膽、不過快進站） |
| 輔助與惡魔 | 依現行單人規則；明文排除輔助者仍按當前條件判定，不把未實作的同等惡魔取得方式說成已完成。 |
| 異空間 | 倒影郵站須借噴泉落腳 |
| 輔助 | 降低風力、擴大停留圈 |
| 原型檢查 | 比較直衝與提早煞停的失誤原因 |
| 修訂理由 | 保留現行推動氣球並煞停，以「搶順風或提早煞車」維持決策差異；多人與異空間仍是規劃。 |

### game-005 帽子救援

| 項目 | 規格 |
|---|---|

| 重玩變化 | 共同陣風對不同帽形的漂移差異與成對來帽 |
| 單人 | 玩家獨立完成主要操作；簡單AI補接遠離玩家的帽子。可暫停、重試及隨時離場。 |
| 多人 | 各守半場，可投回漏帽 |
| 簡單 AI | 簡單AI補接遠離玩家的帽子 |
| 小惡魔 | 六頂全部中心接住、零漏接且未開輔助 |
| 輔助與惡魔 | 依現行單人規則；明文排除輔助者仍按當前條件判定，不把未實作的同等惡魔取得方式說成已完成。 |
| 異空間 | 帽子先經倒影才回實體接線 |
| 輔助 | 加寬手窗、慢化風漂 |
| 原型檢查 | 證明走位與伸手缺一不可 |
| 修訂理由 | 保留左右走位並短按伸手；2026-10-23 加入成對陣風與帽形受風差異，讓「先救哪頂、是否連救」成為實際取捨；多人與異空間仍是規劃。 |
