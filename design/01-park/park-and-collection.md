# Snapland 園區、收藏與多人規格

更新：2026-10-06。需求票：MAIN-1。本文件與 park.json 是設計基線，數值仍需原型試玩。Godot 遊戲尚未實作。

## 遊園循環
看見設施或環境線索 → 免費排練/直接遊玩 → 發生可讀的選擇與短篇笑料 → 結算挑照片 → 自由選下一個目的地。
失敗不扣入場費、貨幣或收藏；可立即重試、開輔助或離開。結算動畫可略過，不必重新跑到入口。每款基本場次約45–90秒，解謎款目標2–3分鐘；時長是待驗證目標。

中央廣場有導覽、補拍服務、拍貼本、借用道具、服裝店、日夜切換鐘與快速移動站。地圖顯示設施/探索/任務圖示及已收集狀態，缺卡頁提供位置和替代路線。各區日常通路有固定安全繞路；互動捷徑可失敗但不封出口。

## 固定收藏与解鎖
每區普通收藏18：12設施、3探索、1主線、2支線。十區180。實際拍貼可每次不同，但同一來源的收藏資格只計一次；不要用照片檔案數或隨機框數開區。

| 已取得不同普通收藏 | 永久開放 |
|---|---|
| 0 | 迎賓大道 |
| 6 | 潮汐碼頭、糖果工廠、霓虹夜市 |
| 30 | 鏡之馬戲團、發條玩具城、苔光溫室 |
| 60 | 幽幽旅館、雲端遊樂場、星光影城 |
| 180 | 地底惡魔劇場8款新遊戲 |

收藏不消耗。門檻可由目前開放內容達成：迎賓18≥6；前四區72≥30；前七區126≥60；十區180可全集。迎賓的3探索+1主線+2支線可提供6張，第一組新區不要求任一設施通關。全部普通設施卡都有輔助/補拍途徑，因此即使不精通動作也可開全部園區。

普通結局要求訪問十區、各区主線拍貼與總普通收藏至少60；沒有180全集要求。終區180包含十區全部18來源，既不包含120張惡魔拍貼，也不包含終區自己的8張。普通結局之後所有探索與支線仍可重播與收集。

## 不鎖死的取得途徑
- 正常完成設施個人目標取得普通卡，競賽輸給朋友也可達標。合作成功時每位有參與的真人各領一份。
- 免費排練、減速、路線/節拍預告、較寬判定、檢查點、角色切換與AI支援可從第一次遊玩選擇；不必先失敗多次。
- 普通卡可做該設施的短補拍委託：用同款道具安排布景、嘗試核心操作、在定點取景。不是看AI全自動代打；玩家仍有選擇與操作。
- 小惡魔條件揭露相同操作的另一用途。模糊提示可直接展開到明確步驟，減速/預覽保持條件本身；仍有障礙時開該條件的分段排練補拍。難度不設獨占卡片或外觀。
- 收藏資格相同，成績不同：輔助/補拍不冒充標準成績，也不提升挑戰評級。評級與徽章只記錄表現，不增加契約力量、不鎖故事或裝飾。
- 任務道具免費借用、可歸還與補領；必要服裝可借，裝飾服裝無能力差距。購物不花掉開區資格。
- 固定掉落、無限重接、日夜自行切換、無現實時間等待、無永久失敗分支。

## 小惡魔與異空間
每區12張小惡魔收藏全齊，只開自己區的異空間。門口永遠能退出。沿用12款原遊戲，每款變體必須説明改變的取捨或互動，不能只增加速度和工作量。可單選任一已開設施，不強迫連打十二場。

異空間貨幣每分鐘目標普通區1.25–1.5倍，原型後再校準；重複普通遊戲、探索委託也能穩定買齊所有用品。每件衣服、框、特效皆有確定購買/兌換路線；稀有候選只是取得順序與驚喜，沒有難度独占。初次獎勵與每輪獎勵分開，支線唯一拍貼不重複計數。

## 拍貼與排行榜
設施回報驚險、失誤、救場、通關等事件及主體；環形暫存有限候選，在结算排出四格。不要每幀保存完整圖片，四分屏與P2P各自只保存需要的紀念內容。玩家能挑選、重排、另選已解鎖框與特效；輸出時記錄當下外觀快照，之後換裝不改舊圖。
排行榜展示拍貼先取得本人同意；可取消公開、點擊放大、匯出或以平台分享流程分享，不自動發送。公共榜圖來自本人允許的該設施拍貼集合，不從全部私有相簿隨機抽。比分附規則版本、模式、座位數、AI配置與輔助狀態；比較相同標準配置，異空間與輔助不混入標準榜。初期公共榜不宣稱防作弊，個人榜離線可用。

## 單人與多人合同
所有設施有1–4個座位；座位與裝置/網路peer不同，同一裝置可持有多個座位。輸入、相機、介面只綁座位，遊戲模擬與全球唯一玩家分開。真人、AI、遠端均產生同類操作指令；AI不能直接改分數或藏入玩家未公開資料。

合作簡單AI能基本分工、跟隨圖示指令與讓路，不故意讓隊伍卡關。中等增加預測，困難增加取捨與配合，惡魔提高規劃與反應但不作弊；四級皆不改收藏門檻。單人可暫停排演及切換職務；有必要的同時操作改為可排程指令或AI穩定維持。2、3、4人按座位分工，沒有「只有4真人才可拿卡」。

同機共用模擬、不同視角。謎題資訊預設公開，記憶题同步揭示/遮蔽，單純遮不同分屏不能作保密機制。節奏輸入按本機時間校準與判定，再同步事件；不能把網路延遲直接作失誤。混合兩台各兩人的拓樸列入架構與後續局部測試。

P2P由房主運行局內狀態與結算，其他端送操作；種子化亂數、事件序號和結果識別碼避免重複領取。不是所有小遊戲都強制跨機完全確定性，也不以可重播宣稱安全。非房主離線可AI接手，標準榜若配置變更就轉休閒；房主離線先保存已確認紀錄、回最近安全點，本輪可重試，不先實作複雜房主遷移。

每位玩家保存收藏、任務和外觀；房主保存當次世界状态。隊友有未開區時可跟房主參觀/遊玩並保留取得資格，回自己存檔仍以自己的數量解鎖，不因隊友離線失去已有物品。终區首次入場各玩家仍需自己180普通；未達者能在自己的園區補拍，不強迫整隊等候，已齊者可先玩。本機訪客用獨立訪客檔可匯入，不把四人進度都寫到房主帳號。晚加入看到事件前因的短重播，參與後結算才領獎。

## Steam 物品與離線存檔
itemdefs.json只使用Steam標準定義欄位與允許的snapland_*擴充欄位。ID為固定、低於一百萬整數；type為item。308拍貼定義=180普通+120惡魔+8終區；另10框、10特效、10服裝和1貨幣樣本。樣本不是完整美術商品庫。
Steam相容格式不表示物品已發放到Steam。離線實例使用本機識別，不冒充Steam item instance ID。所有目前定義marketable/tradable皆false；不放privileged API key在客戶端。任務授予離線收藏；未來可交易掉落使用Steam受控機制或可信任驗證，P2P房主不是可信任經濟伺服器。
個人拍貼像素檔與來源metadata另存，引用框與特效itemdefid；固定收藏资格保留於存檔，賣出/消耗物品不能移除已開區。拍貼與裝飾不綁定，沒有「好瞬間只能配醜框」的永久損失。随机框候選附確定兌換保底；實際市集開通、可交易照片分類與濫用控制另開需求票。

## 驗證邊界
本輪驗證資料数量、固定ID、開區可達及文件一致性；沒有Godot執行畫面、效能數據或玩家試玩。設計截圖是文件預覽。六款原型試玩後再調整門檻、回饋、AI與節奏判定。
