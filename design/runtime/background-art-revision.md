# 小遊戲四格背景：HD-2D 重修方向

使用者於 2026-10-12 提供四格背景並指出「太 AI」，要求修正。本次依既有高細節像素與原創海港風格處理，不把研究本身當作已改圖或通過遊戲畫面驗收。

## 保留的畫面身份與場景

沿用《視覺完善》基準：海港老遊樂園、墨藍印刷輪廓、海青綠／珊瑚／奶油／赭金色、木銅與石材，像素旅人仍用已核可的獨特輪廓。不要引用別款遊戲或單一畫師作樣板。修訂目標是像有人逐物設計的高解析像素場景：保留建築接縫、木板、窗框、欄杆、屋簷、石縫等有功能的細節；把它們整理成形狀清楚、邊緣受控的像素群。砍掉平均散佈的紙噪點、到處同密度的小花與亮點，以及沒有材料或結構理由的筆觸。細節密度依視覺重要性分層，不把整張圖一律簡化成平色海報。

四格分別要讀成：

1. **港灣碼頭**：明確海平線與水平木棧板；碼頭由連續木面、樁柱、橫撐和牢靠的欄杆構成，繩結、繫船環與燈塔只作尺度線索。船與岸線落在同一透視系統。
2. **溫室廣場（日景）**：溫室玻璃分格由結實、連續的窗框支撐，立柱落地且頂棚受力可讀；廣場石鋪面有一致消失方向。植物以數個分明葉簇和少量輪廓高光構成，葉片間保留空隙，不將整面牆填滿花葉。
3. **帷幕舞台（夕照）**：幕布分成少量有重量的垂直褶片，舞台地板、側柱、橫樑及燈架彼此接合；暖光從指定舞台燈具落向同一側，不能每個物件各自發光。
4. **拱廊碼頭（月夜）**：沿用拱形石橋／碼頭的識別輪廓；每道拱有連續拱圈、橋面和落地橋墩，反射水線維持水平。月光方向明確，燈籠的局部暖光只影響鄰近石面。

共通構圖：四格各自維持既有 2×2 格位，正面大形、場景地平線、建築垂直線和光源方向前後一致。近、中、遠三層要靠遮擋、重疊比例、值階與少量景深分開，不靠全幅模糊或柔焦濾鏡。每格中央至下半仍留出遊戲安全平面；移動角色、目標和提示需要可辨。裝飾集中到左右邊緣或上方，不遮住操作區，也不讓橫向屋簷／欄杆突然中斷。遊戲覆蓋層、命中目標和文字的高對比以程式繪製為準，背景不能預畫相似 UI。

## 修圖、提示與驗收

先以原始四格參考和既有調色板鎖定身份；保持各格主體與象限，逐格處理結構，再調光向、材質，最後補少量特色細節。提示把「保留什麼」與「這一輪只修什麼」分開寫。禁止以「painterly」、「storybook」等風格詞作為主指令，也不以 blanket paper grain、柔焦、全幅漸層光暈或無方向筆刷代替像素群。

覆核每格的像素縮放檢視與實際遊戲縮放：一，第一眼能分辨指定場景與主建築；二，支柱、欄杆、窗框、拱圈和橋墩確實接合；三，地平線／透視線和光源方向一致；四，木、石、玻璃、布、葉各自可讀但細節量有主次；五，安全平面和遊戲物件高對比保持清楚；六，四格仍共用 Snapland 墨線、海港色調與高解析 HD-2D 層次。這些是出圖審查項，不是本研究或提示詞已通過的結果。

## 檔案與 runtime 影響面

- 圖集：`assets/minigames/backdrops/tidal-atlas-v3.png`，由 `assets/minigames/art-provenance.json` 登記；原提示只記錄 2×2 象限與泛稱 harbor / coastal garden / boardwalk stage / moonlit photo courtyard。使用者指定的碼頭、溫室廣場、帷幕夕照、拱廊夜碼頭是本次細化方向。
- 使用端：`game/minigames/session.gd::_draw_backdrop()` 載入圖集並將四格以 `AtlasTexture` 切成 `harbor`、`garden`、`stage`、`night`，實際繪在 1280×720 畫布內的 `(29,122,1222,492)`。各遊戲模式透過 `mode` 選象限，之後另繪紙邊、場景裝飾及時間洗色；角色、目標和文字後續繪製。修圖時保留原 2×2 座標分割和象限主題，勿把新細節放在會與上述程式層爭讀的位置。
- `game/tests/native_review.gd` 與 `game/minigames/session.gd::art_cache_status()` 可核對四格資源載入狀態；載入檢查不是畫面品質證據。實際構圖必須由主 session 以 GPU 執行截圖審閱。

不下載外部參考圖作資產。這次研究只產生可供主 session 修圖的文字準則；沒有查看、修改或聲稱驗收目前圖集的像素內容。
