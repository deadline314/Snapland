- 原生Godot 4.7.2／Intel Arc B580：800×450文字1.25、1280×720文字1.0、1920×1080文字1.25，每種33張畫面。Root逐頁看過聯絡表，另全尺寸查看文字與版面疑點。真實輸入事件覆蓋滑鼠懸停／按下、Tab、Esc、下拉選項、設定分類及返回。
- 39張教學候選圖由實際遊戲場景與新版介面擷取，Root看過全部聯絡表後才替換原教學資產。腳本設定的結算示例明確屬教學示意，不是通關證據。

## 退件與修正

放大文字後的設定按鍵曾因中文實際行高不足整行不畫；現以實際可見行數檢查18項文字。換裝快速切頁、一次只有一頁的衣櫃、主選單被小遊戲蓋住、Esc被小遊戲攔截、照片原圖的關閉鍵超界，都有對應回歸驗證。原生驗收程式曾太快結束音效；現沿用遊戲既有0.15秒音訊停止等待，再釋放場景，沒有忽略引擎ERROR。

既有照片原圖測試在headless下原本只有64像素視窗，無法代表它要求的實際照片尺寸；只在建立介面前明確設定1280×720並等待一個影格。原有全部斷言、通過標記及選擇器保留。新增收藏測試改用真正Main標題／內容／操作列，並遍歷18普通、12小惡魔、4時段的全部頁面。

空收藏的卡片與翻頁列重疊由Root全尺寸檢視發現；已加入卡片完整邊界和導航不得相交的CPU與GPU驗收。該項最終結果以票內最新截圖與報告為準，先前被退件的私人log不列為通過證據。

放大檢視又發現卡片文字雖在按鈕矩形內，仍會被凸起邊框遮住。卡片因此加入實際內距，照片集在大畫面使用更多空間；驗收要求文字留在邊框內側的安全區，完整字形行高可見，不能只以按鈕外框判定通過。兩張退件原生圖保留在ART-24，供後續對照。

## 範圍與限制

本輪交付是現有遊戲UI／UX改版，包含分類、完整展開、分頁、固定操作列與偽3D像素高光／側面／投影；超長下拉選單超過視窗容量時仍允許必要捲動。中文保留完整可讀字庫，沒有為像素感犧牲缺字與可讀性。

原生畫面與輸入事件驗證不等同人類試玩、玩家偏好、試聽、實體手把、多人完整體驗或即時效能。既有ART-17完整角色動畫／外觀覆蓋仍未全過；本輪只接受路線及待機回歸與22張靜態完整性證據。該未完成內容與整個執行專案同在feature分支，故不將整枝推main；UI票保留「進行中」並列出已通過的本機条件，直到能與完整執行專案一起交付。
