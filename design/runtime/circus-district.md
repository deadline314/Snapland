# 鏡之馬戲團園區配置

2026-11-27，ART-51。這份文件記錄整建後的園區配置與之後加入小遊戲時要遵守的擺放規則。畫面依原生截圖檢查，不是遊戲試玩結果。

## 主題

林間空地上的巡迴馬戲團營地：一頂朝鏡頭剖開的紅白大帳篷、一條哈哈鏡走廊、一座影子戲台，外圍是篷車、小帳篷、帆布圍籬與樹林。地面是草地與踩實的泥土，外緣沒有圍牆，之後可以直接接上相鄰園區。

## 五塊可走範圍（位置與大小沒有改動）

| 範圍 | 現在是什麼 |
|---|---|
| 馬戲團入口 | 入口廣場。南側是掛著跑馬燈招牌的大拱門，旁邊有售票亭與蒸汽風琴；小角在這裡迎賓 |
| 觀眾席 | 中央走道兩側的長椅，紅白地毯一路通到表演圈 |
| 砲彈安全墊 | 大帳篷內場：木屑表演圈與中央的安全墊、四根主柱、空中鞦韆與吊環、後方看台上的布偶觀眾、人體大砲 |
| 鏡廊 | 西牆一整排斜放的哈哈鏡與兩面立鏡 |
| 影子台 | 影子戲台；戲台後方是用紅絨繩圍起來的後台，不能走進去 |

## 鏡頭與遮擋

鏡頭從南方斜上往北看，高的東西會擋住它北邊約一點五倍高度的地面。因此：

- 高的設施放在可走範圍的北邊或外側（大帳篷、篷車、小帳篷、帆布圍籬、樹林）。
- 一定要放在玩家前方的（入口拱門、兩台小遊戲機台），玩家走到後面時會自動開一個透視圈。
- 影子戲台的布幕無法透視，所以它背後的區域改成後台並圍起來。

## 小遊戲空位

已交付兩款：入口西側的哈哈鏡大頭貼、鏡廊西端的誰是假倒影。另外預留十個空位，地上各有一塊星形地墊與一支小旗：

- 大帳篷內場北緣四個（表演圈兩側各兩個）。
- 鏡廊北端一個、影子台東北角一個。
- 鏡廊南段一個、影子台前方南段兩個。
- 入口東側一個，與哈哈鏡大頭貼對稱。

每個空位是機台或攤位的位置，互動點在它南邊一點六五公尺。這十個位置的後方不是不可走的地面，就是只會遮到和既有兩台機台差不多的範圍。之後加入小遊戲時把地墊換成攤位即可；若攤位高於兩公尺，請比照既有機台加上透視。

## 環境動態與即時互動

- 常態動態：拱門跑馬燈、燈串微閃、帳篷飾邊與旗幟彩旗隨風飄動、舞台聚光燈緩慢掃過表演圈、空中鞦韆與吊環擺動、氣球晃動、表演圈上方飄落的彩紙、風琴冒蒸汽。
- 對玩家有反應、不計分也不存檔：
  - 哈哈鏡會照出玩家自己，每面鏡子拉長、壓扁或扭曲的方式不同。
  - 走進表演圈，三盞聚光燈會追著玩家，旁邊的大鼓開始滾奏；走出去就停。
  - 經過氣球旁邊，氣球會往另一邊偏。
  - 影子台前的鴿子在玩家靠近時飛走。
- 開啟減少動態後以上全部靜止；鏡子仍會照出玩家所在的位置，因為那是玩家自己的移動。

## 燈光

舞台聚光燈與路燈都在「最近八盞亮、兩盞有影子」的名額內；跑馬燈、燈串、腳燈只是會發光的燈泡，不佔名額。鏡廊與影子台原有的兩盞區域光保留。
