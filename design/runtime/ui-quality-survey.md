# Snapland UI 品質調查與可實作方向

本文件是設計研究與實作建議，不代表 UI 已完成或已經過遊戲試玩。研究以實際讀取的官方文件、官方手冊和產品說明為依據；沒有把未播放的影片或未查看的圖片當成已檢視證據。此輪僅做最小程式閱讀：`game/ui/paper_ui.gd`、`game/main.gd` 的 HUD／通用面板／小遊戲說明／設定建立段落、`game/minigames/session.gd` 的共用 HUD 與 12 個 `_draw_*` 畫面、`game/data/welcome_games.json`。

## 現況與問題

Snapland 已有明確的海港紙藝視覺基線：`paper_ui.gd` 設有墨藍、紙白、青綠、深青、珊瑚、赭金六色，紙牌外框、票券 icon 與陰影，並使用 Noto Sans CJK TC。問題主要在資訊編排和遊玩前後的學習節奏，不宜以增加裝飾或再換一套 palette 代替。

主園區畫面把收藏數、拍貼本／任務／成就／地圖／衣櫃／時段／設定七個同權重按鈕、任務文字、長串鍵盤提示和氣氛標語同時留在畫面。玩家在園區中最常需要的「目前在哪、附近可做什麼、目前任務／收藏進度」沒有形成一眼可讀的主次；次要系統的入口也比目標提示更搶眼。

通用面板有一致的置中紙卡框架，但多數內容仍是縱向文字加按鈕。拍貼本、任務、成就、地圖、衣櫃、時段、設定、暫停、抵達介紹與小遊戲說明，沒有共同的信息目錄或標籤習慣；不同面板的資訊密度和入口語意不一。小遊戲開始面板目前把操作長句作為第一內容，另列惡魔條件、收藏回饋、輔助差異和開始按鈕，缺少獨立「玩法／練習／開始」階段及示意畫面。

小遊戲 HUD 目前同時顯示全句操作（14 px）、整句普通目標與加碼條件（13 px）、時間、分數、重來／離開、輔助標記、完整底部 prompt（17 px），並保留背景和玩法物件。小遊戲自己的 `_draw_*` 又會重複顯示部分目標或按鍵，帶來重複提示、文字太小、重要狀態彼此競爭的問題。用於理解機制的細節被塞進即時操作畫面，也沒有固定「進度 → 成績 → 收藏」的結果摘要階層。

| 小遊戲 | 目前最需要解決的 UI／理解問題 |
|---|---|
| 氣球快遞 | 起飛鍵、雙重飛行輸入、煞車與送件圈、風向與碰撞風險一次全說；把「讀風→調高度→煞停收件」拆成畫面步驟並就近顯示風與下一站。 |
| 風箏穿環 | 滑鼠和方向鍵同句呈現，但玩家需要讀懂上下高度與環序；用一張標記目標高度的示意圖和清楚的「已穿／剩餘環數」取代常駐長句。 |
| 噴泉跳拍 | 「最亮時跳」缺少明確預備、命中、過早／過晚差別；將一個節拍示意和「觀察—起跳」練習放在暫停計時的說明頁。 |
| 人潮指揮 | Q/E、點擊、號誌方向與隊伍方向需互相對應；畫面應固定展示當前號誌、下一隊方向及 6 隊通過進度，正確判定不能只靠顏色。 |
| 帽子救援 | 移動控制與陣風策略混在一句目標，成功數、漏接數和最低門檻沒有顯著區別；固定呈現「接住 x/6、漏接 x、普通門檻」並用箭頭示風。 |
| 彩帶節拍 | 八拍輸入、滑鼠半屏對應、強拍要求同時出現；需要節拍序列卡、當前拍與結果圖例，且節奏提示不能只靠顏色或聲音。 |
| 花壇水路 | 選管與轉管的操作沒有用圖例說明管口方向，四次以內的加碼門檻不夠貼近每次旋轉；顯示起點／終點、目前路徑與剩餘旋轉數。 |
| 招牌平衡 | 左右細調、陣風、安全線和中心落點要求混在句中；用固定中線、可辨識安全區、七拍記錄和非顏色式危險標記說明判定。 |
| 影子捉迷藏 | 「在目標內維持三秒」但玩家不易辨認合格邊界、保持時間與是否破壞首次對準加碼；示意輪廓交疊，另顯示保持計時與首次命中紀錄。 |
| 泡泡合照 | 點擊吹泡泡、等待環亮、再點角色是多階段流程，截圖評分規則（置中、完整包住）未在操作前視覺化；用三格流程示意及即時照片評分刻度。 |
| 長椅換位 | 座位選擇、交換次數、兩組朋友關係和三次加碼門檻需要記憶多個對象；顯示座位編號、朋友配對圖例、交換數與完成狀態。 |
| 迎賓大合奏 | 先聽後輸入、四鍵／點擊、三輪和零失誤條件容易被長句淹沒；以可回看的四音符示意、輪次和已記錯誤數交代規則，並標註練習是否計入收藏。 |

## 建議的資訊系統

保留六色基線，規範顏色用途，避免六色每個區塊都同時搶眼：

| 顏色 | 建議語意 |
|---|---|
| 墨藍 `#203e47` | 正文、主要數字、深色 HUD 底板。 |
| 紙白 `#f7efd9` | 長文、教程卡、面板主底色。 |
| 青綠 `#337b7b` | 導覽、互動選取、一般進度。 |
| 深青 `#24585d` | 次層底板、邊框、低干擾分隔。 |
| 珊瑚 `#d97966` | 當前目標、失誤／風險；必須搭配圖示或文字。 |
| 赭金 `#dfa458` | 完成、收藏、加碼資格與一次性重點。 |

以 Noto Sans CJK TC 為主字體，使用五個語意字階：大標題 30–32 px、面板標題 24 px、操作／目標正文 18–20 px、HUD 數字與狀態 18 px、補充說明最低 15–16 px。當前 13–14 px 的核心目標和操作字級應提升；只有不影響理解的標籤、編號可低於 16 px。色彩、圖示、文字三者共同表達命中、失誤和解鎖狀態。

採 8 px 基礎間距：同一組內 8 px，模組間 16 px，區段間 24–32 px；面板四邊至少 24 px，卡片內至少 16 px。主畫面同一時刻最多保留一個主要目標區、一組全域導覽、必要狀態；把長串熱鍵搬到「操作總覽」，只在附近互動或第一次遇到時顯示單一情境提示。保留港口紙藝識別，將航海圖圖例、碼頭票券、航標、船鐘作為低頻結構語彙：一致的標題票根、區域色帶、羅盤式分類標記和小型海港地名標籤；勿在每張卡疊滿繩結、木紋、圖章與裝飾線。

### 一個可實作的小遊戲 HUD

以「人潮指揮」為例，在 1280×720 安全區內採三層：

```text
┌────────────────────────────────────────────────────────────┐
│ 人潮指揮   04:18                         得分  0250   暫停 │  ← 64 px；名稱/時間/分數/暫停
├────────────────────────────────────────────────────────────┤
│ 目標  安全帶完 6 隊             進度  ● ● ● ○ ○ ○  3/6   │  ← 48 px；目標/圖形進度
│ 加碼  6 隊都走對號誌（未達成）                               │  ← 24 px；次級，不搶眼
├────────────────────────────────────────────────────────────┤
│             當前號誌：← 通行      下一隊：→                  │
│                  [路口遊戲場景]                              │
├────────────────────────────────────────────────────────────┤
│ 操作  Q 左 / E 右    或點選號誌       判定：等待切換          │  ← 約 52 px；只留本局相關操作
└────────────────────────────────────────────────────────────┘
```

上列數字和文字均使用可讀字級，目標與加碼拆開；進度同時用數字和形狀，狀態不是只靠綠／紅區分。把「點擊、Q/E」按鍵放在號誌附近；移除其他遊戲的通用重來、方向鍵及無關操作提示。依 viewport 保留安全邊距與可伸縮文字列；較窄畫面時將加碼條件收進可展開的挑戰卡，不能縮小核心字。

## 教學與計時流

1. 從小遊戲入口開「挑戰簡介」：名稱、普通目標、獎勵、難度／輔助選項；主按鈕清楚標「看教學」與「直接開始」，上次已完成者可顯示「重看教學」。
2. 教學使用逐步卡：每頁一個規則，配一張本遊戲截圖／靜態示意截圖；標出交互對象和方向／命中區域，圖旁寫出圖示對應的鍵鼠操作。重要內容文字可選取與完整回看，圖片不能承擔唯一規則資訊。可上一步、下一步、跳過、返回規則索引；有進度 `2/4` 和完成記錄。
3. 練習在不計正式成績、不扣收藏機會的沙盒中重演核心操作；完成後顯示一次具體回饋，如「已學會切換號誌；正式局會有 6 隊」。可從暫停面板回教學索引或練習；繼續遊玩前重新確認「繼續挑戰」。
4. 教學／練習／暫停閱讀時停止回合計時和遊戲模擬。只有明確按下「開始挑戰／繼續」才開始或恢復時計；關閉教學不以倒數逼迫。正式局內核心計時照常運作，失敗後顯示可讀結果再允許免費重來。
5. 完局摘要把普通成功、分數、惡魔加碼、收藏結果分成區塊；用已完成步驟清單和清楚評分標準解釋分數／漏失。提供「再玩一次」「重看教學」「回園區」，重玩前再次確認標準／輔助模式。

## 建議實作次序

1. 先重排 `session.gd` 共用 HUD：核心目標、時間、分數、離開／暫停固定，單一本局操作移到該遊戲區附近；刪除重複長句與全域無關按鍵。定義各遊戲的進度摘要（目前步驟、成功/錯誤、剩餘數）並固定於同一狀態列。
2. 重做 `_show_game_info` 成規則摘要入口，新增每遊戲教學頁資料欄位和教程畫面資源／截圖；確保圖片有對應文字替代說明。首輪先為 12 款各做 2–4 個教學步驟，不需新增裝飾圖，只需能清楚看出互動區和結果。
3. 統一面板標題、章節、主/次行動與返回位置；主園區把固定七按鈕整理為主要「地圖／任務／拍貼本」及其餘「更多」，常駐文字提示只保留可互動上下文。拍貼本卡顯示縮圖、遊戲／區域、取得狀態及詳情入口；地圖與任務使用同一區域名稱及完成圖例。
4. 補上操作對照、文字縮放／版面縮窄檢視、鍵盤焦點與提示停留測試；提供具體計時、判定差異的輔助說明，並確認 reduced-motion 涵蓋 UI 動態與背景。
