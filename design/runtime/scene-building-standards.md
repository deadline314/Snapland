# 場景與素材搭建規範

更新：2026-11-27。新增或修改任何園區場景、道具、貼圖與影子前先讀這份。每條規則後面標示驗證方式：**［自動］** 由場景檢查在測試階段擋下，**［畫面］** 需以原生截圖確認。研究來源見 [畫面打磨研究](visual-polish-research.md)。

這份規範來自三類反覆出現的缺陷：地面層互相超出、未加工的純色方塊道具、貼圖與影子和場景不合。

## 1. 地面分層

由下到上固定為：水面 → 沙灘／岸石 → 草地／泥土 → 鋪面與步道 → 木棧與平台。

- 上層的外緣必須落在下層之內，內縮至少 0.3 公尺。草地不得直接接水，中間一定有沙灘或岸沿。**［自動］**
- 相鄰兩層的高度差至少 0.02 公尺，不得共面閃爍；水面不得高於任何岸沿。**［自動］**
- 區域不能懸浮在單色背景上。可走範圍之外，地面要延伸到鏡頭可見範圍再多 12 公尺，或有符合主題的遠景與收邊（海面、圍牆、廠房牆、帳篷布、樹籬）。任何時段、站在可走範圍任何一處，都不能看到背景底色。**［自動＋畫面］**
- 岸石、礁石等帶水窪的貼圖只放在沙灘或水邊，不放在草地與步道上。**［自動］**
- 迎賓島的海岸線、沙灘寬度、草地邊界與可走範圍都由同一份島嶼形狀資料決定。新增地面、水岸效果、擺放規則或地圖時讀取它，不另外寫一套邊界或座標範圍。**［自動］**
- 步道是沿著折線彎曲的帶狀鋪面，不用對齊座標軸的長方板；重疊的鋪面層之間高度至少差 0.005 公尺。**［自動］**

## 2. 道具造型與材質下限

- 鏡頭可見、最長邊超過 1.0 公尺且次長邊超過 0.5 公尺的方塊、圓柱、圓球或稜柱（也就是露出一大片面的形狀），不得使用單一純色材質；必須使用有紋理的表面（木、石、圖集鋪面、布料等既有表面材質）。細長的欄杆、桿與收邊條不在此限。**［自動］**
- 「三段法」：任何高度超過 1.0 公尺的道具至少有底座、主體、頂蓋三個可辨認的部分，兩個大色面相接處要有收邊條、踢腳或簷口。**［畫面］**
- 招牌性設施（船、攤車、閘門、鐘樓、帳篷、機具）的輪廓不能是矩形盒子：至少一個斜面、錐度、曲面或懸挑。**［畫面］**
- 重複三個以上的相同小件用批次繪製，不逐一建立節點；材質一律經由材質快取取得。**［自動］**

## 3. 貼圖與看板風格

- 像素密度一致：場景看板貼圖以每公尺約 48 像素為準，允許 ±25%；不混用縮放後的高解析圖。**［畫面］**
- 描邊不用純黑。描邊色取該物件暗部再加深，亮度不低於場景中建物的最暗面；樹木的描邊不得比角色與建物更重。**［畫面］**
- 飽和度與明度要落在所在區域的調色範圍內；看板貼圖必須受時段色調影響，不能在夜晚仍是白天的顏色。**［自動：使用受光的看板材質］**
- 看板底部要「落地」：有接地陰影，且底部有草叢、石塊或陰影過渡，不能是一條筆直的切邊浮在地面上。**［畫面］**

## 4. 影子

- 看板物件（樹、灌木、花盆、路燈、角色）的影子用它自己的貼圖剪影投出，輪廓要和外形相符；不得用球、膠囊、圓柱等替代形狀投影。**［自動］**
- 影子來源不得懸空超過 0.05 公尺，也不得有碰撞。**［自動］**
- 每個角色與直立道具腳下有柔和的接地陰影。**［自動］**
- 不把大片影子投到開闊海面中央；岸邊植物離水線至少 1.5 公尺。**［自動］**

## 5. 擺放

- 道具的佔地必須完整落在同一種地面層上，不跨層、不半懸空；底部貼齊地面。看板貼圖底部高於地面 0.3 公尺或陷入超過 0.6 公尺會被擋下。**［自動：看板貼圖；畫面：其他道具］**
- 不擋住互動點、步道與入口；互動點周圍 1.2 公尺淨空。**［自動］**
- 同一種裝飾不等距排成一列；位置、大小與朝向要有變化，但用固定種子，重開後一致。**［畫面］**

## 6. 動態與互動

- 每個區域至少三種符合主題的環境動態（例如水、布料、蒸氣、機具、生物、燈光），其中至少一種會對玩家靠近或互動產生反應。**［畫面］**
- 所有動態都服從「減少動態」設定：開啟後靜止或隱藏，不得殘留閃爍。**［自動］**
- 節點只在場景建立時產生一次；切換時段、設定或進出畫面不得新增節點或材質。**［自動］**

## 7. 燈光

- 可見光源一律配發光的燈體；燈加入區域燈具清單並遵守「同時最多八盞亮、兩盞有影子」的預算，不在清單外新增燈。**［自動］**
- 四個時段都要可讀：夜晚主要動線與互動點亮度足以辨認角色與地面。**［畫面］**

## 8. 效能預算

| 區域 | 場景節點上限 | 單一視點繪製數上限 |
|---|---:|---:|
| 島嶼本體，不含主題區（2026-11-27 六區接上後實測約 2570；2026-11-28 加上第十道劇場閘門後無 GPU 實測約 2675） | 2750 | — |
| 每個主題區（接在島上時，實測 126 到 221） | 900 | 800 |
| 島上任一位置的畫面（島嶼加上醒著的主題區；實測最多 1465，夜晚廣場） | — | 2200 |

- 主題區接在同一張島上後，「每區」指島上的一塊區域：遠處的主題區休眠、不顯示也不更新，所以單一畫面只算島嶼與附近醒著的區。六區全建好時整個場景約 3770 個節點（含介面）。
- 主題區第一次靠近時分好幾個畫面逐步建立，單一畫面的建立時間不超過 100 毫秒。

- 超過預算先合併重複物件，再減少細節。**［自動：節點；畫面：繪製數］**
- 粒子每個區域合計不超過 200 顆；全螢幕效果最多一道。**［畫面］**

## 9. 自動檢查

場景檢查會建立十一個區域（迎賓島、九個主題區與地底惡魔劇場）並逐一稽核，執行方式：

```
python tools/run_game_tests.py --only "scene standards tests"
```

- 目前稽核四類：大面積純色形狀、用基本形狀代替的影子、懸空或陷地的看板貼圖、節點預算。迎賓島的地面分層另由島嶼佈局檢查負責。
- 既有欠債逐區、逐類記錄在 `game/tests/scene_standards_baseline.json`。任何一區的數量只能減少，增加就會失敗並印出第一個違規物件的路徑、座標與尺寸。
- 清掉欠債後把基準數字改小；新增區域時基準從零開始。
- 要列出全部違規（清理票的工作清單），直接執行測試腳本並加上 `-- --scene-audit`；要重寫基準加上 `-- --write-baseline`，只在確認數字是變少時使用。

## 10. 交付前檢查

1. 執行場景檢查，十一個區域全部通過。
2. 用 `python tools/run_native_capture.py` 以固定視點擷取白天與夜晚各一張，對照本規範第 1 到 5 節逐條看過。
3. 票上只附一張必要的畫面。
4. 新增一種規則時，同時補上對應的自動檢查或寫明畫面確認方式。
