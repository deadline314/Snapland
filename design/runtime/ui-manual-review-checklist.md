# UI 人工驗收清單

2026-10-24：依 User-guide 與目前減負設計校正。未勾項仍須實際檢視，不因修正文案而視為通過。

供 GPU 截圖驗收時逐頁查看；只判斷目前實際畫面與操作，不把 headless 測試當成試玩結果。建議先以 1280×720 檢查一般閱讀，再以 800×600 確認彈窗可捲動、按鈕未被裁切。截圖由驗收流程保存，本清單不生成或修改圖片。

## 主 HUD 與航海旅券

- [ ] 探索畫面左上僅呈現區域與時段；收藏數與金幣在旅券按需查看，不重新加入常駐計數。
- [ ] 右上只有「航海旅券 · M」入口；附近僅顯示一個具體動作，例如「敲潮鐘」「和票票說話」；走遠收起，對話與攤位邀請開啟時收起探索HUD。
- [ ] 有進行中的任務時，摘要與步驟數清楚但不遮擋角色；沒有進行中任務時不留空白任務框。
- [ ] 點旅券後能分辨探索、收藏、整裝、遊園安排與操作速查；操作速查可讀出 WASD／方向鍵、E、F、P、C、T、Esc。
- [ ] 點各分類會到既有地圖、任務、收藏本、成就、衣櫃、時段或設定畫面；M 和 Esc 的開關行為一致。

## 入園、對話與旅券內容

- [ ] 入園介紹的主要行動與略過選項清楚；說明文字有足夠行距，按鈕不與內容卡重疊。
- [ ] 對話身份卡使用對應角色圖，角色名、逐字顯示正文與繼續／略過操作層級清楚；E／Space 可繼續。
- [ ] 地圖航線可辨認港口、廣場、迎賓大道；尚未開放區域明確寫「區域布景準備中」，不會像可直接進入。
- [ ] 任務清單能看出尚未開始、進行中或已完成；任務問題、互動舞台、操作提示、選項及錯誤回饋相鄰且不需要猜測下一步。
- [ ] 拍貼卡片優先使用實際收藏縮圖；空卡仍能讀出取得方式。四時收藏明確呈現時段、收藏狀態與 0–4 進度。
- [ ] 成就按完成狀態分組；長清單可捲動，狀態符號旁仍有文字，不靠顏色單獨表意。

## 設定、時段與衣櫃

- [ ] 設定把音量／文字速度與輔助／降低動態／顯示分組；滑桿當前位置、選項狀態及作用說明可辨。
- [ ] 時段面板能看出選中時段與時間；只有允許拍貼的位置顯示可操作的收藏按鈕，切換後返回場景能看見時段變化。
- [ ] 衣櫃試衣鏡顯示實際角色預覽；方向切換清楚，六種外觀欄位不重疊。
- [ ] 衣櫃與商店商品列使用現有服飾縮圖，逐列清楚標示名稱、價格／已收藏／穿著中；預覽、購買、穿戴、套用、取消各自可辨且不誤觸。
- [ ] 低餘額、已擁有或已穿戴的狀態以文字說明；不只用紅綠色表示。800×600 下操作列仍在可見範圍，清單可捲動。

## 小遊戲入口、教學與結果

- [ ] 設施先提供簡短邀請和主要開始動作，規則／教學／練習與輔助從清楚的次要入口按需展開，不恢復多個並列主要按鈕。
- [ ] 園區入口、遊戲入口與局中 Help 都可打開相符教程；每頁可見步數、截圖／說明、目標、輸入與成功條件，左右鍵、Tab、Enter／Space、Escape 有可見焦點和預期行為。
- [ ] 正式截圖存在時比例完整且不變形；若資源尚缺，畫面誠實顯示文字 fallback 與步驟說明，不能把空框看成已完成圖解。
- [ ] 局中打開教學後計時／場景停止；關閉教程返回仍暫停的同一局，玩家可明確選擇繼續。
- [ ] 練習結果明示不保存，顯示實際分數明細且不出現收藏成功、幣、任務或成就獎勵字樣；正式結果再按遊戲規則呈現收藏結果。

## 輸入、焦點、可讀性與裁切

- [ ] 所有主要按鈕實際高度至少 44 px；一般正文約 20 px、次要說明至少 16 px。繁體中文沒有截字、重疊或低對比。
- [ ] 用滑鼠／觸控點擊時，目標邊界足夠大、標籤與點擊動作吻合；操作後不被底層遊戲誤收輸入。
- [ ] 僅用鍵盤操作：初始焦點落在主要動作；Tab／Shift+Tab 焦點框持續可見；Enter／Space 觸發當前控制；Escape 回退或暫停符合目前上下文。
- [ ] 1280×720 與 800×600 兩尺寸下，彈窗留有螢幕內距；一般頁優先分類與分頁，確有必要才用單一捲動區，固定操作列不被內容推出畫面。
- [ ] 關閉／返回後回到原場景和合理焦點；不殘留遮罩、隱藏控件攔截點擊、重複音訊或仍在運作的 session。
