# 潮汐碼頭往返與保存

MAIN-24 沿既定園區設計交付第二個可探索世界。此票不實作或授予潮汐碼頭遊戲、探索、主線及支線收藏；十二款遊戲仍各自依設計實作，不能用迎賓遊戲換名填充。

## 玩家流程

迎賓大道的潮汐碼頭路口，以全島不同普通拍貼總數檢查六張門檻，未滿時顯示還差幾張，達標後提供明確前往按鈕。不消耗任何拍貼或金幣。其他八個未實作園區仍顯示準備中。

潮汐碼頭有獨立燈塔岸線、沙洲、環形水路與船票碼頭，可步行、查看路標與資訊牌。潮汐鐘可立即預覽漲退潮，不保存潮位、不改變全島時段。退潮可走沙洲捷徑；漲潮不讓玩家走入水裡，有永久可達的免費渡船。渡船在兩種潮位都可使用，固定安全登岸。若玩家站在沙洲時升潮，先移到安全岸邊並歸零速度。返回迎賓大道的入口永久免費，不要求潮位或其他進度。

潮汐碼頭尚未交付的遊戲只用誠實的資訊牌，不產生遊戲亭、收藏、任務或造訪獎勵。保留既有遊戲指南及迎賓收藏的查閱，明確標註所在園區；不把迎賓內容列為潮汐碼頭內容。

## 保存與生命週期

`Progress.current_region` 只支援 `welcome`、`harbor`。新遊戲／重置預設 welcome；有效舊檔缺欄位預設 welcome；錯誤型別、未知或尚未實作目的地警告並回 welcome，保留其他資料。存檔版本保持 1，未知欄位仍往返保存。

`set_current_region(region: String) -> bool` 拒絕不支援值；相同值不寫檔；成功只原子寫一次，失敗還原原欄位。此方法不發出會再次保存的 changed 訊號；Main 在世界替換完成後自行刷新。

先驗證目的地與入場資格，再成功保存目的地，才釋放舊世界。保存失敗保留原世界、人物、鏡頭與所有進度，提供簡短重試提示。換區期間阻擋重入與操作，忽略舊區域事件；釋放舊世界後才建立新世界，穩態只有一個世界。固定安全出入口，返回迎賓時站在潮汐碼頭路口旁，不保存任意座標。

Main 啟動依有效保存園區建立世界；船上序章／碼頭開場只在迎賓初次啟動。船上重播保留於迎賓暫停選單，潮汐碼頭不顯示缺少船上舞台的重播按鈕，返回迎賓後仍可重播。重置進度時回迎賓世界，不能留下舊世界與新旗標不一致。遊戲、對話、拍攝及正在換區時不允許旅行。

每次建立世界重新連接互動與區域事件，套用外觀、設定、全島時段、收藏標記及故事快照；對可選的海岸玩具／發現控制採用原位的空值檢查。潮汐碼頭使用既有海港音樂，不以迎賓子區名稱假裝園區身份；關閉時沿用 ST-6 的退出守衛。

## 最小世界接縫

保留 `ParkWorld` 與既有 `_ready`／物理流程，HarborWorld 繼承可共用功能。只抽出下列既有行為：園區幾何、園區活動、出生點、玩家地板、地形取樣、移動邊界與區域名稱。迎賓預設內容與順序逐字保持，不先建迎賓再刪除。

保留被既有測試使用的靜態迎賓地形取樣 API；新增實例包裝供內部取樣並讓潮汐碼頭覆寫，須涵蓋腳底、影子、動作、外部移位與移動。玩家地板接縫不可漏掉隱藏迎賓大地板。潮汐碼頭不建立迎賓 NPC、海岸玩具、地標任務或遊樂設施控制器。海面／噴泉材質的設定套用需容許沒有噴泉的園區。

HarborWorld 提供 `set_tide(high: bool)`, `is_high_tide() -> bool`, `take_ferry(point_id: String) -> bool` 與 `map_snapshot() -> Dictionary`。互動點使用 `harbor:tide`、`harbor:ferry:*`、`harbor:info:*` 及 `region:welcome`，避開會授予迎賓獎勵的識別碼。地圖快照包含實際 bounds、land（矩形陸地列表）、sandbar、points（只含 id／label／position）、player 與 high_tide，不保留世界節點。圖形與碰撞使用相同地形範圍，避免地圖描述不存在的路。

## 選單與引導

HUD 與暫停的 /18、/12 使用目前園區數字；開區使用全島普通總數。潮汐碼頭地圖使用獨立的小面板顯示實際岸線、燈塔、沙洲、潮位、渡船與返回點，不能沿用迎賓十二站地圖。迎賓地圖與既有測試保持原本功能，潮汐路口開放狀態如實更新。

收藏冊可切換查看迎賓與潮汐碼頭，預設目前園區；迎賓原十八／十二來源不變。潮汐碼頭未實作來源顯示清楚的空狀態，不提供假開局／假取卡。已有迎賓照片保持可看、可開原圖。潮汐碼頭沒有當地任務，任務入口指出回迎賓查閱既有任務；既有任務進度不清除。其他成就及實作遊戲仍可查閱，名稱標註迎賓範圍。

新增提示使用繁體中文；Hover 只解釋門檻、不消耗、免費渡船／潮位預覽或返回目的地，不顯示實作名詞。

## 驗證

先保留迎賓地形、動作、邊界與原對話的局部基準，再驗證新欄位往返與保存失敗；兩個世界的地形／碰撞、潮位切換安全與渡船；Main 門檻、換區重入、保存失敗、設定、遊戲取消返回潮汐、重置、關閉重開與節點釋放。三種視窗／1.25 文字／降低動態、實際原生入場返回與隔離輸出包證據附票。程式化驗收不能寫成真人遊玩或真人試聽。
