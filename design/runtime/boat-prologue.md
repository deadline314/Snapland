# 晚風號船上序章

來源：2026-11-12 使用者要求完成整個遊戲並自主補票。ST-6 將既有船上接點接成可玩的開場；不修改已完成的 ST-2 碼頭導覽。

## 玩家流程

全新玩家先在晚風號甲板看見目前外觀的角色，依自己的步調讀五段短對話：阿浪廣播靠岸、主角整理相機、試看取景、向島上招手、走上棧橋。沿用既有對話的前進、整句顯示、角色滴滴聲與字幕。Esc／「直接下船」可略過船上演出，接續原碼頭導覽；後者仍能另外略過。

暫停選單提供「重看船上序章」，重播結束回到原地自由探索，不再自動開始碼頭導覽。沒有新拍貼、金幣或道具獎勵；不增加普通收藏分母。

## 視覺與資源

重用 `ParkWorld` 已建好的晚風號、海面、材質與主角 `avatar_renderer`。新增船上站位標記與一個暫時的完整角色 Sprite3D；不重建世界、不拆接四肢、不變更角色 PNG。固定船上鏡頭須讓頭、腳與甲板可見，字幕沿用既有可縮放面板。

演出期間保留原玩家位置與朝向，停用世界物理更新、隱藏原角色並沿用對話的 NPC 停留規則。完成、略過、外部移除對話與退出場景，都須還原原鏡頭、物理更新及可見性。站位初值為晚風號前甲板 `(5.5,1.04,22.65)`；可依實際渲染校準，不得讓鞋底被甲板或欄杆裁掉。

待機使用 `AvatarRenderer.idle_frame_for_time()`；相機、互動與招手使用既有逐格時間資料，有限動作播完回待機。降低動態固定姿勢，不新增鏡頭晃動或整身伸縮。只在影格改變時更新貼圖，共用現有有上限的角色快取。

## 保存與容錯

增加 `prologue_seen` 布林欄位，存檔版本保持 1。新記憶體／新遊戲預設 false；載入缺少此欄位的既有有效存檔預設 true，避免更新後強迫重看。無效型別視同缺少欄位並警告，其他保存資料保持原樣。完成與略過只保存這個旗標；保存失敗復原旗標，但仍能繼續導覽。

故事資料增加五段 `prologue_lines`，說話者僅用現有阿浪／主角，姿勢只准 idle、interact、photograph、wave。缺少此新欄位的舊故事資料仍可使用原導覽；無效船上資料不啟動演出並安全回到既有流程。故事與舞台準備好後，船上接點才改為 available。

## 驗證

- 新遊戲完成／略過 → 碼頭導覽 → 自由探索；旗標保存、沒有額外獎勵。
- 舊存檔、失敗保存、錯誤欄位；金幣、拍貼、外觀與未知欄位不被破壞。
- 重播、連續重播、對話外部移除、場景退出；還原鏡頭／物理／可見性。
- 目前外觀、降低動態、有限動作結束、貼圖更新與暫時節點數有上限。
- 800×600、1280×720、1920×1080、1.25 文字；原生截圖、隔離 PCK 及 Windows 啟動。

局部測試與程式化截圖不代表真人遊玩或真人試聽。
