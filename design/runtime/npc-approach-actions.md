# NPC 非正面靠近的互動動作

2026-11-18，ART-17，基準 main `3ca0b9c`。

票票的招呼、小角與阿浪的互動目前只有正式正面完整來源。世界事件把玩家位置換成八方向後，直接請求不存在的側面或背面來源；對話能開啟，動作卻退回站姿。

世界互動事件固定選用角色目前已認可的正面表演，與既有任務完成反應一致。刪除這條事件途徑不適用的位置量化；不改走路方向、不增加素材別名或隱藏來源缺失。角色根與互動點不因表演而移動；正面完整動作結束仍依原規則回到站姿。

素材庫、NPC 的明確方向請求及完整來源驗證維持原契約。直接請求缺少方向仍回報缺件並恢復完整人物；連正面來源也損壞時，實際對話仍可使用，不能沿用上一張手勢。將來新增其他正式方向時，另依其來源與演出設計調整事件選擇，不預先建立配置或方向回退框架。

驗證須經真實 Main／世界互動途徑，覆蓋三位 NPC、八個靠近方位，確認表演、對話保持、暫停、動作結束、取消與釋放；保留原對話回歸所有斷言。原生三位 NPC 的代表非正面靠近需記錄正常與慢速、降低動態／重入及隔離封裝播放，記錄攝影與玩家擺位，不修改 NPC 根位置或注入動作結果。

事件選擇與降低動態呈現均使用既有來源。全角色動畫的自然度、缺少原畫與全方向覆蓋仍依 ART-16／ART-17 原條件驗收；自動記錄與逐張查看不聲稱真人遊玩、連續觀看或試聽。

## 原生檢視發現的降低動態缺口

首次隔離封裝的技術檢查通過，但主 Session 查看降低動態的阿浪代表圖，發現舊註冊基準仍是右向走路姿勢，且與正式待機比例不同。基準貼圖相等只能證明還原舊圖，不能證明完整站姿；此輪降低動態畫面拒收。

降低動態時，若角色有合法完整正面站姿來源，須選用該來源的靜止姿勢，保留同一正式畫布、服裝合成與方向／動作狀態，再停止時間前進。缺少或損壞正式站姿時仍沿用既有完整人物安全回退並明確記錄缺件。場景釋放、舊路線根位置還原與互動點政策維持原契約，不擴大改動範圍。

回歸須先以正式來源斷言重現舊走姿還原失敗，再驗證三位角色、重複切換、啟用前已互動／行走、暫停／對話保持、恢復與缺件情境。原生來源比對不得以舊基準相等替代正式站姿；重錄降低動態重入並重新核對最終封裝來源指紋。

共用原生接地檢視也需使用正式站姿與服裝合成，暫停恢復期間不能重新要求舊貼圖。三位正式站姿的腳底錨點為 448，最後不透明像素列為 447；檢視要求與正式來源的像素列精確相同、位於錨點之上且相差不超過既有一列邊界規則，保留 RGBA8、完整畫布、接觸與深度條件。完整入口較早發生的舊位置／來源假設及身體遮擋分別由 MAIN-32／33 追蹤，相關降低動態方法的實際局部通過不能當作完整入口通過。
