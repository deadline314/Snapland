# NPC 原地轉向與巡路交接

2026-11-12，ART-16。三位 NPC 使用既有左右收勢的完整姿勢反向播放，在真正移動前先原地轉向。沒有新增原畫、拆腿、鏡像、補間或逐格縮放。票票、小角先接入；阿浪隨後也改用共用接地巡路，保留原路線範圍與移動速度。

## 時序與責任

`AuthoredNpcPatrol.advance(delta, allow_translation)` 先驗證地面、路徑與休息時間；`ready` 只表示可以起步。待機時禁止平移，`NpcActivity` 選擇有限的 `depart`。完整播放後才呼叫 `begin_stride()`，將距離相位歸零並接行走；下一次巡路更新才移動根位置。行走繼續由實際地面位移推進影格。

起步來源必須完整、非循環、沒有回正面指令且不超過一秒。缺少方向、後段損壞、循環、過長或錯誤回正面設定時，保留原有完整來源步行。暫停凍結起步；招呼可中斷；對話期間結束的起步回到正面站姿，不能接成原地踏步。解除對話後重新起步。降低動態維持完整靜止人物，結束時不補走過期路程。

## 中立姿勢與資源

三位 NPC 的收勢末格直接引用各自既有 `idle/front/0`，避免另一張正面原畫的頭部、衣著及站距在交接處跳變。票票、小角的起步首格因此與原待機完全相同。

素材庫僅在選定裝備後的完整影格描述相等時，共用 `depart → settle → idle` 的貼圖與佈局；保留各動作的播放時間。任何來源、錨點、圖層或裝備差異都不共用。引用方向固定，不構成遞迴環；既有貼圖上限不變，也不額外產生 GPU 畫布。

## 驗證

來源重建檢查 218 個區域；Python 局部 38 項及受影響引擎 11 項通過。新增生命週期回歸涵蓋原地轉向、暫停、對話、招呼中斷、重新設定、接步、降低動態、五類損壞回退與貼圖／佈局共用。

正式世界原生正常、四分之一速度、降低動態與隔離 PCK 逐項觀察；票票、小角左右各四張起步均出現，轉向期間最大根位置偏移為 0。另核對阿浪共用中立姿勢。使用相同 Godot 執行 PCK，非獨立桌面執行檔；Dummy 音訊與固定錄影節拍不代表真人試聽或硬體性能。詳細指紋、原生姿勢、影片與診斷附 ART-16。


## 2026-11-12 阿浪加入共用接地巡路

阿浪加入 `AUTHORED_PATROL_PROFILES`：原點左右各 0.6 m、0.6 m/s、步距 0.36 m、休息 1.9 秒及原地起步。起步使用既有四張收勢反向播放；沒有新增原畫。休息內可完成收勢與個性小動作，完整動作不再被舊時間表強制切回走路；停留可因完整個性演出而延長。

有合法地面與完整左右行走來源時，只有 `AuthoredNpcPatrol` 移動根；舊 AnimationPlayer 位置軌道停用，阿浪的舊時刻選動作也停用。未選過接地巡路的舊註冊與可選實驗 rig 仍保留既有途徑。相機、互動點及完整 Sprite3D 仍由原主人更新，不新增碰撞身體或另一套逐姿勢時鐘。

已選接地路徑後若 provider 失效，停在當前完整站姿，不重新開啟舊軌道或原地踏步。每位角色最多保留一個暫停的巡路物件；provider 恢復重用該物件，保留原點與範圍，從新的原地轉向恢復移動。場景釋放一併移除，沒有計時器或輪詢重試。

三位角色共同執行起步、暫停、對話、招呼中斷、provider 遺失／恢復、降低動態與損壞來源檢查。原生阿浪再觀察左右各四張起步、行走及收勢，根位置在起步期間偏移為 0；正常、四分之一速度、重入、降低動態及空目錄 PCK 證據附 ART-17。
