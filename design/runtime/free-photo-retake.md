# 參與收藏與免費補拍

SG-29 補齊既定「樂趣、收藏與認證分開」，涵蓋交付目錄中實際開放的玩法，不讓規劃中的識別碼變成可領獎內容。依賴 SG-28 的輕量目錄、區域身份與原子遊戲取卡；完成該票後再接入，不平行修改其 Session／Main／Progress。

## 參與與嘗試

正常遊戲自然結束即有普通卡資格，勝利、分數與實際挑戰資格保持原樣；練習與取消不自動發獎。Session 共用完成路徑提供 ordinary_eligible，Main 分開處理收藏與真實成功事件。不能為了取卡把失敗改成成功或派發成功任務事件。

玩家確實進入已交付遊戲才記為一次嘗試（含練習及立即退出）；只看教學、點邀請或未知 ID 不算。嘗試歷史原子保存、驗證、去重，重開保留，重置清空，舊檔缺欄安全預設空集合。保存失敗不能謊稱已開啟補拍；介面明示可重試，不扣費或毀掉舊檔。

## 固定入口與三步

每張已交付遊戲普通／小惡魔卡在相簿列出區域、固定遊戲亭、缺卡 ID 與免費補拍。遊戲亭同樣提供補拍入口；未嘗試時可直接進入練習，立即退出後返回入口。已擁有的卡可查看取得方式與原圖，不自動覆蓋舊照片。

補拍是明確標示的主題攝影布景，與實際挑戰結算分開：

1. 觀察示範：展示該玩法已驗證的原生教學圖與重點，不假稱這張範例是玩家本局畫面。
2. 調整布景：以無時限、可返回的鍵鼠選項改變主題布景中的構圖／標記／道具配置；選擇會實際改變拍攝預覽。
3. 拍攝：按下快門保存當前補拍布景的真正影像，再授予所選原卡；不存在勝負、反應、人工智慧、裝備或金錢門檻。每一步有簡潔說明與可辨識狀態。

重用現有原生教學圖、紙本元件、字型與照片保存／原圖檢查。新增一個小型主題攝影控制即可，不為十三款各重做一個遊戲模型，也不把補拍算成新小遊戲。範例與布景拍攝的來源區別清楚：保存的是這次實際安排的布景，不是複製範例後冒稱遊戲通關。圖像預覽需檢查存在／解碼／尺寸上限，遺失時提供可理解回退而不授予空白照片。

## 取卡與保存

沿用原卡 ID、配額與開區／異空間收藏計數；一次 40 金幣收據仍按全域遊戲去重，舊卡無收據仍不補發錢。補拍記錄 acquisition_method=retake 與實際補拍照片，不創造勝利、排名、高分或實際挑戰成功；後續真正達成挑戰仍可如實更新取得證據。第一張照片與全區收藏成就依其收藏語義處理，高分／技巧認證只接受真實挑戰。

嘗試資格、三步狀態、目錄身份及選定卡別都必須驗證；取得後先完整保存成功才顯示發獎。圖片寫入或取卡保存失敗清楚提示、可重試，不留下半份獎勵、不重複發錢、不發錯區成就；只更新缺少的所選卡，不覆蓋另一張既有卡與原圖。共用現有原子獎勵根部，不讓補拍偽造 Session.finished(success)。

## 驗證

先保留舊迎賓與新碼頭實作的基準。新增局部檢查覆蓋全部已交付玩法的正常失敗普通資格與真實失敗、練習／取消無自動卡、未嘗試／未知 ID 拒絕、嘗試保存／重開／重置、三步順序／返回／重播、兩種卡／取得來源、舊卡及原圖保持、失敗保存完整回復與新技巧證據不被補拍冒領。

原生實際操作從遊戲亭和相簿進入，在迎賓及碼頭完成普通與小惡魔補拍；檢查布景確實改變、快門保存的圖像與取得說明、關閉重開、鍵鼠及逐步選項、小視窗／放大文字／降低動態、獨立資源包與 Windows。所有新套件登記到完整四批 CI，不省略既有玩法。自動操作不稱真人樂趣或人耳驗收。

決策代價：沿用真正教學圖作為示範，補拍採主題攝影布景，不複製每款遊戲的物理模型；若後續希望逐款動態補拍演出，可替換其布景呈現，但收藏與真實成績的邊界保持不變。
