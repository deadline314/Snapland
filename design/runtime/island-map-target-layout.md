# 地圖標記、選取與小視窗

2026-10-24；ART-20。以 User-guide 的減負方向為準，不恢復舊紙卡選單。

## 問題與決定

800×600、1.25 文字的原生圖顯示右側未開放島嶼相互遮擋。單一按鈕在地圖內，不代表九個按鈕彼此分開。固定設計座標先縮放，再把最後一欄夾回地圖，造成三組中／右欄點擊區重疊。

保留 44 個實體像素以上的操作面積，以地圖實際剩餘寬度安排三欄；島嶼底圖跟隨同一組標記中心。普通、懸停、按下、停用、焦點的內容邊距一致，避免一獲焦或滑鼠移入便變大。短標籤沿用像素字型及使用者文字倍率，不靠縮小至不可讀來湊版面。

地圖的用途是挑選目的地與了解目標。站點保留完整既有目標，完整操作仍在設施入口與可重看的教學。未開放島嶼保留名稱、主題、目前／門檻、尚差資格及收藏不消耗，移除重複邀請長句。選取不能因長文把地圖或返回鈕擠出畫面，也不能傳送或改動入園資格。

## 本輪實讀來源

- [NN/g：Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)：讀主要／次要資訊的區分與可見入口，避免以三層以上選單藏資訊。採用地圖先講目的地與目標、入口再講操作；沒有聲稱玩家已做偏好測試。
- [NN/g：Tabs, Used Right](https://www.nngroup.com/articles/tabs-used-right/)：讀少量清楚分類、選取指示，以及需要同時比較的資訊不應拆成來回切頁。地圖與目的地情報保持並排，不再為這個缺陷新增頁籤。
- 全套遊園 UI 的十方研究及已保存官方遊戲圖例沿用 [UI survey](ui-quality-survey.md) 與 ART-20；本輪沒有把搜尋摘要、未能載入的 Sea of Stars 行動版頁面，記成新圖片或動畫研究。

## 可重播的檢查

1. 先保留舊版三尺寸圖、九標記矩形及重疊反例。使用同一隔離資料，不改原目標／門檻。
2. 核對每個標記在畫布內、保留陰影空間，且所有標記相互分開。量測字型的真正文字寬度與樣式內容邊距。
3. 逐一選取九個未開放島嶼與十二個站點，再核對完整情報、地圖和固定返回。只測初始短說明會漏掉長操作描述導致的高度增加。
4. 原生 Tab／Enter 和滑鼠逐一操作；重看懸停、按下與焦點狀態。正常版面不代表獲焦後仍相同。
5. 同時保存全視窗證據與內容 viewport 尺寸；800×600 的內容可能是 800×450，不能把後者說成完整 client window。錄影也須核對擷取範圍，裁掉視窗的版本拒收。

測試使用隔離存檔，原生流程是派送真實輸入，不是真人試玩。UI 合成收藏與練習結果只驗畫面／返回；真正取得與冷重開由 ART-20 同輪照片流程證明。資料檢查與 Dummy 音訊不證明試聽。
