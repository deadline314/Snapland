# 島郵局與航海旅券 UI 改造定稿

## 設計方向

以「島郵局／航海旅券」作介面識別：一張航海旅券串聯所在區域、當前遊園任務與收藏；地圖、拍貼本、衣櫃和時段以郵戳／目的地條目分類。底色使用暖紙白，正文和主控件使用深墨藍／深青，珊瑚只標示當前上下文、需要留意的狀態，青綠作次要導航，金色只表示已完成或收藏。保留既有六色作語意色，不增加紋理、邊框、印章的數量；只在旅券頁籤、分區標題及空白狀態使用少量港口圖例。

不改任何遊戲進度、儲存 key、快捷鍵或互動回呼。現有功能留在原有 panel；只改視覺層級、入口組織及可讀性。主要常用按鈕高度至少 44 px，正文使用 20 px；補充內容至少 16 px。卡片以文字、標題、狀態三層呈現，分區有固定 16 px 內距及 24 px 間隔，按鈕間距 8 px；裝飾不能擠壓內容。

## 主 HUD

- 左上只顯示區域名／時段、普通與小惡魔收藏數，以及一條當前任務或最近互動狀態。常駐行動只有最近互動（靠近可互動點時顯示動作與物件名）。
- 右上以一個「航海旅券」按鈕取代七個並列按鈕。保留鍵盤 T 時段、C 衣櫃、P 拍照、F 招呼、E 最近互動與 Esc 暫停；入口收納不移除原快捷鍵。
- 底部長串 hint 改為情境提示：平時只留「E 互動：{最近互動名稱}」；附近無互動時隱藏提示。方向移動、招呼、拍照、衣櫃和時段留在旅券「操作」頁籤，需要時可重看。
- 任務文字不再總常駐；只有進行中任務顯示一行摘要和步驟數，完整資訊由旅券任務頁查看。

## 航海旅券分類

| 分類 | 既有頁面與行為 |
|---|---|
| 探索 | 地圖、任務；沿用現有區域／任務資料及回呼。 |
| 留念 | 拍貼本、成就；收藏縮圖優先載入既有照片 texture，缺圖以清楚的郵票空狀態表示。 |
| 整裝 | 衣櫃與服飾店；維持外觀草稿／購買／穿戴的既有確認行為。 |
| 遊園安排 | 時段、設定與輔助；說明時間選擇與輔助實際改變。 |
| 操作 | 移動／最近互動／衣櫃／時段／招呼／拍照／暫停快捷鍵清單。 |

所有入口仍呼叫原本 `_show_*` 函式；航海旅券只是新增一層可見的分類導航。面板均維持鍵盤焦點、滑鼠操作、Esc／返回路徑與資料空狀態。

## 面板層級

| 介面 | 定稿改動 |
|---|---|
| 對話 | 說話者肖像與姓名作一組身份卡；對話正文獨立大字紙卡；固定「繼續／略過這段對話」操作列與頁數，不讓肖像裝飾競爭文字。 |
| 任務清單／任務內容 | 每任務一張卡：標題、已完成步驟、下一步；內容頁採單一問題、選項一項一列、成功／錯誤回饋靠近選項，保留互動舞台實際行為。 |
| 成就 | 分組為小遊戲初見、迎賓全收集、四時紀念；每列以已完成勾章／未完成輪廓加狀態文字呈現，保留現有成就 ID 和文字。 |
| 拍貼本 | 現有三欄縮圖卡片優先；卡上以圖片、名稱、取得狀態為主，拍攝來源／重拍提示移至次級文字；維持 18 張普通卡與四時卡的現有計數規則。 |
| 地圖 | 旅券方向圖作頁首，區域分卡列門檻／開放狀態；尚未實作區明確標示「準備中」，不畫成已可進入。 |
| 設定 | 音量與文字速度歸「聲音／閱讀」群組；輔助、降低動態、全螢幕歸「遊玩方式／顯示」群組；滑桿列有 20 px 標籤、當前值可辨，選項說明獨立。設定 key 和 `Progress.set_setting` 保持不變。 |
| 時段 | 維持 `TimePanel` 的時段切換和收集 callback；透過 main 通用面板提供新的紙張與內距。只允許於目前受支援地點收集的規則要在行動按鈕旁清楚說明。 |
| 暫停 | 「繼續」為唯一強調主操作；旅券、收藏、衣櫃、設定次層分組；離開在分隔後並維持保存回呼。 |
| 商店／衣櫃 | 左欄預覽、右欄選擇和動作分明；免費外觀、收藏衣櫃、服飾店使用一致頁籤；商品列呈現實際縮圖（資源存在時）、名稱、價格／已擁有／穿著中狀態；購買、穿戴、套用和取消保留原回呼。 |
| 迎賓介紹 | 以「入園票」引言卡呈現短段落，主要行動「下船，去看看」突出，略過導覽為次要按鈕。 |
| 小遊戲入口／遊戲 HUD／教學 | 本輪只重整入口層級與接線：入口分開「圖解教學、練習操作、開始遊玩、輔助挑戰」；圖解教學可從入園票、遊戲入口或局中 Help 重看。局中打開教學時 round 暫停，關閉後留在暫停狀態。練習回合顯示 score summary，但不得保存分數、拍貼、任務或成就；遊戲內 HUD 視覺另由 ART-21 實作。 |

## 實施與驗證順序

1. 改 `Paper` 共用 tokens：正文預設 20 px、常用按鈕 44 px、低陰影、紙白卡／深墨強調、清楚 focus 外框；補充可複用的卡片、分區標題樣式。
2. 在 `main.gd` 把 HUD 改成區域／時段、收藏、任務／上下文加單一旅券入口；新增分類導覽但讓舊 `_show_*` 行為和鍵位直達不變；逐頁套用卡片、分組、20 px 正文與操作層級。
3. 在 `wardrobe_panel.gd` 整理預覽、帳本、選擇清單和動作列；每項操作仍經既有 draft、Progress 購買和穿戴 API，不改經濟或服裝資產。
4. 更新／補充 `test_integration.gd` 及 `test_wardrobe_ui.gd`，檢查旅券分類會導向原頁、快捷鍵仍觸發、收藏固定數和任務行為不變、衣櫃預覽／購買／穿戴結果保持，且 800×600、1280×720 常用操作不裁切。再跑 Godot headless integration、wardrobe UI 和 tutorial panel checks；GPU 截圖留給根任務按票驗收。

## 本輪落地

- HUD 以區域／時段與收藏計數為主，增加單一「航海旅券」入口與依最近互動顯示的底部操作；原有 C、T、P、F、E、Esc 和新增的 M 入口仍可用。旅券把地圖、任務、收藏、衣櫃、時段與設定分類收納。
- 對話、任務、地圖、收藏、成就、設定、衣櫃和結果頁採相同紙卡／標題／狀態節奏，內文至少 18 px、次要內容至少 16 px、按鈕最小高度 44 px。縮圖只使用已保存照片或實際服飾／角色 sprite。
- 衣櫃保留草稿、購買與穿戴流程，增加清楚狀態及服飾 sprite 縮圖。票票角色肖像取角色動畫庫中的 authored ticket/front idle frame，不另外繪製通用帽子或臉。
- TutorialPanel 的 start／skip／practice／close 意圖已接到主流程；缺少正式截圖時仍使用教學面板的文字 fallback。本輪只驗證面板資料與流程，沒有宣稱截圖完成。
- 練習結果展示真實 `score_summary` 明細，不進照片、幣、任務、成就的正式存檔流程。
