# 糖果工廠往返與材料探索

MAIN-26 接續已批准的十區設計及完整遊戲交付順序，開放第三區「糖果工廠」。本票交付旅行、可走世界、溫度觀察與如實選單；拉糖橋等十二款基本遊戲另逐款交付，不發放虛構收藏。

## 決策

使用者於 2026-11-17 授權自主選擇、開票與連續交付。可選擇只增加第二區變體、先完成第三區整批十二款，或以區域接縫加獨立新玩法逐票交付。本輪採第三項：既定下一款拉糖橋以材料形變與承重建立不同操作，第三區先提供正確世界／保存邊界，再接入真實玩法。代價是兩票之間會短暫顯示尚未開放的當地遊戲；不把材料觀察當遊戲數量。

## 玩家流程與安全

- 迎賓的糖果工廠路口以全島六張不同普通拍貼開放，與設計資料一致。顯示差額、不消耗收藏或金幣。其他未交付區域仍準備中。
- 工廠由主輸送廊、材料工作台、糖漿管道及泡泡停靠台構成；與港口使用不同輪廓及色彩。主路連通，所有互動點在可走區，邊界有護欄／安全約束；入口與重置點固定，永遠免費返回迎賓。
- 2026-11-27（ART-49）整建為大島東側的一個街區：四塊地坪是粉彩磁磚的主廊、材料實驗區、管道廊與泡泡停靠區，管道廊與泡泡停靠區之間隔著糖漿運河，由一座威化餅橋相連（新增的可走範圍）。北側是廠房立面，西側是倉儲場與包裝廠房，東側是糖漿河，南側是通往迎賓大道的小徑；外緣一律是偏粉的草地與糖果樹，不留懸空邊或單色底，之後接上大島時直接延伸。兩條輸送帶、餅乾壓模機、扭蛋機、銅鍋、運河水車與試吃機都在可走範圍之外或邊上；試吃機與扭蛋機會對走近的玩家產生反應，不計分、不存檔。
- 溫度觀察台循環冷／溫／熱三態，顯示黏度／形狀差異與短說明，暫停或降低動態時仍可辨識。只更新既有展示節點，不在每幀配置材質或無限制增加節點；不存溫度、不授卡或錢。
- 地圖依真實地形與互動位置繪製；圖例說明入口、觀察台與工作台。尚未開放的十二款以資訊說明，不建立假遊戲入口或假結算。

## 既有資料與生命週期

沿用 Progress 的 current_region 欄位，加入 candy，不改存檔版本；舊檔缺欄位仍回 welcome，錯誤型別／未知地區警告並回 welcome，其他資料及未知欄位往返保留。

旅行先驗證地區、門檻與目前狀態，保存成功才釋放舊世界。保存失敗保留原世界、鏡頭、人物及資料；換區阻擋重入，舊世界事件不得觸發新世界操作。穩態只保留一個世界，三區任意次數切換皆如此。正在遊戲、對話或拍攝時不旅行。

工廠繼承既有 ParkWorld 的人物、鏡頭、接地與設定，僅覆寫園區幾何、活動、出生、地面與邊界接縫；不先建立迎賓再刪掉。沒有迎賓 NPC、任務地標、海岸玩具或遊樂設施控制器。沒有噴泉／海面等選用節點時，日夜與設定須安全運作。

Main 啟動與重置依保存地區建立世界；序章只在迎賓初次啟動或明確重播。返回迎賓站在糖果路口附近，不保存任意座標。所有世界切換重新套用外觀、全島時段、文字縮放、降低動態與既有故事快照。

HUD、暫停、旅券、成就、任務與收藏冊如實顯示目前園區。工廠沒有當地卡／任務時顯示空狀態，仍可查閱及重看迎賓、碼頭既有收藏與原圖，不清除任何進度。當地尚未有遊戲時不得把迎賓指南冒充工廠內容。音樂只使用現有有效情境，沒有新增未授權素材或假稱試聽驗收。

必要 Hover 僅說明六張門檻、不消耗、溫度不影響進度、免費返回或重置；不向玩家展示實作名稱。

## 世界接口

新增 `game/world/candy_world.gd`，沿用 HarborWorld 既有繼承接縫。提供 `cycle_temperature()`、`temperature_label() -> String`、`reset_to_entry() -> bool`、`map_snapshot() -> Dictionary`。

地圖快照只含值：bounds（Rect2）、land（Rect2 列表）、points（id／label／position）、player（Vector3）、temperature（0–2）、region（candy），不持有世界節點。互動 ID 僅用 `region:welcome`、`candy:temperature`、`candy:reset`、`candy:info:*`。拉糖橋交付前沒有 game-025 互動。

## 驗證與公開範圍

受影響局部包含三區存檔往返／保存失敗、六張門檻、世界節點釋放與舊事件隔離、地形／地圖／固定重置、溫度三態、選單空狀態，以及原迎賓／碼頭旅行與收藏。保留原有測試斷言，新增第三區案例，不把雙區回歸改弱。

原生 800×600（1.25 文字／降低動態）、1280×720、1920×1080 檢查入場、觀察、地圖、返回及重開。隔離包從空工作目錄重做往返，所有程序提供獨立絕對存檔路徑並使用 run_validated_godot；不描述為真人試玩或試聽。完成後可玩遊戲數仍為二十四款，糖果遊戲尚待後續獨立交付。

碼頭十二款全部交付後，既有地圖把十二個玩法入口放在固定橫列，導致內容最小寬度超出小視窗。MAIN-27 依[既有免捲動要求](pixel-ui-redesign.md)將地圖與遊戲入口分成兩個清楚頁面：地圖底列只保留「遊戲入口」及返回；入口頁以完整展開的原生格狀按鈕呈現全部已開放遊戲，維持原名稱與回呼，返回操作固定。三種尺寸逐一驗證全部地點及十二款入口，不用新增長捲動區或縮小文字掩蓋溢出。此修正不混入 MAIN-26 的第三區交付。

MAIN-27 原生回歸也確認迎賓地圖原有 600 寬地圖加 280 寬情報欄，在真實 800 視窗切掉情報與返回；與同票的小視窗地圖目標一併修正。窄視窗使用上下配置，保留寬地圖、全部十二站／九園區的實際目標與完整情報；寬視窗維持並排。即時調整視窗須更新配置，不縮小字體或命中區、不隱藏原有內容，所有目標互不重疊。返回文案必須對應實際目的地。
