# 浪間小艇與第一張碼頭拍貼

SG-28 交付第十三款真正可玩的獨立遊戲，不增加其餘未實作遊戲的可領獎識別碼。依既有目錄：划槳、轉舵並側滑靠岸，載三箱到兩座浮碼頭；逆浪近路與防波堤長路有不同浪推，潮位改變可航缺口。同路線的不同槳時機必須真的改變靠岸角度。呈現為三維低俯小艇，不複用氣球投遞規則。

## 可操作規則

以確定性純模型處理船首方向、角速度、線速度、船體前向與橫向速度、槳衝量、舵、側滑、浪力、遮蔽與碰撞。使用有限、非負且有上限的時間步進／子步；無系統時間亂數、每幀歷史或直接設置目的地。放手保留慣性；同樣輸入可重現結果。三箱各有身份與目的地，必須實際拿取、運輸、以合理速度及角度停靠兩個可辨識的碼頭。不可重複交同一箱。邊界、碰撞或潮位變化不可永久卡船或遺失貨物。

起點空船與待拿貨箱不得重疊，仍在一次拿取範圍內；畫面必須如實反映未拿／已載狀態，不能靠移動畫面上的箱子掩飾與規則不同的位置。

W／上：划槳，S／下：反向槳減速，A、D／左右：持續轉舵，Q、E：左右側滑，空白鍵：拿取／交貨；畫面按鈕與鍵盤走相同命令。槳與側滑是離散操作，拒絕鍵盤重複事件；舵可持續按住。明示目前貨箱、碼頭編號、浪峰時間、航向與靠岸速度／角度，以及操作失敗原因；顏色之外有文字／圖形，靜音仍可理解。簡單船員只在玩家划槳命令時划槳，單人能完成全部內容。

正常回合自然結束（送完三箱或時間到）均有普通卡資格，成功仍只表示三箱真正送達；練習與中途取消沒有資格。小惡魔為完成運箱且曾在浪峰中側滑靠岸、全程沒有撞箱；不要擅自改成全程不得碰任何牆。輔助降低浪推、放寬靠岸並適度吸附，不能停用小惡魔資格。固定回合時間、具體幾何與物理常數由模型集中定義並記錄；不藉由放寬到自動完成製造通過證據。

## 最小擴充邊界

新增輕量 GameCatalog：只讀取明確列出的 welcome／harbor 執行資料，驗證列與身份，快取資料並回傳副本，不載入 Session、介面、模型或腳本。零參數仍為原迎賓十二款；碼頭只有實作的 013。全域 game-013 對應區域 harbor、第 1 格、photo-harbor-game-1、photo-harbor-devil-1、ACH_GAME_013；錢幣收據仍是 game-013。014 等未交付項目一律拒絕。

Progress 沿用既有圖片驗證與保存方式，提供一般化拍照附檔並保留迎賓入口相容性。取卡、一次 40 金幣、收據與成就在單次保存成功後才發訊號，失敗完整復原並讓結算能如實提示未保存。舊有卡無收據不補發錢；重播不重複發放。迎賓全區成就仍要求當地十二款，不讓碼頭一格誤解鎖。教程與收據只接受已交付目錄項目；不得將全部規劃 IDs 都開放。

Session 新增只給新玩法使用的小型 driver 路徑，保留原十二款，避免再把每個玩法分支撒進所有方法。Driver 擁有模型、快照與可選 Control view；reset、create_view、handle_input、clear_input、step、snapshot、present、score_summary 即足夠。模型為唯一時鐘；Session 在既有通用計時／逾時前處理 driver。暫停、失焦、教學、離開清掉持續輸入，凍結模型及呈現，恢復不吃長時間差。只完成一次、無重複 view／訊號。降低動態只減非必要裝飾，不隱藏物理訊息。無頭執行可不建立 SubViewport。

View 使用既有原生三維小場景、低俯攝影機與 HUD；不載入第二座園區，不加入依賴，不拆解或伸縮人物原畫。船、槳、箱與碼頭可用簡單實體幾何；既有角色若使用，必須完整來源貼圖。模型只輸出資料，view 不模擬第二次。

新 driver 的即時操作回饋由其 view 顯示一次；共用 HUD 保留標題、目標、進度、時間、分數與選單，不再疊放另一份相同回饋浮窗。這避免原有浮窗遮住水面狀態；舊十二款的回饋位置不變。

## 所有玩家入口

碼頭實際遊戲亭與地圖可進入 013；其他十一款仍清楚準備中。Main 查找全域已交付記錄，但迎賓清單仍維持十二款。結算以 ordinary_eligible 判斷取卡，舊十二款缺此欄時保留原 success 判定；任務成功事件仍依真實 success，不把失敗報成完成。圖片來自真正本局畫面；取卡／附檔保存失敗有明確結果且可重試。

收藏按區域切換並顯示碼頭第一格／原圖；迎賓六個非遊戲來源不漏到碼頭。成就按全域遊戲 ID，不能用區域清單索引猜編號。每區配額仍為普通 18／小惡魔 12。013 的首次教學、說明與練習使用既有流程，補上真實原生 PNG 教學圖與精簡操作提示。

## 驗證與界限

局部測試涵蓋資料邊界、舊存檔、原子保存回復、重播、圖片、教學、成功／逾時／練習／取消、正常與輔助小惡魔、不同槳時機、浪推／遮蔽／潮位／碰撞、持續輸入釋放與 pause。完整 CI 登記所有新增 suite，不能跳過原十二款。

原生驗證用公開命令與快照回饋操作，不能傳送船、設分或直接設定結束；可明確標記隔離測試檔預置六張迎賓卡以進碼頭。保留標準與輔助真實送貨路徑、失敗取普通卡、重播／重開與原圖；三種視窗 800×600、1280×720、1920×1080，至少一組 1.25 文字／降低動態；獨立資源包與 Windows 成品實測。自動操作不稱真人試玩或人耳試聽。

後續逐票完成其餘 115 款與園區／劇情；既定全遊戲免費補拍政策另以共用功能票完成，不能把本票或目前十三款當整個遊戲完成。

## 定稿決策與代價

- 輕量資料目錄與新玩法 driver 路徑共存，保留迎賓十二款的成熟實作；代價是暫時維護兩條生命週期，避免一次遷移破壞既有操作。
- 013 使用自然結算的 ordinary_eligible，舊十二款保留原有 success 回退；全體參與取卡與補拍接續 SG-29，不能把此過渡當成全遊戲規則已齊。
- 獎勵、一次 40 金幣收據、成就與平台待同步佇列同次保存；成功後訊號抑制重複保存。縮圖／原圖沿用限額與回復，失敗明示重試，不偽造成功。
- 同一局照片保存重試帶著僅存記憶體的劇情已通知狀態，成功劇情只通知一次；真正重玩仍是新回合。代價是未保存結果須在本次結果視窗重試，不宣稱當機後仍能回復未寫入資料。
- 數位操作驗收只用玩家可用的槳／側滑 ±1、舵 -1／0／+1 與時機；模型容許的連續強度不作特權通關。模型是唯一時鐘，單幀上限與子步防止長時間差穿牆；極低更新時捨棄過量追趕，以穩定優先。
- 空船起點與第一箱相距 0.9，保留拿取範圍與全部規則；更動一個模型常數與對應測試，而非把畫面中的箱子畫在假位置。
- 即時回饋由 driver view 顯示一次，共用 HUD 提供實際上緣空間；新畫面維持等比且指標依真正轉換計算。代價是後續採此路徑的 view 必須遵守相同回饋與預留空間契約。
- 相簿以選定園區的正式目錄為準，保留舊 setup 參數位置；不再讓自訂傳入子集合覆蓋正式區域內容。印章以全域身份查找，碼頭第一款是 013。
- 地圖沿用原圖與標記，加入查看玩法入口，實際園區位置不變。測試入園的六張舊卡明示為合成前置，新 013 卡透過真實輸入取得；所有程式化操作均不稱真人樂趣或人耳驗收。
- 新目錄依賴同步納入舊存檔隔離測試的最小複製專案與精確清理；無頭音樂測試在 Session 開始後借入已就緒畫面、結束前歸還外部擁有者。保留全部路徑保護、實際指標同步與原生建立測試，不改正式程式來遷就舊測試生命週期。
- Windows 發行執行檔未執行外掛的測試啟動腳本，因此以實際鍵鼠確認入口、拿箱、划槳、暫停、重開、教學與取消，另用獨立資源包完成全回合及原圖重讀。兩者分別記錄，不把執行檔的腳本逾時當成通過，也不為測試加入正式遊戲自動操作開關。
