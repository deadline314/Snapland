# 主角 2D 光頭與部件樣本實作計畫

**Goal:** 保留原本主角的 2D 像素畫風、臉與比例，完成光頭底圖、八方向髮帽／配件、兩種輪廓外套及相機，實際檢視正常與慢放的換裝、走路起停與轉身。

**Architecture:** 原有 2D 動作圖作為姿勢與身份基準。imagegen 只製作缺少的完整光頭與獨立部件原件；經逐格檢查後，以固定畫布、明確頭部／手部錨點及作者分層規則組合。執行端只有同一個 2D 姿勢狀態，根位置由碰撞後實際位移推進；不存在人物 3D 模型或 3D 烘焙來源。

**Tech Stack:** built-in imagegen、透明 PNG、手動可編修的 JSON 分層／錨點資料、Python 圖格與契約檢查、Godot 4.7.2 的 Node2D／Sprite2D 原生樣本。

**Spec:** [使用者批准的 2D 決策](character-production-pipeline-v2.md) 第一節；[ART-29](../../pm/Snapland-art/[ART-29]製作主角完整換裝動作樣本.md)。2026-10-16 使用者再次明確指示照此實作；本輪直接執行已批准工作，不重複詢問是否繼續。

## 固定限制與檢視重點

- 原圖的臉、比例、配色、相機、背包、手腳與像素細節是基準；不可改畫風，不能用立體模型替代。
- 每張生成圖先看身份、透明度與完整頭皮，再談綁定；來源原圖、提示詞、生成原件與雜湊都保留，不覆寫舊素材。
- 生成不保證對齊。不同方向、低頭握機、抬手遮擋與每格頭部移動都有明確作者資料；不依頭髮／皮膚 RGB 在執行時切頭或補頭皮。
- 髮帽共用身體姿勢與相位；衣服有不同輪廓，不能待機外套、走路背心。缺格要診斷並顯示完整保底。
- 不改既有髒工作樹的舊合成器。先做獨立 2D 主角樣本，保留被拒收的 3D 候選紀錄，不能採用其人物素材。
- 每次原生測試／錄影經安全啟動器、使用絕對隔離 SNAPLAND_SAVE_PATH；一個 GPU 工作一次。正常、四分之一真實模擬速度、逐姿勢全身與普通包啟動分開記錄。

獨立樣本已輸出為 `build/hero-2d-sample-release/Snapland-Hero-2D-Sample.exe`；預設主畫面啟動擷取 30 格，未指定來源場景。方向鍵／WASD 移動、Space 舉機拍照，畫面按鈕切換髮型／帽／外套／速度／暫停。沒有正式島嶼的存檔或自動載入。
