# 降低通用生成感：Snapland 素材提示與審稿

2026-10-11 使用者指出目前生成圖「有點太 AI」。這是本批 ART-3～6 的美術修正，沒有改動玩法範圍。

## 實際讀到的來源

- [OpenAI 圖像提示指南](https://developers.openai.com/api/docs/guides/image-prompting)：先定義需要的圖，再描述主體、構圖、風格與限制；編輯時寫明改變項目與保留項目，一次調整一件事並看成圖。
- [Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)：短而明確、具體數量與詞彙、描述想看到的東西；缺少必要描述會讓模型填入預設風格。不是把所有限制都省掉。
- [Adobe Firefly 官方指南](https://community.adobe.com/p/firefly-image-guide)：保持描述一致、聚焦並逐次修正；實際查看的平面海岸例子用清楚色面、圖形陰影與克制配色。不是所有美術都應改成平面。
- [cure：The Pixel Art Tutorial](https://pixeljoint.com/forum/forum_posts.asp?TID=11299)：相連像素群形成有意義的形狀；大量孤立像素與隨機抖色會產生噪點，小色盤有助作品一致性。這是像素畫設計原則，不是生成模型必定遵守的保證。
- [Midjourney Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize)：較低 stylize 更貼近描述、較少額外發揮。這個參數只屬該工具；本批內建圖片工具沒有套用 `--s` 或 `--raw`。

## 對本批素材的判斷

舊圖每片葉子都有細碎高光，樹、花盆、路燈都密集装飾；這是看過圖片後的判斷，並非上述來源證明「這些詞一定導致 AI 感」。修正重點是細節的用途與視覺秩序：大形先清楚，小形集中於輪廓、葉群、操作目標與必要識別特徵。

海港青綠、珊瑚、奶油色與墨藍繼續共享。世界植物採像素群；小遊戲以較平整的印刷色面呈現，角色保持同一身分。木紋只用於木、磨損只在腳邊或常用邊緣。留出玩法空間，不用裝飾填滿它。

## 可重用提示格式

```text
用途：遊園中的植物 sprite，正面完整物件，透明背景。
主體：海港橡樹，偏心樹幹、三大葉冠群。
畫法：清楚方形像素群，輪廓先讀得懂，每種材質三個色階。
配色：墨藍、海青綠、苔綠、木棕、少量奶油高光。
細節：少量葉群分界與樹幹分叉，大部分色面保持安靜。
編輯時保留：物件功能、完整根部、原有排列與空白間隔。
移除：均勻顆粒、逐葉高光、無用途的金屬花紋。
```

先做一組小素材看效果，再讓其他素材共享已確認的色面與細節密度。不使用現有遊戲、畫師名稱或第三方圖像作生成輸入。實際提交的完整英文提示、圖片雜湊與成圖檢查存於素材來源紀錄。

## 審稿

提示中的像素尺寸、色數是目標，必須看成圖與遊戲縮放結果，不能宣称文字本身強制了網格或色盤。比較舊／新圖的輪廓、葉群、材質、透明邊緣；再確認原生遊戲中的大小、陰影與操作可讀性。風格改善不等於完成玩家喜好或專業美術評審。
