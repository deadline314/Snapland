# 換髮後的手持相機前景

2026-11-12，ART-18。長捲髮在斜向步行及待機時覆蓋原圖的相機、手掌；只保護臉孔不足以維持道具前後順序。

## 責任與失敗行為

`AvatarPropForeground` 讀取來源綁定的半開像素區段，核對完整原始 RGBA 的 SHA-256 後才提供索引。正式播放不推斷顏色、肢體或相機位置。資料限制為 2 MiB、256 個來源、每個來源最多 4096 段；座標必須為有限整數、在 280×360 內、順序正確且無重疊。任一格式錯誤拒收整份資料；未知或改變的來源不借用其他姿勢。

合成先完成膚色、衣料，再換髮；以該次已選膚色／服裝的原圖恢復相機和手掌，帽子繼續維持原有上層。既有拍照動作的明確前景仍獨立保留。需要前景卻缺少有效資料時，換髮退回完整原髮，不能先刪髮再發現缺件。

髮尾骨架也使用同一來源索引形成固定附件保護區，讓相機、手掌不參與髮尾變形。前景快取最多 16 組 `PackedInt32Array`；目前最大一組 2425 像素，索引有效負載上限 155200 bytes，未包含容器及既有角色貼圖。角色貼圖、髮尾及衣料各自既有快取上限不變。

## 製作與複核

`tools/island_avatar/build_prop_foreground.gd` 是離線製作工具。五個方向的明確相機範圍排除另一側背包；色彩分區只在製作時協助標記，輸出仍須原生檢視。64 個走路／待機請求對應 55 張不同原圖，沒有新增人物原畫或改變原動作時序。相機隨手臂在側向步態內移動，測試使用逐格原圖的獨立鏡頭檢查點，不假設道具永遠固定同一座標。

直接執行工具預設只核對；`-- --write` 才重建。來源像素變更會使預設核對失敗，須重新檢視才能接受新輸出。舊候選誤選鞋子或背包的診斷及反例附票，皆不作最終結果。

原生姿勢對照使用獨立 `World2D` 的 SubViewport，以 1:1 畫布每頁 16 格繪製，等待完整後續繪製並檢查每格非背景內容；避免預覽取樣自身造成空白。每頁釋放前一頁控制項，不累積所有畫布。

## 驗證範圍

- 原生姿勢矩陣：每套 172 個既有合成請求、三套代表外觀共 516 格。148 格來自實際動作／八方向行走與待機，另 24 個舊慶祝 API 請求共用原正面靜態圖，不能當新動畫。
- 正式世界的慶祝實際沿用八格 `jump/front`。正常及四分之一速度以真實按鍵行走、招呼、拍照；互動、慶祝事件與外觀為明確測試資料。走路及動作中換裝，影格、時鐘、步距相位、根位置、方向即時相同。
- 128 組換髮合成、獨立相機／手掌檢查點、64 個附件保護區、改圖拒收、十類壞資料與快取上限；既有完整 172 格衣料及角色外觀回歸。
- 空目錄啟動 PCK，確定沒有原始 PNG 可供散落檔案回退；96 組髮型／方向／帽子 GPU 像素比較，另 200 格逐姿勢靜止比較，含可見髮尾運動、停下精確回原圖、暫停與故意一像素位移反例。
- Windows 獨立成品含內嵌 PCK，隔離啟動與原生 Forward+ 十二入口初始繪製。固定錄影節拍與 Dummy 音訊不代表硬體性能、真人遊玩或試聽。

證據附 ART-18。完整新角色動作原畫與動畫自然度仍按 ART-16、ART-17 各自驗收；此處驗證分層在實際來源與安全回退上的同步，不將舊別名算成額外動作。
