# 長椅換位：小型座位邏輯桌

## 遊戲方向

長椅換位使用穩定的 3/4 近距離桌面視角。六位朋友是明確放在木桌微縮底座上的全身立繪立牌；底座上的色點也和朋友姓名牌相符。這是座位桌上的人物棋子，不暗示新增 NPC 坐姿動畫。桌面有厚木邊、木紋、黃銅嵌線、帶弧腿的軟墊長椅，單一窗框露出海平線並由布簾收邊。四個時段改變桌木、窗景和紙色的光感。使用者每次選兩席，交換座位上的朋友。點擊與方向鍵加 Enter 都走同一個選席輸入。海星、貝殼等圖形符號與姓名牌並用；規則以兩欄呈現，分得出朋友相鄰、朋友至少隔一席、窗位和指定座號。

這個近桌面構圖讓玩家先看人際關係，再看位置規則。它採單排座序，透過一個窗位、朋友相鄰和朋友分開坐的條件形成三個逐步增加的排列問題。三桌開始時都違反至少一項明示規則；逐桌加入「兩人分開坐」與指定座位，條件從兩項增至四項。第 1、2、3 桌的規則最短交換數分別是 1、2、3；每組最佳值都由有限六人排列空間的 BFS 求得。任何符合當桌明示規則的排列都能過關，沒有額外隱藏的固定座序。每桌交換額度是 3、4、5，容許玩家繞路；每次成功解題按實際交換數給分。解完三桌後，只有全程未輔助、未因用盡額度重排，而且每桌都恰達規則最短步數才得到全章標記。助手只圈出 BFS 找到的下一組有效交換，仍需玩家完成座位操作。

交換以角色完整身體貼圖抬起、沿弧線移動、落在對席；交換中的兩個底座都保留青綠描邊。減少動態效果時直接呈現交換後的座位，並保留被選取的席位和座號。標題、操作、規則、狀態與提示各有獨立且經測試的文字框，限制在 1280×720 的 y=130–640 安全區；頂端 130px 和底部 80px 留給共用 HUD。

## 遊戲與視覺差異

花壇水路是俯視管線格，主要問題是局部轉向如何連成一條路；迎賓大合奏以近景港灣樂器工作台呈現貝殼簧片、玻璃潮鈴、漂木音板與小港鼓，主要問題是記住音高與長短拍後回奏。長椅換位不使用格線、格磚或節拍軌道，而把六個人固定排成一列，讓交換動作直接改變關係。桌面提供能讀座位相鄰與間隔的淺景深；整個場景仍然保持靜止，因此不會把玩家的注意力拉向動態背景。這沿用 ART-21 調查中「依互動動詞選鏡頭、用不同空間形狀承載玩法」的原則，而不是借用參考作品的素材或場景。

## 交付介面

- `BenchSwapModel.reset(assisted, time_phase)`, `select_seat(index)`, `step(delta)`, `snapshot()` 管理三組有限排列、依可見規則計算的最短步數、寬於最佳值的普通交換額度、分數、輔助提示和逐次紀錄。`rules_satisfied(order, level_index)` 可檢查任何候選排列。
- `BenchSwapView.configure_avatar(appearance, equipped)`, `update_frame(snapshot, time_phase, reduced_motion)` 管理角色貼圖和手繪桌景。`screen_to_design`, `playfield_rect`, `geometry_bounds`, `seat_geometry_bounds` 供尺寸與點擊座標查驗；`guest_visual_layout` 以桌景局部基準追蹤六位客人，交換中仍繪出未移動的四位與恰好兩位移動客人。`seat_requested(index)` 向共用根流程回報席位操作。
- 角色來自既有 `AvatarRenderer.texture(...)`，用有界快取後以完整 `280×360` 姿勢畫布縮放顯示；交換軌跡沿用同一局部腳底基準，起終點與靜止角色重合，完整身體留在安全遊戲區。六席顯示既有主角 renderer 的外觀變體，不是新增六名 NPC；既有主角素材包含生成圖，本票沒有另外生成六套人物動畫。

## Main 整合驗證證據

`game/tests/native_bench_swap_review.tscn` 是視窗環境中的 Main 整合檢查：透過園區 game-011 站牌的 E 互動與「開始遊玩」按鈕進入正式 Session，正式回合以座位按鍵解題，正式完成後再透過 HUD 的暫停與練習按鈕開啟輔助、減少動態效果的私人回合，改用指標點擊解題；檢查暫停時模型時間與 revision 凍結、確認重試的 `pressed` 回呼內模型已同步歸零、以及 `finished` 回呼捕獲的 Session instance ID、結果與模型快照一致。它分別在三桌、實際重試與結果狀態擷取 PNG，檢查每桌可見規則的 1／2／3 最少交換、275／250／225 分與總分 750；最終輸入使用匹配 instance ID 的同步結果與 ledger 快照，等待後不讀取已釋放的 Session，意外消失或逾時以失敗退出。並檢查首次正式完成前照片、成就、任務、貨幣、服裝與待送平台成就等既有進度欄位未變；正式全最短解完成後只驗證預期的 game-011 普通及惡魔收藏與成就。私人回合再次完成三桌後，照片、成就、任務、待送平台成就、貨幣、服裝、衣櫥獎勵紀錄及普通／惡魔收藏數都必須完全相同。Root 已實際觀看一般速度與慢速兩段 Main 正式流程影片；兩次都以座位輸入完成三桌最少交換解並得到 750 分，這是兩次原生正式流程驗收，不代表其他尚未驗收的操作組合。
