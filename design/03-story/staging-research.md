# 演出與主線：研究、現況與提案

2026-11-28。本文件延伸 [story.md](story.md) 的六人、四段主線與兩種結局，不改門檻、卡片分母或結局條件。研究來源標 **［讀］** 表示實際開過頁面，**［搜］** 表示只看過搜尋摘要。

## 現況：原生畫面逐段走過一次

用隔離存檔，以腳本依序觸發晚風號序章、上岸導覽、票票導覽、夜市與馬戲團迎賓、馬戲團委託、相簿與怪盜收尾，每句截一張 1280×720 原生畫面。這是腳本操作的畫面檢查，不是人工試玩。

| 段落 | 看到的畫面 | 平淡的地方 |
|---|---|---|
| 晚風號序章 | 固定一個俯角遠景；主角會扣背帶、舉相機、揮手 | 說話的阿浪不在畫面上；鏡頭從頭到尾沒動；「島上的燈像小星星」卻看不到島 |
| 上岸導覽 | 主角站在棧橋，票票在畫面上緣 | 票票用文字描述自己的長相，而不是走出來；小角喊「等等」時根本不在畫面裡 |
| 四區迎賓 | 大遠景，兩人站著不動，字幕板蓋住下三分之一 | 「鏡子裡的小角比我先鞠躬」只用講的；沒有停頓、沒有反應鏡頭 |
| 合照 | 直接切到近景、角色換姿勢，是目前最有感的一刻 | 前一句對話和快門之間沒有過場 |
| 委託 | 與迎賓同一個遠景 | 「倒影拿走領結」這種畫面笑點完全沒演 |
| 相簿重看 | 只重播字幕 | 沒有從照片「回到那一刻」的感覺 |
| 怪盜收尾 | 字幕「又被你抓到了」 | 怪盜本人不在畫面；與主線無關 |

共同問題：所有劇情都是同一個字幕板加一個遠景，角色不動、鏡頭不動，沒有停頓與反應；各區都提到「幕幕在籌備首演」，但除了口頭沒有任何看得見的主線線索。

## 採用的技巧

| 技巧 | 參考 | 為什麼適合 Snapland |
|---|---|---|
| 鏡頭只在畫面平面上滑動與推近 | Lost in Play 以卡通鏡頭效果代替台詞［讀 developer.apple.com/news/?id=n4w6zydm］ | 保持原有俯角，看板角色不會歪；推近就能讓兩人對話變成「雙人鏡頭」，還原時零風險 |
| 表情泡泡（！？…♪♥ 與汗滴） | 漫畫符號：汗滴表示尷尬，大汗滴留給笑點［搜 en.wikipedia.org/wiki/Manga_iconography］；動物森友會的反應泡泡［搜 animalcrossing.fandom.com/wiki/Reaction］ | 一眼可懂、不用讀字，也適合同機多人與小朋友 |
| 停頓、反應、再接笑點 | Jazzpunk 的笑點靠順序與時機［讀 gamedeveloper.com/design/exploring-what-it-takes-to-make-a-funny-game］ | 每段只加一個「靜止半秒→泡泡→台詞」的節拍，不拉長流程 |
| 無字默劇節拍 | 鵝作遊戲角色以轉頭對視與肢體笑點撐起戲［讀 vice.com 開發者訪談］；Lost in Play 無台詞 | 有些節拍不需要字幕：小角一個「！」比一行字好笑 |
| 角色在被拍時才擺姿勢 | TOEM：NPC 被看時反應，「好照片！」是刻意的假回饋［讀 gamedeveloper.com/production/postmortem-toem］ | 舉起相機就是演出開關，接上本作既有的合照近景 |
| 收藏背面是劇本頁 | Tunic 的手冊頁是收藏也是故事［搜 gameinformer.com］；Obra Dinn 的書同時是目錄與推理工具［搜 emshort.blog］ | 主線不用章節標題卡：線索寫在拍貼背面，只在相簿裡被翻到 |
| 三次目擊再揭曉 | 炸彈超人樂園 3 的怪盜要目擊三次才給一塊，園區員工其實是黑暗軍團［讀 ja.wikipedia.org/wiki/ボンバーマンランド3］ | 本作怪盜已是「抓三次」，直接把它接進主線，不新增系統 |
| 少即是多的無障礙 | Xbox 無障礙準則 117：鏡頭晃動、移動內容要能關［讀 learn.microsoft.com/…/117］ | 降低動態時鏡頭改為直接切換、泡泡不彈跳，但意思（誰在說、停頓）保留；每段都能略過 |

不採用：章節標題卡（使用者明確不要）；長篇過場或語音；只有高難度才看得到的劇情；把劇情鎖在異空間（異空間仍只強化遊戲，不當結局前置）。

## 演出工具組的範圍

對話每句可附一個小提示：鏡頭對準某個角色或兩人、推近倍率、某人頭上冒泡泡、說話者做一個既有動作、台詞出現前先停頓；也可以是沒有字幕的默劇節拍。全部可略過、降低動態安全、結束後鏡頭與角色完全還原。寫在劇情資料裡，作者不必改程式。

## 主線提案：「照片邊緣的人」

story.md 已寫好結尾：派對合照時幕幕緊張得站到鏡頭外，小角把他拉回畫面；首演用整本相冊當節目，最後的合照留下幕幕。這條線缺的是前面的伏筆。提案讓「總有人站在照片邊緣」成為全島的小謎團，最後由這兩張合照收束。

1. **線頭（迎賓大道）**：第一張主線合照的角落有一截披風。主角沒注意，只有相簿裡的拍貼背面寫著一行鉛筆字：「第一幕：客人上岸。燈要亮。」
2. **各區迎賓**：每張迎賓合照邊緣都有一點不屬於畫面的東西：手套、帽緣、一隻緊張的影子。拍貼背面各是一張劇本頁，寫著該區被借去當首演布景的東西（夜市的燈牌、玩具城的車站鈴、溫室的亮座位……都是各區台詞已經提到的）。
3. **怪盜**：怪盜是幕幕的「膽大版」。他不敢開口借道具，就戴面具去「借」氣球、帽子、魚和棒棒糖；三次被抓後還東西、留下面具。面具背面蓋著「道具組」的章。玩家可以猜，劇情不說破。
4. **幽幽旅館的幽靈**：幽靈不會出現在普通照片裡，是「照片裡少了人」的反向謎團。溫室迎賓說的「首演要留一個亮著的座位給晚到的人」，其實是留給他們的。
5. **異空間**：依 [異空間設計](../01-park/other-space.md)，是幕幕劇團借各區搭的排練場，看守演員要一張首演海報劇照。主線只多一層意思：劇團排練的正是那場「把整本相冊留在畫面裡」的首演，後台劇照頁的空白邊角也留著同一截披風。不收集也不影響兩種結局，只多知道一點幕後。
6. **普通結局（派對）**：員工合照時邊緣又出現那截披風，小角一把將幕幕拉進畫面：原來每張照片邊緣的人都是他。這是謎團揭曉，也是 story.md 原本寫好的笑點。
7. **可選終區（首演）**：相冊變成節目，借來的東西都回到台上當布景；劇場的相機拍得到幽靈，謝幕合照裡大家都在畫面中間，邊緣第一次是空的。

這條線只加線索與演出，不增加卡片、門檻或必做步驟；每段都能略過，重看從相簿進入。
