# [SG-15] 重做氣球快遞操控與風場

> 狀態：待辦

## 內文

### 需求
氣球快遞提供看得見、可預判的海風與陣風，讓玩家有明確操控、避險與投遞目標。以逐步引導和可讀回饋改善無聊、操控弱與不知如何完成的體驗。

### 來源
2026-10-11 使用者追加：建築遮擋時需要圓形穿透顯示主角；氣球快遞過於簡略、海風不可見、操控與引導弱。參考資料至少超過五個來源，跨不同方向比較並形成自己的設計。

### 驗收條件
- [ ] 查閱至少六個來源，涵蓋不同遊戲做法、操控、環境訊號、引導及玩家體驗；記錄採用理由。
- [ ] 風向、風力與陣風預告在畫面可辨識，視覺訊號與實際受力一致。
- [ ] 鍵盤與滑鼠各有直接且可理解的控制，玩家能主動減速、穩定投遞或避開障礙。
- [ ] 首次與重玩都有清楚目標、按鍵說明及逐步短引導，不在讀引導時消耗遊玩時間。
- [ ] 投遞過程有多段目標、清楚成功失敗回饋與可快速重試，普通及惡魔成就資格正確。
- [ ] 輔助與降低動態仍可完成，十一款其他遊戲無退化；原生驗證與打包檢查通過。

### 測試流程
1. 第一次從園區開始遊玩，按引導完成移動、減速與投遞。
2. 用鍵盤與滑鼠分別操作，觀察風場、陣風預告、避險與多段目標。
3. 普通、輔助、降低動態及重試後核對結算、收藏與成就，跑受影響局部測試。
