# [SG-102] 讓不操作的街機回合不得分

> 狀態：完成

## 內文

### 需求

街機式小遊戲放著完全不操作時，一回合必須是 0 分、沒有獎牌、不發拍貼。目前有幾款的規則會自己得分（走鋼索的小丑自己走、陀螺相撲的對手撞上來自己出場、露珠牽橋的葉子自己把露珠滾進花苞、接飛碟放過派也有分、蘑菇撐傘被冰雹打到也有分），遇到隨機事件剛好有利時偶爾會拿到銅牌，讓共用的街機檢查時好時壞。修正所有街機小遊戲，並加上一項固定種子的檢查，讓以後新增的遊戲也不會再出現。

### 來源

2026-11-28 主導的對話轉述：其他對話在乾淨的 main 上重現 game-066 與 game-068「放著不玩卻拿到牌」的檢查偶發失敗，要求所有街機小遊戲遵守「沒有輸入就沒有分數」。

### 驗收條件

- [x] 每一款已開放的街機小遊戲，放著不玩一整回合都是 0 分、沒有獎牌與拍貼。
- [x] 共用的街機檢查以固定的多組種子與不均勻的畫格時間，逐款驗證放著不玩為 0 分，結果每次相同。
- [x] 有在玩的回合計分不變：各款原有的金牌、銅牌與失敗演出檢查照常通過。
- [x] 新增街機小遊戲的準則寫明這條規則與對應的檢查。

### 測試流程

1. 每款小遊戲進場後不按任何鍵，等回合結束，確認 0 分、沒有獎牌。
2. 再正常玩一回合，確認得分與獎牌和修改前一樣。

# Commit-1

## 內文

有幾款街機小遊戲放著不玩也會得分：走鋼索的小丑自己往前走就一直加分，陀螺相撲的對手撞到停著的陀螺被彈出場也算你的，接飛碟沒疊盤子時放過派也有分，蘑菇撐傘停著不動被冰雹打到也有分；隨機事件剛好有利時偶爾會拿到銅牌，讓共用檢查時好時壞（露珠牽橋與藤蔓編織已由溫室那邊先修好）。
現在所有街機小遊戲共用「本回合玩家按過任何鍵」這件事：走鋼索要有人掌過平衡，小丑走路與走到對岸才算分；陀螺相撲只有你在操控時撞出去的對手才算你的；接飛碟頭上有疊盤子時放過派才有分；蘑菇撐傘被冰雹打到要你動過傘才算分。有在玩的回合計分方式不變。共用的街機檢查新增一項：每一款已開放的街機小遊戲都以 50 組固定種子、不均勻的畫格時間放著不玩一整回合，全部必須是 0 分、沒有獎牌與拍貼，結果每次相同；新增街機小遊戲的準則也寫上這條規則。
修改前以 40 組種子放著不玩：走鋼索最高 367 分（兩次拿到銅牌）、陀螺相撲 85、露珠牽橋 80、接飛碟 40、蘑菇撐傘 15；修改後 23 款全部 0 分。各款原有的規則檢查（金牌、銅牌、失敗演出）全部照常通過。
