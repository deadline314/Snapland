# [SG-102] 讓不操作的街機回合不得分

> 狀態：進行中

## 內文

### 需求

街機式小遊戲放著完全不操作時，一回合必須是 0 分、沒有獎牌、不發拍貼。目前有幾款的規則會自己得分（走鋼索的小丑自己走、陀螺相撲的對手撞上來自己出場、露珠牽橋的葉子自己把露珠滾進花苞、接飛碟放過派也有分、蘑菇撐傘被冰雹打到也有分），遇到隨機事件剛好有利時偶爾會拿到銅牌，讓共用的街機檢查時好時壞。修正所有街機小遊戲，並加上一項固定種子的檢查，讓以後新增的遊戲也不會再出現。

### 來源

2026-11-28 主導的對話轉述：其他對話在乾淨的 main 上重現 game-066 與 game-068「放著不玩卻拿到牌」的檢查偶發失敗，要求所有街機小遊戲遵守「沒有輸入就沒有分數」。

### 驗收條件

- [ ] 每一款已開放的街機小遊戲，放著不玩一整回合都是 0 分、沒有獎牌與拍貼。
- [ ] 共用的街機檢查以固定的多組種子與不均勻的畫格時間，逐款驗證放著不玩為 0 分，結果每次相同。
- [ ] 有在玩的回合計分不變：各款原有的金牌、銅牌與失敗演出檢查照常通過。
- [ ] 新增街機小遊戲的準則寫明這條規則與對應的檢查。

### 測試流程

1. 每款小遊戲進場後不按任何鍵，等回合結束，確認 0 分、沒有獎牌。
2. 再正常玩一回合，確認得分與獎牌和修改前一樣。
