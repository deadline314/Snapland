# [SG-19] 精修人潮指揮玩法與計分

> 狀態：完成

## 內文

### 需求
將人潮指揮提升為可對外展示的完整小遊戲。隊伍需求、路口風險和號誌效果可辨，讓玩家能計畫通行順序，而非只交替按鍵。操作手感、目標、分數和演出一起設計，學習內容放在有截圖的完整教學，遊玩時保留必要資訊。

2026-10-12 使用者追加：同一園區維持共同主題，每款小遊戲須依玩法選擇自己的 2D、2.5D、HD-2D 或 3D 表現。不能沿用同一場地、構圖與動畫再換規則；鏡頭、空間、操作節奏和成功演出須帶來可辨認的新體驗。

### 來源
2026-10-12（Asia/Taipei）使用者要求全面重新審閱 UI 和小遊戲，提升目標、計分及操作手感；先廣泛 survey，減少遊戲當下提示，提供含截圖的完整教學。使用者授權自行決定設計，強調循序完善、細節有主次且不雜亂，以可面向大眾的品質驗收。

### 驗收條件
- [x] 依玩法採用獨立鏡頭、場地、視覺節奏與成功演出；與首區其他遊戲並列比較能辨認不同體驗，海港主題仍一致。
- [x] 比較至少六個跨不同方向的玩法、操控與玩家體驗來源，保存實際閱讀、圖例及選擇理由。
- [x] 隊伍需求、路口風險和號誌效果可辨，讓玩家能計畫通行順序，而非只交替按鍵。
- [x] 普通、精準表現、失誤及輔助的成績規則明確；結算能說明成果與個別成就資格。
- [x] 首次學習、練習、正式遊玩、重試和離開形成完整流程，不在教學閱讀時消耗回合時間。
- [x] 正常及輔助、鍵盤及滑鼠、降低動態下以實際输入遊玩驗收；保留正常速度影片、截圖和受影響測試。

# Commit-2

## 內文

問題：原本人潮遊戲依固定拍點換燈，隊伍幾乎不會同時等待，玩家缺少安排次序的理由，畫面也與其他小遊戲共用場地。

改動：改成俯視海港路口，兩側各自排隊，紅燈停在線後；已開始過路的人必須完整走完，清場和全紅後才換向。六隊以重疊時程抵達，救援隊有擔架與較短耐心，不能跳過同向隊伍；玩家須比較兩側等待期限。安全通過給基礎分，等候效率與救援另計，全部六隊達普通資格，至少 430 分達惡魔資格。教學更換成此版實際路口截圖。

驗收：主 Session 在隔離存檔用實際滑鼠選縱向、Q 選橫向，接著依等待期限安排通行；正常與四分之一速度均完成六隊、430 分，捕捉兩側同時排隊、救援進場與結果。原生畫面查看確認人物、擔架和訊號對應；影片播放檢視通行片段。局部規則驗證也確認：選全局最早抵達反而會讓救援逾期；較慢但全隊安全仍可獲普通資格，效率不足不給惡魔。這是原生輸入與模型驗證，不當作真人完整試玩或十二款全部完成。

# Commit — 2026-10-23 看得見的排程資訊與逐隊結算

## 問題

號誌卡只寫「等候 N」，看不出幾人、有沒有救援隊、最急的一隊還能等多久；換向要清場和全紅，畫面卻不說幾秒後才能換，也看不出「先放另一側，這一側就會來不及」；下一隊何時從哪側來完全看不到，只能事後反應。結算把六隊合併成兩列，看不出哪一隊拿多少、哪一隊改道；輔助回合仍可能顯示小惡魔；規則說明沒寫普通與小惡魔條件。

## 改動

路口上方改成四張卡：「路口」寫目前通行或清場、幾秒後可換向；橫向／縱向號誌卡寫幾隊幾人、是否有救援、燈號與「最急 x.x 秒」，若另一側先走會讓這側排頭改道，卡框變紅並寫「先放這側！剩 x.x 秒」；「到站預告」列出接下來兩隊的到站秒數、方向、人數與是否救援。輔助回合另在最該先放的一側寫「建議先放」，並維持延長耐心；標準回合只有紅框警示，不替玩家選擇。

計分不變（每隊安全 +50、開始過路前等不到 2.2／4.4 秒 +20／+10、救援及時 +50）。普通拍貼為六隊全部安全；小惡魔改為未開輔助、沒有隊伍改道且總分至少 430。結算逐隊一列：方向、人數、開始過路前等了幾秒，以及通行、效率、救援各得幾分；改道的隊伍列「等太久改道」0 分；資格說明寫出本次安全／改道數或距 430 還差幾分。三頁教學換成現行實際畫面並重寫。

## 驗收

以隔離存檔從園區站點進入，固定 60 FPS 遊戲時鐘、真實 Q／E 與號誌卡點擊。腳本照卡片資訊做兩種決策：先放最急的一側，或先放先到的一側。

| 路線 | 實際結果 |
|---|---|
| 輔助＋降低動態、夜晚、鍵盤，先放最急 | 六隊安全、430 分，只收藏普通拍貼；結算寫明輔助不取得小惡魔；畫面出現「建議先放」 |
| 標準、正午、鍵盤，先放最急 | 暫停凍結、恢復、確認重試回到紅燈零分；救援隊排頭時卡片變紅寫「先放這側」，照做後六隊安全 430 分，取得小惡魔拍貼與本遊戲成就 |
| 標準、黃昏、只用滑鼠，先放先到（從結算「再玩一次」） | 救援隊等太久改道，5 / 6 未達普通；結算寫「本次 5 / 6，改道 1」並列出改道的那一隊，進度不變 |
| 私人練習（滑鼠） | 結算為練習、不保存，進度不變，返回遊園 |
| 首次教學（遊戲 3、4） | 新存檔首次進入三頁實際畫面教學、鍵鼠翻頁、開始後記為已學；遊戲中開教學時回合與模型時鐘不動，重看、私人練習與返回正常 |
