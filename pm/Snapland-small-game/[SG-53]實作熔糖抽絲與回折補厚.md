# [SG-53] 實作熔糖抽絲與回折補厚

> 狀態：進行中

## 內文

### 需求

開放糖果工廠第十二站「熔糖抽絲」。玩家控溫並調整拉速，完成三段指定粗細的連續糖絲。兩種原料的冷卻速度與各段長度不同。小惡魔挑戰要求把長度足夠的過細段回折成合格雙股。

### 來源

2026-11-26，使用者要求完成後繼續後面章節。設計候選 game-036 規劃調熱、拉力、三段絲徑、回折雙股與輔助接續。

### 驗收條件

- [ ] 工廠與地圖能進入第十二站，區內十二款均可遊玩與收藏。
- [ ] 兩種原料有不同冷卻率及目標段長，拉速、溫度和拉力確實影響絲徑。
- [ ] 完成三段才能通關，過細段回折須消耗雙倍原長且量得合格雙股。
- [ ] 鍵鼠及單指可完成。AI 可協助控溫，輔助斷絲後保留已完成段落。
- [ ] 圖解、Hover、過熱與拉斷回饋可辨識，暫停、失焦和取消不殘留輸入。
- [ ] 第十二格拍貼、補拍、成就、舊存檔及重開延續既有規則。
- [ ] 局部、原生及封裝驗證通過，PM 留摘要與代表截圖。

### 測試流程

1. 裝上兩種原料各試一次，切換拉速與加熱，完成三段。
2. 在目標長度的兩倍拉出過細絲，拿去回折並核對粗細。
3. 驗證過熱與冷拉斷裂、練習退出、補拍和重開。
