# [SG-54] 實作雨棚快遞與熱餐滑遞

> 狀態：進行中

## 內文

### 需求

開放霓虹夜市首款遊戲「雨棚快遞」。玩家逐份取餐，依雨勢在短巷和雨棚繞路之間取捨。撐傘可避免淋濕，收件口到位時把餐盒滑入，送達三份乾爽熱餐即可完成。小惡魔挑戰要求以傘接住滑行的餐盒跨越積水。

### 來源

2026-11-26，使用者要求依序接續後面章節並增加玩法變化。小遊戲設計 game-037 規劃雨向、棚缺口和送餐順序，以及路程、保溫與遮雨的取捨。

### 驗收條件

- [ ] 夜市和地圖可開啟首站。圖解與 Hover 簡明交代路線、雨傘、餐盒與接貨時機。
- [ ] 短巷與雨棚路線均可完賽。雨向、棚隙及收件順序有實際變化，濕度、溫度和進度可見。
- [ ] 玩家須親自取餐、走路與滑遞。輔助可引導走雨棚及遮雨，並可由玩家完成所有收藏條件。
- [ ] 鍵鼠及單指可操作，暫停、取消及失焦可安全釋放輸入。失誤可重試當前訂單並保留已送達餐點。
- [ ] 驗證以傘接餐跨過積水、普通與小惡魔結算、練習、拍貼、免費補拍、成就及重開。
- [ ] 局部、原生與封裝驗證通過。PM 保留摘要與一張代表截圖。

### 測試流程

1. 走雨棚和短巷各試一次。於雨中切換雨傘，確認食物狀態與路程差異。
2. 取餐並完成三份滑遞，核對不同接貨順序、失誤重試、輔助及暫停恢復。
3. 驗證以傘接滑餐、練習、照片、重開及小視窗。
