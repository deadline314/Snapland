# [SG-46] 保護圖形測試截圖輸出

> 狀態：進行中

## 內文

### 需求
圖形模式的巧克力工藝回歸會輸出診斷截圖。未設定截圖目錄或給相對位置時，不能將同名影像寫進工作目錄；只有明確指定的獨立絕對檔案系統目錄才輸出。截圖輸出為選用診斷，原有像素與玩法檢查仍須執行。

### 來源
2026-11-18，SG-45 最終複審發現單獨啟動圖形測試時，未檢查的截圖位置可能覆寫工作目錄的同名檔案。

### 驗收條件
- [ ] 未設定截圖目錄時不寫入工作目錄，同名既有檔案保持原樣。
- [ ] 相對位置與遊戲虛擬位置不輸出截圖，同名既有檔案保持原樣。
- [ ] 明確指定獨立絕對目錄時，可輸出三張原始診斷影像。
- [ ] 未輸出影像時，切痕、孔洞與撤銷的實際像素檢查仍完整執行。
- [ ] 已註冊的無視窗測試維持通過，完成實際隔離驗證與提交。

### 測試流程
1. 在獨立測試目錄預先放入同名檔案，分別以未設定、相對及遊戲虛擬位置啟動圖形檢查，確認原檔內容不變且像素檢查仍執行。
2. 另設獨立絕對截圖目錄，確認三張原始影像可讀取；重跑已註冊的無視窗檢查。所有程序使用獨立存檔與設定目錄。
