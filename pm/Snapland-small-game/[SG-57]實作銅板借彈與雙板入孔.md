# [SG-57] 實作銅板借彈與雙板入孔

> 狀態：完成

## 內文

### 需求

開放霓虹夜市第四款小遊戲「銅板借彈」。玩家選角度和力道，收放或轉動兩片斜板，將三枚銅板滑入指定孔。漆面和布面煞速不同，直投需控制入孔速度，借板可轉向及減速。

### 來源

[小遊戲目錄 game-040](../../design/02-minigames/catalog.md#game-040-銅板借彈) 與 2026-11-26 使用者要求接續夜市、增加不同玩法及打磨美術與操作。

### 驗收條件

- [x] 兩套桌面各可直投和調整斜板。角度、力道、油漆與布面、板緣碰撞和孔口速度會影響實際落孔。
- [x] 鍵盤、滑鼠、觸控與手把可完成回合。孔位、桌面材質、碰板次數和擦邊可讀，Hover 說明角度、力道及收放。
- [x] 同一枚銅板確實撞過兩片不同板並穩落指定孔，完成三孔才取得小惡魔。練習、空投、二撞同板、錯孔與失手有相符結果。輔助首段預覽、補幣與指定板 AI 可用。
- [x] 夜市站位、圖解、結算、拍貼與免費補拍可用。局部回歸、原生多尺寸與 Windows 封裝重開通過，PM 保留摘要和一張畫面。

### 測試流程

1. 走到夜市桌檯，試直投和借板，觀察布面減速與孔緣碰撞。
2. 在兩套桌面用同一枚銅幣撞兩塊板後落孔。比較二撞同板、錯孔、收起斜板和輔助回合。
3. 取得拍貼與補拍，從隔離 Windows 成品重開確認。
