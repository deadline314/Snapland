# [SG-48] 實作糖豆蹺蹺板與回彈側槽

> 狀態：進行中

## 內文

### 需求
開放糖果工廠第七站「糖豆蹺蹺板」。移動踏板改變支點兩端的高度，從左右料斗放豆，讓糖豆接近同時落入各自的秤盤。玩家能先留住輕豆，再利用重豆改變板端動量。小惡魔要讓真正回彈的輕豆落入右側槽。

### 來源
2026-11-19，使用者要求延續票券並增加玩法多樣性。設計目錄 game-031 已定義移踏板、雙料斗、同步落盤、豆重與料斗位置變化，以及回彈側槽。

### 驗收條件

- [ ] 從工廠設施、區域地圖與圖解教學進入，既有六站可繼續玩。
- [ ] 踏板力矩、豆重、料斗位置和放料時間實際改變運動與落盤。兩端確實在容許時間內分別落盤才完成普通目標。
- [ ] 至少兩組料斗位置與豆重，盤上重量、板端動量、下一顆豆重與側槽回饋可辨。
- [ ] 只有實際因板端向上回彈並落入側槽的輕豆能取得小惡魔。輔助可放寬判定，AI 可扶穩板端，兩者都保留手動移踏板、放豆與回彈。
- [ ] 鍵盤、滑鼠和單指觸控可移踏板及開雙料斗。暫停、重新開始、取消和場景離場沿用既有行為。
- [ ] 有精簡 Hover 與原生圖解，在三種驗證視窗仍能看清操作、豆重與結算。
- [ ] 正常參與、通關與補拍可取得第七格固定收藏，練習與取消無獎勵。舊存檔、重啟與重玩都正常且不重複發點。
- [ ] 局部自動化、原生呈現和獨立封裝實際執行通過，原生截圖及紀錄附票。

### 測試流程

1. 在獨立存檔進工廠開第七站。分別放輕重豆，試未移踏板、放太早、兩側落盤和真正回彈進側槽。
2. 重玩換一組料斗，切換 AI 與輔助，驗證鍵盤、滑鼠、單指、暫停、退出及小視窗畫面。
3. 完成正式挑戰、練習、取消及補拍，以新程序確認拍貼與點數。用獨立封裝實際跑同一條操作路線。
