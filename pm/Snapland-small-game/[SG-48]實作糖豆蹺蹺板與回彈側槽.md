# [SG-48] 實作糖豆蹺蹺板與回彈側槽

> 狀態：完成

## 內文

### 需求
開放糖果工廠第七站「糖豆蹺蹺板」。移動踏板改變支點兩端的高度，從左右料斗放豆，讓糖豆接近同時落入各自的秤盤。玩家能先留住輕豆，再利用重豆改變板端動量。小惡魔要讓真正回彈的輕豆落入右側槽。

### 來源
2026-11-19，使用者要求延續票券並增加玩法多樣性。設計目錄 game-031 已定義移踏板、雙料斗、同步落盤、豆重與料斗位置變化，以及回彈側槽。

### 驗收條件

- [x] 從工廠設施、區域地圖與圖解教學進入，既有六站可繼續玩。
- [x] 踏板力矩、豆重、料斗位置和放料時間實際改變運動與落盤。兩端確實在容許時間內分別落盤才完成普通目標。
- [x] 至少兩組料斗位置與豆重，盤上重量、板端動量、下一顆豆重與側槽回饋可辨。
- [x] 只有實際因板端向上回彈並落入側槽的輕豆能取得小惡魔。輔助可放寬判定，AI 可扶穩板端，兩者都保留手動移踏板、放豆與回彈。
- [x] 鍵盤、滑鼠和單指觸控可移踏板及開雙料斗。暫停、重新開始、取消和場景離場沿用既有行為。
- [x] 有精簡 Hover 與原生圖解，在三種驗證視窗仍能看清操作、豆重與結算。
- [x] 正常參與、通關與補拍可取得第七格固定收藏，練習與取消無獎勵。舊存檔、重啟與重玩都正常且不重複發點。
- [x] 局部自動化、原生呈現和獨立封裝實際執行通過，原生截圖及紀錄附票。

### 測試流程

1. 在獨立存檔進工廠開第七站。分別放輕重豆，試未移踏板、放太早、兩側落盤和真正回彈進側槽。
2. 重玩換一組料斗，切換 AI 與輔助，驗證鍵盤、滑鼠、單指、暫停、退出及小視窗畫面。
3. 完成正式挑戰、練習、取消及補拍，以新程序確認拍貼與點數。用獨立封裝實際跑同一條操作路線。

# Commit-1

## 內文

糖果工廠開放第七站「糖豆蹺蹺板」，全園可玩小遊戲增至 31 款。移踏板、看料斗豆重和安排放豆順序，讓兩顆豆在 0.43 秒內分別實際落入秤盤。高端可先留輕豆，重豆落板會抬高另一頭。重玩交替兩組料斗位置、豆重和起始踏板格。

雙盤同步後可按 F 結算。也可移踏板讓右端把輕豆實際回彈進側槽，取得小惡魔。輔助加寬秤盤與側槽，同步窗放寬至 0.64 秒。AI 可扶穩板端。移踏板、放料與回彈由玩家控制，可用鍵盤、滑鼠或單指。按鈕 Hover 說明各格的板端影響及放料動作。

移踏板並開過兩邊料斗即可在正式回合自然結算時取得普通卡。取消和練習不發卡。第七格普通、小惡魔、成就、補拍原圖與單筆 40 點沿用既有保存規則。
