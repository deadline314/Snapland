# [SG-51] 實作糖紙滑翔與擦鈴減速

> 狀態：進行中

## 內文

### 需求

開放糖果工廠第十站「糖紙滑翔」。玩家在試飛台摺好兩側機翼，調整投出力道與側風，讓紙機穿過兩道風窗後落入包裝籃。寬翼與窄翼會改變滑翔距離和操控；紙重、風窗及側風有兩種配置。小惡魔挑戰是在落籃前讓翼尖擦鈴減速。

### 來源

2026-11-25，使用者要求接續糖果工廠小遊戲。設計目錄 game-034 規劃寬窄摺翼、紙重、兩道風窗、包裝籃、擦鈴與單人輔助。

### 驗收條件

- [ ] 可從工廠與地圖進入第十站，既有九站與收藏維持可用。
- [ ] 摺翼、力道、紙重與側風確實改變軌跡。兩種配置有可讀差異，碰窗與漏窗有明確回饋。
- [ ] 兩窗及落籃決定通關，小惡魔另須實際翼尖碰鈴並減速。
- [ ] 鍵盤、滑鼠及單指能完成；輔助提供首段軌跡與收回重摺，AI 依玩家選定的折線摺翼。
- [ ] 有圖解、簡短 Hover 與視覺提示，暫停、練習、失焦及取消可安全操作。
- [ ] 第十格拍貼、成就、補拍及舊存檔延續現有規則，重開可讀回。
- [ ] 局部與原生流程通過，PM 只保留必要截圖與摘要。

### 測試流程

1. 從工廠進入，以不同摺型和力道投紙機。
2. 操作兩種配置，分別穿窗落籃與擦鈴後落籃。
3. 由地圖及補拍入口進入，確認暫停、取消及重開同行為。
