# [SG-127] 實作一鏡走位

> 狀態：待辦

## 內文

### 需求

演員照著地上的標記在片場走位，左右推動軌道上的攝影推車，讓演員一直待在取景框正中央。佔用星光影城的 game-109 位置，攤位在攝影棚，取代原本偏向規劃與多按鈕的設計。

### 來源

2026-11-28 星光影城（MAIN-68）完成，十二個攤位都還是準備中。使用者要求小遊戲單純好玩、玩法多變、不要枯燥的射擊；依 design/00-principles/simple-fun-minigames.md 改寫為單一動詞的街機式小遊戲（Bomberman Land 3 方向）。

### 驗收條件

- [ ] 演員會突然停下、折返或小跑，後段軌道出現彎道。
- [ ] 跟丟時推車撞上布景，主角被倒下的燈架罩成一盞檯燈。
- [ ] 整款只用方向鍵與一到兩顆按鍵，畫面上沒有操作按鈕面板；進場五秒內開始操作，沒有強制教學頁。
- [ ] 一回合不超過 60 秒，回合內速度或變化明顯升級；至少兩種隨機出現的變奏。
- [ ] 結算只顯示一個分數、銅銀金獎牌與一句評語；銅牌取得普通拍貼，未用輔助的金牌取得小惡魔拍貼。
- [ ] 玩法物件達到街機小遊戲的畫面下限：沒有大面積純色、有材質與受光、描邊、接地陰影，色調與星光影城背景一致。
- [ ] 鍵盤與手把都能完成；開啟減少動態後仍可遊玩；沒有按鍵就不得分。
- [ ] 通過稽核十問，結果寫在設計目錄的該款說明；星光影城原有互動與其他小遊戲不受影響。

### 測試流程

1. 從攝影棚的攤位進場，不看說明直接玩一回合。
2. 故意失敗一次，再玩到銅牌與金牌。
3. 開啟減少動態與手把各玩一回合，確認拍貼入冊與重開後保留。
