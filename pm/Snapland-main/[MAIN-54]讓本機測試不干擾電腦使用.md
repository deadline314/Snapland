# [MAIN-54] 讓本機測試不干擾電腦使用

> 狀態：待辦

## 內文

### 需求

在本機跑引擎測試或截圖時，視窗會跳到前景搶走焦點，處理器也被佔滿，影響同時進行的其他工作。讓本機測試在背景安靜執行。

### 來源

2026-11-27 使用者要求測試時盡量不要影響正常使用電腦。

### 驗收條件

- [ ] 本機引擎測試以低於一般的優先權執行，並可用環境變數改回一般優先權。
- [ ] 原生截圖有統一的啟動方式，視窗不出現在桌面上且不發出聲音。
- [ ] 原生截圖一律使用獨立存檔，不讀寫玩家進度。
- [ ] 工作規範寫明本機原生截圖的啟動方式。

### 測試流程

1. 執行一次原生截圖，確認桌面沒有出現視窗且有輸出畫面。
2. 執行一組引擎測試，確認結果與優先權設定。
