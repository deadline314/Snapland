# [MAIN-76] 讓正常遊玩一定拿得到一百八十張普通拍貼

> 狀態：待辦

## 內文

### 需求

終區劇場要求一百八十張普通拍貼，但目前實際拿得到的大約只有一百四十張，玩家永遠進不了終區。盤點十區實際可得的普通拍貼（包含已開票但還沒做的雲端遊樂場、星光影城小遊戲），算出每區缺口，再用符合各區主題的方式補齊：地圖即玩遊戲、區內收集要素、拍照點、居民委託等。目標是正常遊玩一定拿得到一百八十張，每張都有固定、可重做的取得方式。

### 來源

2026-11-28 MAIN-71 交付時發現目前普通拍貼總數約一百四十張；使用者要求正常遊玩一定拿得到一百八十張，調整門檻前要先問使用者。

### 驗收條件

- [ ] 票上有一張表：十區各自目前可得、已開票待做、缺口，以及每張拍貼的來源。
- [ ] 依設計每區十八張普通拍貼（十二款小遊戲、三個探索、一個主線、兩個支線）補齊缺口；補的內容符合該區主題，玩法不和既有的重複。
- [ ] 每張普通拍貼都有固定、可重做的取得方式，相簿顯示缺少的拍貼在哪一區、怎麼取得。
- [ ] 有一個檢查確認十區普通拍貼合計正好一百八十張、每張都有取得途徑，之後有人改動造成不足會失敗。
- [ ] 不調整劇場門檻；若盤點後發現必須調整，先停下詢問使用者。

### 測試流程

1. 對照票上的盤點表與遊戲資料。
2. 跑拍貼總數與取得途徑的檢查。
3. 在一區實際取得一張新補的拍貼，確認相簿登記。
