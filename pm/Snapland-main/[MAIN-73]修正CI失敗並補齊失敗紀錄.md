# [MAIN-73] 修正CI失敗並補齊失敗紀錄

> 狀態：完成

## 內文

### 需求

自 MAIN-54（本機測試改低優先權）合併後，GitHub Actions 的完整測試每一次都失敗：模擬 Windows 的兩個逾時測試在 Linux 上找不到只有 Windows 才有的優先權常數。這個錯誤發生在遊戲執行測試的前置檢查，四個分片都在這一步中止，Godot 遊戲測試其實一直沒有在 CI 上跑。另外失敗時只看得到第一個失敗套件，看不到同一分片的其他失敗，也沒有完整紀錄可下載。

### 來源

2026-11-28 使用者發現 CI 常常沒有通過，要求更詳細的紀錄並修正 CI。最近 200 次執行為 143 次失敗、56 次取消、0 次成功。

### 驗收條件

- [x] 逾時測試在 Linux 與 Windows 上都通過，本機低優先權行為不變。
- [x] 前置檢查失敗時，遊戲執行測試仍會照跑，不會一個錯誤蓋掉全部結果。
- [x] 每個分片跑完所有套件才結束，一次列出所有失敗套件。
- [x] 每次執行的摘要頁列出每個套件的通過、失敗與耗時，失敗的附上輸出結尾。
- [x] 每個套件的完整輸出存成檔案，失敗時可從該次執行下載。
- [x] 修正後 main 上的 CI 執行結果與失敗原因清楚可讀；仍失敗的套件另外開票處理。

### 測試流程

1. 推上 main 後打開該次 GitHub Actions 執行。
2. 看摘要頁每個分片的套件清單與失敗輸出。
3. 下載紀錄檔，確認每個套件都有自己的檔案。

# Commit-1

## 內文

CI 從 MAIN-54 合併後每次都失敗：兩個模擬 Windows 的逾時測試在 Linux 上找不到 Windows 才有的優先權常數，四個遊戲測試分片都在前置檢查中止，Godot 遊戲測試一直沒有真正在 CI 上跑。
現在 Linux 上改用固定數值，本機 Windows 仍以低優先權執行；前置檢查失敗時遊戲測試照跑；每個分片跑完所有套件才結束並列出全部失敗；每次執行的摘要頁列出每個套件的結果、耗時與失敗輸出結尾；每個套件的完整輸出存成檔案，失敗時可下載七天。
修正後第一次完整執行（main 上第 46132500249 次）：設計資料驗證、Python 測試、來源檢查與第 2 分片全部通過，其餘分片共 4 個套件失敗，各自另開票處理：風箏追風未達銅牌仍得拍貼（SG-139）、旅館鬼影擦窗在 CI 逾時（SG-140）、存檔隔離探針缺檔（MAIN-74）、高 RTL 文字下暫停選單按鈕超出畫面與兩個缺少的翻譯（MAIN-75）。
