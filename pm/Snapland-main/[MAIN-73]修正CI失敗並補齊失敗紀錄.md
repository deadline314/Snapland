# [MAIN-73] 修正CI失敗並補齊失敗紀錄

> 狀態：進行中

## 內文

### 需求

自 MAIN-54（本機測試改低優先權）合併後，GitHub Actions 的完整測試每一次都失敗：模擬 Windows 的兩個逾時測試在 Linux 上找不到只有 Windows 才有的優先權常數。這個錯誤發生在遊戲執行測試的前置檢查，四個分片都在這一步中止，Godot 遊戲測試其實一直沒有在 CI 上跑。另外失敗時只看得到第一個失敗套件，看不到同一分片的其他失敗，也沒有完整紀錄可下載。

### 來源

2026-11-28 使用者發現 CI 常常沒有通過，要求更詳細的紀錄並修正 CI。最近 200 次執行為 143 次失敗、56 次取消、0 次成功。

### 驗收條件

- [ ] 逾時測試在 Linux 與 Windows 上都通過，本機低優先權行為不變。
- [ ] 前置檢查失敗時，遊戲執行測試仍會照跑，不會一個錯誤蓋掉全部結果。
- [ ] 每個分片跑完所有套件才結束，一次列出所有失敗套件。
- [ ] 每次執行的摘要頁列出每個套件的通過、失敗與耗時，失敗的附上輸出結尾。
- [ ] 每個套件的完整輸出存成檔案，失敗時可從該次執行下載。
- [ ] 修正後 main 上的 CI 執行結果與失敗原因清楚可讀；仍失敗的套件另外開票處理。

### 測試流程

1. 推上 main 後打開該次 GitHub Actions 執行。
2. 看摘要頁每個分片的套件清單與失敗輸出。
3. 下載紀錄檔，確認每個套件都有自己的檔案。
