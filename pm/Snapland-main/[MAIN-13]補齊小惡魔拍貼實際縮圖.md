# [MAIN-13] 補齊小惡魔拍貼實際縮圖

> 狀態：待辦

## 內文

### 需求
正式通關後普通拍貼有本局截圖，小惡魔拍貼卻顯示「已收藏 · 照片檔未讀取」。讓兩個分類都能展示真實遊戲畫面，並安全支援已有收藏的舊存檔。

- 同一局成功同時取得普通與小惡魔拍貼時，兩張卡都讀取本局實際遊戲畫面。
- 普通與小惡魔共用同一組截圖路徑，不另存重複圖檔；重玩更新既有記錄，不增加收藏張數。
- 舊存檔若已收藏小惡魔、普通拍貼仍有可讀的實際截圖，安全補上小惡魔的縮圖資料。沒有可讀普通截圖時保留收藏，讓收藏冊顯示既有安全fallback。
- 私人練習不寫入縮圖或收藏；失敗局不寫入截圖。截圖路徑缺失、格式錯誤或檔案損壞時發出含拍貼 ID 與路徑的具體警告，收藏冊仍可正常開啟並顯示fallback。

### 來源
2026-10-12 主 Session 實際觀看 SG-17 正常與慢放原生收藏冊截圖時發現。使用者要求完整的收藏體驗，獨立問題先開票再實作；設計範圍已整理於本 Session 的小惡魔縮圖設計草稿。

### 驗收條件
- [ ] 原生完成一款遊戲的普通與小惡魔條件，收藏冊兩個分類都顯示同一局真實截圖。
- [ ] 關閉並重開遊戲，兩張縮圖仍可讀，照片檔只有一份共同來源。
- [ ] 重玩同款不重複增加普通或小惡魔收藏張數，縮圖仍可正常讀取。
- [ ] 私人練習不新增／改寫收藏縮圖。
- [ ] 舊存檔有普通截圖時，小惡魔縮圖可安全回填；缺檔、損壞檔與無來源圖都保留收藏並顯示fallback，不崩潰。

### 測試流程
1. 使用隔離存檔，實際操作同一款遊戲通過普通與小惡魔條件，檢查結算、普通收藏頁與小惡魔收藏頁。
2. 重開後再次檢查兩個分類與圖片檔案數；重玩一局確認收藏數不增加。
3. 在測試存檔建立「只有普通圖」「惡魔有舊收藏但無 frames」「路徑不存在」「圖片損壞」等情況，執行相關局部測試並核對警告與fallback。
4. 以私人練習完成一局，確認收藏資料與截圖目錄沒有被新增或改寫。
5. 保存普通、小惡魔分類及重開後的原生截圖；程式化檢查不能代替畫面驗收。
