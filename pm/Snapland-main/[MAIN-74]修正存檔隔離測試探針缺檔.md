# [MAIN-74] 修正存檔隔離測試探針缺檔

> 狀態：待辦

## 內文

### 需求

存檔隔離測試會在獨立的假專案裡載入進度檔，但進度檔從 MAIN-51 起預先載入畫質設定檔，假專案沒有一起帶入，探針因解析失敗結束，無法證明測試與檢視流程不會碰到玩家存檔。

### 來源

2026-11-28 MAIN-73 修好 CI 後的第一次完整執行（main 上第 46132500249 次）發現。這個失敗之前被 CI 的前置錯誤蓋住。

### 驗收條件

- [ ] 存檔隔離測試在 CI 與本機都通過。
- [ ] 之後進度檔新增相依檔案時，測試會直接指出缺的檔案，而不是只回報探針失敗。
- [ ] 測試仍證明測試與檢視流程不會讀寫玩家存檔。

### 測試流程

1. 本機只跑「test/review save isolation tests」一次，輸出寫進紀錄檔。
2. 推上 main 後看 CI 摘要頁，該套件為通過。
