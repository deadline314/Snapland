# MAIN-24 證據索引

本票交付園區往返、可走動線與安全保存；碼頭遊戲、故事及當地收藏仍依接續範圍實作，沒有以空場景算成完整園區。

入場驗證使用明確標記的六張既有迎賓普通拍貼測試資料。這些是隔離保存的程式化準備，不是取得獎勵、真人遊玩或真人試聽證據。流程前後的照片、金幣、任務、外觀及造訪紀錄都有比較，沒有發放碼頭獎勵。

## 最終結果

- `local/main24/native-800x600/{writer,restart}`：捲髮、雨背心、降低動態與 1.25 文字。
- `local/main24/native-1280x720/{writer,restart}`：原外觀與一般動態。
- `local/main24/native-1920x1080/{writer,restart}`：短髮、雨背心與 1.25 文字。
- 每組 writer 為實際門檻按鈕、旅行、潮位、渡船、地圖、收藏與返回，共 11 張。restart 另開程序真正讀入保存的碼頭位置，共 10 張；各自 report.json 核對實際視窗／PNG 尺寸、外觀、進度及空的失敗清單。
- `packed-forward-plus/{writer,restart}`：空工作目錄載入獨立資源包，以預設光影重做同一套 21 張流程。
- `local/main24/windows-*.log`：Windows 新存檔、已存碼頭及原十二款圖資檢查；後者明確使用迎賓驗收場景，不改掉保存的碼頭位置。
- `windows-twelve-assets/`：實際 Windows 成品的原十二款圖資截圖。
- `reviews/`：三項任務與整批審查、局部及跨平台測試紀錄。
- `local/main24/ci-*-final.log`：183 項 Python 與全部 107 項遊戲檢查通過。
- `build/`：乾淨提交的來源指紋與輸出成品資訊。

紅燈、診斷、早期草稿與 standalone preview 檔案是保留的開發歷史，不是最終驗收。原迎賓建物材質警告仍如實保留，沒有以忽略資源錯誤取得通過。
