# [MAIN-26] 開放糖果工廠往返與探索

> 狀態：完成

## 內文

### 需求
沿既定第三區設計開放糖果工廠，提供和迎賓大道、潮汐碼頭不同的材料加工環境、可走動線與溫度觀察互動。玩家能以全島六張不同普通拍貼免費進入，隨時免費返回迎賓大道，離開重開仍停在正確園區。尚未交付的遊戲與收藏須如實標示，不以空亭或換皮遊戲充數。

### 來源
2026-11-17 使用者要求持續完成所有票，並自主檢查遊戲缺口、增加不重複的多樣內容。依 design/01-park/park.json 的糖果工廠與 design/runtime/full-game-delivery.md 的逐區交付順序；目前可玩二十四款，第三區與拉糖橋仍只有設計。

### 驗收條件
- [x] 有獨立糖果工廠地形、主輸送廊、材料工作台與糖漿管道；玩家能完整步行探索，碰撞、地圖、重置點與返回入口一致，不建立迎賓 NPC 或虛構當地任務。
- [x] 達全島六張普通拍貼後能進入，不消耗收藏或金幣；不足時顯示差額，返回永久免費；既有碼頭入口與全部遊戲正常。
- [x] 能觀察冷、溫、熱對材料顯示的變化，有簡短操作說明與必要 Hover；觀察互動不冒充正式小遊戲、通關或收藏。
- [x] 三區切換、重入、設定、地圖、收藏空狀態、任務說明、重置與關閉重開正常；舊存檔缺欄位與未知地區安全回到迎賓，保存失敗保留原世界與進度。
- [x] 穩態只保留一個世界，換區忽略舊事件且阻擋重入；旅行後原圖、免費補拍、教學、成就與既有獎勵不受損。
- [x] 受影響局部測試、三種視窗含放大文字／降低動態、原生往返與隔離輸出驗證附票，不把自動操作當真人試玩或試聽。

### 測試流程
1. 分別使用五張與六張普通拍貼，核對門檻差額與不消耗；進工廠查看實際動線、溫度互動與地圖，免費返回。
2. 暫停、重入、讀檔、重置與保存失敗時核對園區與資料；三區反覆切換確認舊世界釋放、舊事件不觸發。
3. 在三種視窗和獨立輸出中實際往返，檢查設定、收藏與任務資訊，以及原有迎賓／碼頭遊戲。
