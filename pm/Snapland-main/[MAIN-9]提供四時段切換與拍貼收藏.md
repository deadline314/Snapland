# [MAIN-9] 提供四時段切換與拍貼收藏

> 狀態：待辦

## 內文

### 需求
建立凌晨、中午、傍晚、晚上四時段，玩家隨時可切换；提供可融入時段的拍貼收藏及獎勵，保留自由遊園與既有收藏規則。

### 來源
2026-10-12 使用者要求：加大透視圈並考慮效果、NPC 避免遮擋且有個性動作、修正光影、自由切換四時段並融入拍貼或任務、小遊戲有時段布景。研究需超過五個來源，來源與已看過的截圖一同附票。

### 驗收條件
- [ ] 至少六個来源比較日夜、自由切時與收藏机制，記錄採用理由。
- [ ] 四時段可隨時選取、重新啟動保存且未知存檔安全回退。
- [ ] 時段拍貼來源與獎勵可理解，重複領取不重複發獎，不改既有普通與惡魔收藏門檻。
- [ ] 任務或收藏介面可查看四時段收集狀態；全部取得有遊戲內成就並保留平台接口。
- [ ] 原生切時與收藏流程有截圖，受影響局部驗證通過。

### 測試流程
1. 啟動獨立測試存檔，原生操作本票功能。
2. 檢查四時段、設定、重啟與不同視窗的相關行為。
3. 保存實際看過的截圖和短片，執行受影響局部驗證。
