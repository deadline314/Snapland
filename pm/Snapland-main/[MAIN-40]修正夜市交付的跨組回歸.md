# [MAIN-40] 修正夜市交付的跨組回歸

> 狀態：進行中

## 內文

### 需求

補齊夜市交付後暴露的兩項整合回歸。雨棚快遞先完成有效操作再自然逾時，參與資格仍可正確判定。存檔隔離驗證需要載入完整的測試依賴，子程序未載入時應立即回報。

### 來源

2026-11-26，夜市交付後的主分支整合驗證發現參與結果與存檔隔離問題。

### 驗收條件

- [ ] 雨棚快遞實際移動後自然逾時，保留參與資格與真實失敗結果。無操作逾時保留未達參與資格，練習與取消維持既有規則。
- [ ] 隔離驗證涵蓋拒絕非法路徑、寫入指定測試檔和重開假預設存檔。缺少依賴或未啟用保護時應明確失敗並結束子程序。
- [ ] 局部整合驗證用隔離使用者資料通過，PM 保留必要摘要。

### 測試流程

1. 以既有控制移動快遞員並等待自然逾時，再比對正式、練習與無操作結果。
2. 使用隔離路徑執行存檔測試，確認原有負面檔案雜湊及正向讀寫。
3. 在測試副本省略依賴，確認立即回報缺少依賴並停止。
