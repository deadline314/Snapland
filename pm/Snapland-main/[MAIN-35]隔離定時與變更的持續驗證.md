# [MAIN-35] 隔離定時與變更的持續驗證

> 狀態：完成

## 內文

### 需求

主分支的定時驗證和變更驗證都應能執行完整套件，以便辨識各次提交是否通過。新的變更仍可取代同分支的舊變更驗證。

### 來源

2026-11-19 交付 ART-17 時，[主分支的推送驗證](https://github.com/deadline314/Snapland/actions/runs/44404088517)已有五項通過，第六項在[同一提交的定時驗證](https://github.com/deadline314/Snapland/actions/runs/44406936194)啟動後被取消。專案要求在每小時及有程式或規格變更時跑完整套件。

### 驗收條件

- [x] 同一分支的定時驗證與變更驗證可同時排入並各自執行。
- [x] 同一分支的新變更可取代尚未完成的舊變更驗證，各來源保有原本的觸發條件及六項工作。
- [x] 驗證紀錄可辨識事件來源與提交，GitHub Actions 可執行更新後的完整套件。

### 測試流程

1. 以同一分支的定時事件、推送及手動事件比對分組，另核對不同分支及連續兩次推送。
2. 以 GitHub Actions 的實際執行紀錄確認工作、來源及結果。
