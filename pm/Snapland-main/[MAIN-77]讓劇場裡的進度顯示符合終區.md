# [MAIN-77] 讓劇場裡的進度顯示符合終區

> 狀態：待辦

## 內文

### 需求

走進地底惡魔劇場後，畫面上的區域進度顯示「0 / 18」，沿用了一般區域的普通拍貼分母，但劇場是收齊一百八十張後才開放的終區，只有八款劇場短遊戲。改成符合終區的顯示，例如首演節目的進度（已演出幾段、共八段），並和劇場的風格一致。

### 來源

2026-11-28 MAIN-71 交付時發現；使用者要求改成符合終區的顯示。

### 驗收條件

- [ ] 在劇場內，進度顯示改為終區專屬的內容與分母，不再出現「0 / 18」。
- [ ] 顯示的樣式符合劇場（節目單或票根感），和其他區的進度顯示一致可讀；滑鼠提示只講重點。
- [ ] 離開劇場回到地面後恢復一般區域的顯示；其他區的顯示不變。

### 測試流程

1. 進入劇場看進度顯示，再回到地面確認恢復。
