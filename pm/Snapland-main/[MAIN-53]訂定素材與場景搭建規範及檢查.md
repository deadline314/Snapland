# [MAIN-53] 訂定素材與場景搭建規範及檢查

> 狀態：完成

## 內文

### 需求

地面層超出、純色方塊道具、風格不一的貼圖與錯誤影子一再出現，因為沒有寫明素材、場景與部件的搭建條件，也沒有檢查會擋下來。寫出搭建規範，並加入自動檢查，讓不合規的場景在測試階段就失敗。

### 來源

2026-11-27 使用者附三張迎賓碼頭截圖，指出地面層超出、方形色塊道具、樹木風格與影子錯誤，並要求讓同類問題不再發生。

### 驗收條件

- [x] 規範文件寫明地面分層與邊界、道具造型與材質下限、貼圖風格與描邊、影子做法、擺放位置及效能預算。
- [x] 自動檢查涵蓋地面層不超出、可見的大型純色基本形狀、影子與外形不符、物件懸空或陷地。
- [x] 檢查對七個區域執行並全部通過。
- [x] 故意放入一個違規物件時檢查會失敗並指出位置與原因。
- [x] 工作規範中註明新增場景內容前先讀此規範。

### 測試流程

1. 執行場景檢查並確認七區通過。
2. 暫時加入違規物件確認檢查失敗，再移除。
3. 閱讀規範確認每條都有對應的檢查或人工確認方式。

# Commit-2

## 內文

搭建規範寫好之後還沒有任何檢查會擋下違規的場景。
現在有一項場景檢查會建立七個區域並逐一稽核：露出大片純色面的方塊、圓柱與圓球，用基本形狀代替的影子，懸空或陷地的看板貼圖，以及節點是否超過預算；迎賓島的地面分層沿用島嶼佈局檢查。各區既有的違規數量被記錄為欠債，之後任何一區的數量只能減少，一旦增加檢查就會失敗，並印出違規物件的路徑、座標與尺寸。檢查本身會先放入一個純色大方塊、一個只用來投影的圓球與超量節點，確認三種都會被抓到，而細長欄杆與有貼圖的表面不會誤報。規範文件補上了執行方式與欠債的處理規則，工作規範要求交付前執行。
首次稽核結果：七區共有 316 個大面積純色形狀（迎賓 67、潮汐碼頭 26、糖果工廠 18、霓虹夜市 101、鏡之馬戲團 52、發條玩具城 30、苔光溫室 22），影子、看板貼圖與節點預算目前都是零違規。這份清單是 ART-46 與各區整建票的工作項目。

### 測試結果

| 項目 | 結果 |
|---|---|
| 場景檢查（七區） | 通過，欠債已記錄 |
| 植入違規的自我檢查 | 純色方塊、投影圓球、節點超量皆被抓到 |
| 大面積純色形狀 | 316 個（只准減少） |
| 影子、看板貼圖、節點預算 | 0 個違規 |
| 設計與連結檢查、Python 檢查 | 通過 |
