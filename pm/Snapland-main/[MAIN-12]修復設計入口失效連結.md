# [MAIN-12] 修復設計入口失效連結

> 狀態：待辦

## 內文

### 需求
設計入口的「128款小遊戲目錄」指向不存在的文件，導致連結驗證失敗。核對現行設計的實際位置，恢復可閱讀的正確入口並保留既有驗證的失敗偵測。

### 來源
2026-10-12 本 Session 驗收 ART-17 文件時，執行連結驗證發現此問題；origin/main 與 feature/island-first-park 均沒有該連結目標。使用者要求獨立問題先開票，不刪斷言或跳過失敗。

### 驗收條件
- [ ] 設計入口的目錄連結可開啟對應實際文件，內容與現行小遊戲基線一致。
- [ ] 連結驗證通過；移除必要目標的反例仍能被拒絕，不改選擇器或忽略失敗。
- [ ] 附入口檢查與局部驗證的實際證據，文件檢查不冒充遊戲試玩。

### 測試流程
1. 從設計入口開啟小遊戲目錄，核對文件可讀與內容基線。
2. 執行 python tools/verify_design.py --scope links，確認沒有失效目標。
3. 使用隔離副本移除必要目標，確認驗證回報具體失效位置。
