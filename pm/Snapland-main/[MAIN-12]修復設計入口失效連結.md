# [MAIN-12] 修復設計入口失效連結

> 狀態：審查中

## 內文

### 需求
設計入口的三個小遊戲文件連結都指向不存在的目標，導致連結驗證失敗。將入口改為目前存在的小遊戲目錄設計進度票，清楚呈現可閱讀的內容範圍，並保留連結驗證對失效目標的偵測。

### 來源
2026-10-12 本 Session 驗收 ART-17 文件時，執行連結驗證發現此問題；origin/main 與 feature/island-first-park 均沒有該連結目標。使用者要求獨立問題先開票，不刪斷言或跳過失敗。

### 驗收條件
- [x] 設計入口只連到基準版本中存在的小遊戲設計進度文件，不宣稱該文件是完整目錄或可玩內容。
- [x] 連結驗證通過；移除必要目標的反例仍能被拒絕，不改選擇器或忽略失敗。
- [x] 附入口檢查與局部驗證的實際證據，文件檢查不冒充遊戲試玩。

### 測試流程
1. 從設計入口開啟 SG-1 小遊戲目錄設計進度票，核對連結可讀且標示沒有誇大其內容。
2. 執行 python tools/verify_design.py --scope links，確認沒有失效目標。
3. 使用隔離副本移除必要目標，確認驗證回報具體失效位置。
