# [MAIN-34] 修復小視窗規則頁裁切

> 狀態：完成

## 內文

### 需求
小視窗放大文字時，遊戲規則頁的固定橫列操作會把面板撐出畫面，導致右側內容與返回按鈕裁切；較長的目標與操作也需完整可讀。需讓已交付遊戲的規則、說明翻頁、補拍與遊玩／返回操作在三種尺寸均完整可讀可用，保留原有功能與順序。

### 來源
2026-11-18 SG-43 原生 Main 全按鈕邊界檢查，在 800×600、1.25 倍文字的兩個規則頁面各發現三個右側按鈕超出畫面；1280×720 與 1152×648 無此裁切。這是共用規則介面問題，先以既有遊戲重現並獨立修復。

### 驗收條件
- [x] 保存既有遊戲的實際失敗，確認共用排列造成裁切，不以縮小字體或藏掉操作解決。
- [x] 800×600 放大文字、1152×648 與 1280×720 下，規則、補拍、說明翻頁及所有底部操作在視窗內，保持可讀與可點按。
- [x] 原有圖解教學、練習、開始、輔助、普通／小惡魔補拍與返回回呼正確，既有遊戲入口與收藏不受影響。
- [x] 局部版面與既有介面檢查通過，保存獨立存檔的原生截圖及紀錄，逐票提交並同步 main。

### 測試流程
1. 用既有遊戲在 800×600、1.25 倍文字開啟規則，核對未嘗試、已嘗試及已收藏時的按鈕與所有說明頁。
2. 修正後重做三尺寸，逐一操作教學、練習、一般／輔助開始、兩種補拍、返回及說明翻頁。
3. 核對代表遊戲及其餘已交付目錄的局部版面；腳本驗證與原生截圖不當作真人試玩或試聽。
