### 驗收條件
- [x] 預設本機完整驗證仍執行全部檢查；分批方式固定、可重現，所有批次合起來無遺漏、無重複的玩法或功能檢查。
- [x] 每批先確認匯入成功，錯誤、缺少測試、缺少引擎、錯誤完成訊息與不合法批次設定都會明確失敗，不能以空批次冒充通過。
- [x] 雲端在變更與定時執行時驗證完整批次集合；共用素材與來源檢查維持必要且不在每批重複執行。
- [x] 分批失敗可從對應批次找到原因，其他批次仍保留執行結果；原有隔離存檔、精準失敗診斷及完成判定保持有效。
- [x] 真實雲端完整批次、覆蓋核對及本機相容性驗證通過，保存結果與執行時間。

### 測試流程
1. 核對未分批與所有批次的檢查集合，加入缺漏、重複、越界與空集合案例確認會失敗。
2. 執行本機原有選擇性驗證與一個真實批次，確認匯入、隔離存檔及錯誤判定保持原行為。
3. 執行雲端完整驗證，核對每個批次、共用來源檢查與資料檢查的實際結果及時間。
