# [MAIN-30] 穩定地圖選點位置驗證

> 狀態：進行中

## 內文

### 需求
地圖選點應只改變目的地資訊，不移動玩家。持續整合的位置回歸偶發把角色貼地與鏡頭追隨造成的視覺調整誤認成玩家被傳送；驗證需嚴格核對真正玩家位置，同時允許正常的畫面貼地修正，不以放寬距離或停止物理掩蓋真正移動。

### 來源
2026-11-18 main 持續整合第四分片以外的另一項失敗：旅行收藏介面檢查在選地圖目的地時回報角色位移。初步檢查發現該斷言核對受鏡頭調整的視覺角色，玩家本體與畫面位置需要分別觀察。

### 驗收條件
- [ ] 以可重現證據區分玩家位置與正常視覺貼地變化，選點仍只切換地圖資訊，不傳送玩家。
- [ ] 回歸對真正玩家位置維持嚴格不變的斷言，不新增寬鬆容差、不停止物理、不靠固定延遲避開問題。
- [ ] 地圖、收藏與小視窗局部回歸通過，完成訊號與錯誤檢查維持原要求；證據附票並同步 main。

### 測試流程
1. 玩家落地後保留鏡頭追隨，開地圖切換目的地，記錄玩家與視覺角色的位置。
2. 確認視覺貼地可正常更新，但真正玩家位置不變，並重跑地圖、收藏與不同尺寸回歸。
