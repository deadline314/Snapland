# [MAIN-30] 穩定地圖選點位置驗證

> 狀態：完成

## 內文

### 需求
地圖選點應只改變目的地資訊，不移動玩家。持續整合的位置回歸偶發把角色貼地與鏡頭追隨造成的視覺調整誤認成玩家被傳送；驗證需嚴格核對真正玩家位置，同時允許正常的畫面貼地修正，不以放寬距離或停止物理掩蓋真正移動。

### 來源
2026-11-18 main 持續整合第四分片以外的另一項失敗：旅行收藏介面檢查在選地圖目的地時回報角色位移。初步檢查發現該斷言核對受鏡頭調整的視覺角色，玩家本體與畫面位置需要分別觀察。

### 驗收條件
- [x] 以可重現證據區分玩家位置與正常視覺貼地變化，選點仍只切換地圖資訊，不傳送玩家。
- [x] 回歸對真正玩家位置維持嚴格不變的斷言，不新增寬鬆容差、不停止物理、不靠固定延遲避開問題。
- [x] 地圖、收藏與小視窗局部回歸通過，完成訊號與錯誤檢查維持原要求；證據附票並同步 main。

### 測試流程
1. 玩家落地後保留鏡頭追隨，開地圖切換目的地，記錄玩家與視覺角色的位置。
2. 確認視覺貼地可正常更新，但真正玩家位置不變，並重跑地圖、收藏與不同尺寸回歸。

# Commit-1

## 內文

原本的位置斷言核對受鏡頭追隨與貼地校正影響的角色圖像，玩家落地後畫面仍可能微調，造成選地圖目的地被誤判為傳送。現在維持完全相等的判斷，改核對真正的玩家本體，並增加明確標記的合成鏡頭控制測例，確認正常視覺修正與玩家移動可被區分。
