# [MAIN-44] 開放鏡之馬戲團探索

> 狀態：進行中

## 內文

### 需求

達到三十張不同普通拍貼後，玩家能從迎賓大道進入鏡之馬戲團，沿清楚的步行動線探索鏡廊、觀眾席、影子台與砲彈安全墊。影子台提供可反覆試玩的投影預覽，玩家可隨時循步道離開或免費返回迎賓大道。

### 來源

2026-11-26 玩家要求繼續後續章節並打磨地圖、介面、光影及操作。園區設計指定三十張普通拍貼、四個探索區域與可逆投影。

### 驗收條件

- [ ] 29 張普通拍貼時實地入口顯示還差一張，30 張時可入場，拍貼和遊園幣保留。
- [ ] 四個區域有可辨識的景觀和標示，玩家可沿實際步道走進、向後走出並安全回到入口。
- [ ] 影子台可切換投影並回到起始效果，減少動態下也可辨識切換結果，通路與獎勵維持原狀。
- [ ] 地圖依實際朝向與位置描繪可走區域及免費出口，縮小視窗和放大字級時仍能操作。
- [ ] 入場與返回可儲存，舊存檔維持原有內容。旅券與相簿準確顯示目前開放的探索內容。

### 測試流程

1. 以 29 張和 30 張普通拍貼操作迎賓大道的實際入口，核對資格、收藏和遊園幣。
2. 由入口走遍鏡廊、觀眾席、影子台與安全墊，切換且復原投影後走回，檢查視窗縮放和圖面指引。
3. 分別由實地出口、地圖返回迎賓大道，再用同一隔離存檔重新開啟遊戲確認區域及既有資料。
