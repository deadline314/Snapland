# [MAIN-50] 改善迎賓高刷新步行流暢度

> 狀態：完成

## 內文

### 需求

迎賓碼頭起步與走向廣場時，高刷新畫面需要平順呈現鏡頭和角色。保留操作反應、腳步節奏、碰撞、既有投影，以及回到安全位置時的即時畫面。

### 來源

2026-11-26 使用者要求從頭打磨操作手感、動畫與效能。迎賓碼頭固定步行量測中，60 Hz 物理更新搭配每秒 120 與 144 個繪製步，鏡頭分別有 60 與 84 個重複姿態。

### 驗收條件

- [x] 同一段實際步行以每秒 120 與 144 個繪製步比對，重複鏡頭姿態顯著減少，角色與投影同步。
- [x] 一般繪製頻率、減少動態、轉身、慢步煞停、騎乘、暫停、快速復位及跨區維持正確回饋。
- [x] 固定物理步數的行走距離、碰撞、步態與操作反應一致。同機原生量測維持繪製預算。

### 測試流程

1. 從迎賓碼頭以實際方向輸入走向廣場，記錄鏡頭、角色與投影在各繪製步的位置。
2. 切換繪製頻率與減少動態，測試起步、反向、滑行停止、上岸及復位。
3. 測試騎乘、暫停和跨區，並在同機與相同場景條件比較繪製成本。

# Commit-1

## 內文

迎賓碼頭起步往廣場時，高繪製頻率下的鏡頭與主角會平順移動，影子跟著角色。一般繪製頻率和減少動態維持直接呈現。上車、跨區或位置復位時會立即採用正確位置。
