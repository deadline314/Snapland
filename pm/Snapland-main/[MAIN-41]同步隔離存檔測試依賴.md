# [MAIN-41] 同步隔離存檔測試依賴

> 狀態：進行中

## 內文

### 需求

正式存檔模組新增區域造訪資料後，隔離測試的子專案仍能啟動並驗證存檔行為。後續同類資料與腳本變動時，測試可同步取得所需資源，準備失敗時須回報具體原因。

### 來源

2026-11-26 夜市合照交付後檢查，現有子專案缺少區域造訪模組，無法載入正式存檔模組。

### 驗收條件

- [ ] 隔離子專案啟動後，拒絕不安全的存檔路徑，且保留測試專用假存檔及其備份與暫存。
- [ ] 隔離寫入與正常預設路徑流程可分別儲存並重啟讀取。
- [ ] 測試準備失敗時，以非零狀態及明確錯誤結束，局部回歸通過。

### 測試流程

1. 使用獨立測試路徑重現原本啟動失敗，再驗證更新後的同一組測試。
2. 檢查測試涵蓋拒絕路徑、隔離寫入、預設路徑重開及缺少資源。
