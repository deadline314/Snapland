## 內文

### 需求
整合使用者歷次明確需求、品質底線與工作偏好，建立按主題可查閱的使用者指南；另提供下一個 Session 可直接使用的 Prompt，能辨別實際完成、仍待驗收與應避免重做的錯誤。參考圖與實作證據保留來源及用途，不把示意圖或局部驗證當成完整遊戲驗收。

### 來源
2026-10-15（Asia/Taipei）使用者要求整理需求與在意事項到 user guide，必要時附截圖，並準備下一個 Session 使用的 Prompt。沿用既有檔名 `pm/user_guide.md`，不另建拼字不同的重複指南。

### 驗收條件
- [x] 指南按主題整合島嶼體驗、美術、角色動畫、換裝、UIUX、教學、聲音、日夜、收藏與工作規範，無遺漏重要更正。
- [x] 區分使用者固定要求、曾表達喜好的參考、目前採用方案與未完成內容。
- [x] 圖片標明使用者肯定／否定或過去實作證據，沒有把未批准圖片寫成定案。
- [x] 接續 Prompt 包含實際程式所在分支、工作區、已驗證與缺口、先讀文件、下一步、存檔與測試安全規範，可獨立使用。
- [x] 新增／修改文件的本機連結及圖片可解析，文件驗證結果與實際試玩明確分開。

### 測試流程
1. 對照對話中的最新更正與目前票據／證據，逐主題核對指南。
2. 單獨閱讀接續 Prompt，確認能找到實際程式並開始下一項可執行工作。
3. 查看每張參考圖片，核對用途標籤與來源；執行文件連結檢查。
