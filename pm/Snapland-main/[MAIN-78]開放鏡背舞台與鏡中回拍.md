# [MAIN-78] 開放鏡背舞台與鏡中回拍

> 狀態：進行中

## 內文

### 需求
鏡之馬戲團的十二張小惡魔拍貼收齊後，應能進入該區的異空間「鏡背舞台」，和鏡中雜技員雙雙比一場「鏡中回拍」：一場節奏對決，和迎賓的拍照決鬥、碼頭的水道追逐、糖廠的找真身、夜市的潛行都不同。雙雙在鼓聲的前三拍各擺一個姿勢，玩家在下一小節的同三拍用方向鍵擺回同樣的姿勢；三拍全對，鏡框就掉下一片鏡片，六片掉完鏡子碎開、兩人一起謝幕。壓軸不是小遊戲，不計入 128 款，也不發收藏卡。

### 來源
2026-11-29 主持對話交辦下一區（馬戲團）異空間，要求玩法與前四區不同並符合畫面完成度要求；規格見 `design/01-park/other-space.md` 第 5e 節。

### 驗收條件
- [ ] 十二張馬戲團小惡魔拍貼未齊時，入口顯示還差幾張與缺少的設施；收齊後可進入，也可選輔助進入
- [ ] 馬戲團裡有一座「鏡背舞台」主題的入口
- [ ] 每拍有燈號與鼓聲；雙雙每個姿勢前有預備動作，並亮出姿勢牌
- [ ] 方向鍵在拍點上擺姿勢，擺對、擺錯、搶拍或沒擺都有一看就懂的反應
- [ ] 三拍全對掉一片鏡片；三幕依序加入蹲姿與只看剪影的姿勢、最後一幕左右上下反著擺，反轉前有預告
- [ ] 六片掉完鏡子碎開謝幕；時間用完主角被關進鏡子裡，照片收進相簿
- [ ] 謝幕照片收進相簿並給遊園幣；不增加任何收藏分母
- [ ] 雙雙用部件骨架做出等待、預備、擺姿勢、偷笑、驚訝與謝幕的連續動作
- [ ] 模擬輸入可完成；不按任何鍵一定不會完成；減少動態與無畫面環境可執行
- [ ] 舞台有三層景深與環境微動，物件有描邊、明暗與接地影，字幕不切邊
- [ ] 遊戲數量、收藏數量與資料驗證不變

### 測試流程
1. 以測試存檔收齊馬戲團十二張小惡魔拍貼後到鏡背舞台入口
2. 進入鏡中回拍，看雙雙擺三個姿勢，下一小節在同樣的拍點按出同樣的方向
3. 預期六次全對後鏡子碎開謝幕，相簿出現照片；另一輪放著不玩，預期時間到後主角被關進鏡子裡
