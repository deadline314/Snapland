# [MAIN-22] 修復收藏冊條件檢查回歸

> 狀態：進行中

## 內文

### 需求
主線每小時完整測試在氣球快遞更新小惡魔條件後轉紅：收藏冊實際顯示新條件，但檢查仍比對舊文字。檢查要跟著實際資料驗證「上鎖的小惡魔拍貼說明真正條件」，不因條件文案改寫再次誤報，也不放寬原本要證明的行為。

開發者在本機逐項排查時，完整套件遇到第一個失敗就停止，較慢的機器也可能在大型渲染檢查上逾時，無法一次看到全部結果。需要能只跑受影響項目、一次列出所有失敗，並在較慢機器上延長（不可縮短）時限；CI 的預設行為不變。

### 來源
2026-10-23（Asia/Taipei）使用者要求接續完成所有未結案票。開工核對最新主線實際 CI（排程第 392～394 次）時發現收藏冊檢查失敗。

### 驗收條件
- [ ] 收藏冊檢查從實際遊戲資料取得小惡魔條件並確認卡片顯示；改用舊文字時仍能被抓到。
- [ ] 本機可只跑指定項目、一次列出全部失敗，並以不小於 1 的倍率延長時限；不帶參數時與 CI 原行為一致，有對應測試。
- [ ] 收藏冊局部檢查與 Python 測試通過，主線完整 CI 恢復綠燈。

### 測試流程
1. 執行收藏冊局部檢查，確認惡魔分頁的條件說明檢查通過，無引擎錯誤。
2. 執行執行器的 Python 測試，確認預設遇錯即停、可選擇一次列出全部失敗、只跑指定項目，以及拒絕縮短時限。
3. 推送後查看實際 CI 結果。
