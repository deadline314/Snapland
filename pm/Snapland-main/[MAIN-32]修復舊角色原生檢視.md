# [MAIN-32] 修復舊角色原生檢視

> 狀態：進行中

## 內文

### 需求
舊角色原生檢視仍要求過時的出生位置、固定四格來源及僅一位角色巡路，與現行三位角色正式動畫及接地巡路不符，會在完整流程之前失敗。需要依目前正式世界驗證角色身份、動作來源、材質同步、可見性、路線與互動點及降低動態，保留原本驗證目的與如實失敗機制。

### 來源
2026-11-18 延續 ART-17 降低動態站姿修正時，核對既有檢視入口發現舊位置及四格來源假設已過時；相關站姿斷言已由 ART-17 同步，完整入口需另行修復。

### 驗收條件
- [ ] 先保存舊入口與現行世界不符的實際失敗，區分既有失效與本輪變更。
- [ ] 三位角色均以現行正式來源完成原生呈現、身份與可見性驗證；來源、材質與服裝同步，移動與互動位置符合各自現行路線。
- [ ] 降低動態、恢復與乾淨退出可完成完整入口，不刪除必要檢查、不假造完成或忽略引擎錯誤。
- [ ] 保存隔離存檔的原生畫面及局部驗證，逐票提交並同步 main。

### 測試流程
1. 使用獨立存檔執行舊角色原生檢視，保存第一個實際失敗與對應世界狀態。
2. 修正驗證假設後完整執行三位角色檢視，核對正式動作、位置、互動點、降低動態、恢復及退出。
3. 保存實際截圖及執行紀錄；不把腳本取景或來源檢查描述成真人遊玩或整套藝術驗收。
