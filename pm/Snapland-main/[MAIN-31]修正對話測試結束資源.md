# [MAIN-31] 修正對話測試結束資源

> 狀態：進行中

## 內文

### 需求
角色對話的保持與釋放回歸在結束程序時，持續整合回報仍有資源使用中。需要找出真正被保留的資源與生命週期原因，讓測試完成對話功能驗證後正確釋放再退出；不可忽略錯誤、偽造通過或用無條件等待掩蓋問題。

### 來源
2026-11-18 main 持續整合角色對話回歸結束時，回報三份資源仍在使用。此項在先前執行曾通過，須保留原功能斷言並查明不穩定條件。

### 驗收條件
- [ ] 以實際診斷辨識退出時保留的資源及原因，與對話中的正常保持、結束、取消與離場區分。
- [ ] 受影響生命週期能有界地完成釋放，逾限仍如實失敗，不放寬原功能斷言或引擎錯誤檢查。
- [ ] 受影響局部回歸及退出檢查通過，保留重現與修正證據，逐票提交並同步 main。

### 測試流程
1. 使用獨立存檔執行對話保持／離開／取消回歸，收集退出時資源診斷與對照。
2. 核對修正後對話原行為、正常清理與逾限失敗皆符合預期，退出不殘留資源。
