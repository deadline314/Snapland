# [MAIN-28] 修正補拍回歸退出資源保留

> 狀態：完成

## 內文

### 需求
補拍完整回歸雖通過操作與保存斷言，部分正常退出仍報告五個資源、十個物件保留。找出實際保留來源並修正生命週期，讓無詳細日誌的一般驗證也能穩定乾淨退出，保留全部補拍、保存失敗及原圖保護驗證。

### 來源
2026-11-17 MAIN-26 局部回歸發現。以舊主分支 5655318 的正式內容，在同一隔離專案、相同補拍流程與一般執行參數重現同樣退出訊息，確認原有問題；詳細日誌模式常無法重現。

### 驗收條件
- [x] 有可重現的實際資源來源與生命週期證據，修正後一般與詳細日誌執行均正常退出，不保留該批資源或物件。
- [x] 原有補拍、正常參與、練習／取消、保存失敗、原圖保護與獎勵去重斷言完整保留，結果正確。
- [x] 不略過退出檢查、不隱藏引擎錯誤、不以增加任意等待掩蓋原因；受影響局部回歸及隔離保存證據附票。

### 測試流程
1. 重做一般參數的補拍完整流程，記錄成功斷言與退出時保留的實際資源；對照詳細日誌及舊主分支。
2. 修正後以兩種模式及不同隔離存檔連續執行，確認操作、保存與資源釋放皆正確。
