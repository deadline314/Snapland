# [MAIN-47] 減少角色投影重複更新

> 狀態：進行中

## 內文

### 需求

迎賓大道靜止角色的陰影會重複送出相同畫面資料。讓穩定畫面少做重複更新，保留走動、換裝、乘坐遊具、合照及日夜切換時的即時投影。

### 來源

2026-11-26 使用者要求從頭打磨光源、動畫、動態與效能。原生引擎對照已量到靜止場景的重複寫入。

### 驗收條件

- [ ] 迎賓大道四個靜止角色在固定物理與繪製步數中，陰影重複寫入明顯減少，報告可重現的前後計數。
- [ ] 行走、乘坐、拍照、即時姿勢與日夜轉換保有相同畫面結果。
- [ ] 減少動態、投影降級、不可見角色及跨區重開各走原本的有效分支，沒有殘影或漏更新。

### 測試流程

1. 用同一引擎、同一場景靜止兩次，固定每秒繪製和物理步數，量出陰影更新。
2. 同樣操作步行、乘坐、入鏡與黃昏切換，核對輪廓與投影支撐點。
3. 分別檢查不可見角色、降級方式與減少動態，必要時以同一視點比對畫面。
