# [MAIN-38] 統一舊小遊戲的失焦暫停與重新操作

> 狀態：完成

## 內文

### 需求

切換視窗時，舊小遊戲也能停表並清除當下按住的控制。回到遊戲後可從原有暫停選單繼續，下一次操作從玩家新輸入開始。

### 來源

2026-11-26，使用者要求逐項改善已開放章節的操作體驗。小遊戲規格支援暫停，較晚交付的遊戲已在離開視窗時暫停。

### 驗收條件

- [x] 舊小遊戲進行中離開視窗，顯示暫停選單；再次取得焦點後等待玩家繼續。
- [x] 失焦期間計時、進度與分數保持。失焦前的按住或拖曳不會殘留，也不會觸發一次性操作。
- [x] 繼續後能立即用既有快捷鍵、指標或觸控操作。備用輸入方式與其他遊戲維持既有行為。
- [x] 隔離局部回歸與原生操作驗證通過，PM 留必要摘要與代表截圖。

### 測試流程

1. 進入迎賓大道舊小遊戲，按住移動、蓄力或拖曳時切換到另一個視窗。
2. 在外部釋放輸入，回到遊戲，確認計時與狀態保持並可看見繼續選項。
3. 繼續後確認舊輸入沒有觸發，再給新輸入並驗證鍵鼠與觸控的對應動作。
