# [MAIN-1] 重整園區與收藏玩法

> 狀態：完成

## 內文

### 需求
以操作掌握、風險取捨、觀察預測、創意解法、協調救場與節奏喜劇重整遊園流程。玩家可選擇不同活動開區，使用簡單 AI 與輔助仍能取得完整收藏。

### 來源
使用者於 2026-10-06 在 Snapland 設計對話要求重新思考園區玩法、先開票後工作並逐票 commit 與 push；已確認終區僅要求普通拍貼全收齊。

### 驗收條件
- [x] 十個普通園區的主題、動線、活動循環與異空間入口清楚可查。
- [x] 普通收藏來源、開區門檻、終區條件與替代取得途徑一致且沒有循環鎖死。
- [x] 單人、同機與 P2P 的座位、收藏歸屬、AI 等級及中斷處理有明確要求。
- [x] Steam 物品相容格式與離線收藏、交易物品的界線清楚可查。
- [x] 有可重現的設計檢查結果與文件截圖。

### 測試流程
1. 逐區比對普通拍貼來源與開區條件，推演只探索、混合遊玩及輔助取得的路線。
2. 比對多人與 AI 情境，確認無真人或高難限定收藏。
3. 檢查資料及文件連結，檢視交付文件截圖；預期沒有矛盾或遺漏。

園區、拍貼與多人規則原本散在對話，無法核對來源與解鎖是否一致。
現在十區動線、六種樂趣、180普通收藏、120惡魔收藏、單人輔助及多人進度有一致的可查規格，物品從離線收藏階段採用Steam相容固定定義。
驗收了門檻可達、普通結局與全集終區分離、AI與輔助收藏平等、物品ID與來源覆蓋；人工核對多人成績與收藏歸屬。這是文件交付，遊戲試玩另行驗收。
