# [MAIN-75] 修正高RTL文字下暫停選單超出畫面

> 狀態：待辦

## 內文

### 需求

以高字形、由右至左的測試語系開啟暫停選單時，繼續、設定、離開按鈕在 1280×720 與 800×450 下有部分超出畫面；另外設定頁的字體選項在測試語系缺少兩個翻譯。

### 來源

### 驗收條件

- [ ] 高字形 RTL 語系下，暫停選單所有按鈕在 1280×720 與 800×450 完整顯示在畫面內。
- [ ] 字體設定的兩個選項在每個語系都有翻譯，不再出現缺字警告。
- [ ] 一般語系的暫停選單版面與動畫不變。

### 測試流程

1. 本機只跑「localization framework tests」一次，輸出寫進紀錄檔。
2. 推上 main 後看 CI 摘要頁，該套件為通過。
