# [MAIN-36] 精簡超大票的附件

> 狀態：進行中

## 內文

### 需求

pm 資料夾已累積約 5.3GB 附件，拉取與切換分支都變慢。附件超過 100MB 的票需要精簡，保留每張票的重點畫面、影片與文字證據，移除沒有被任何文件引用的重複截圖，以及證據壓縮檔內的逐格原始畫面。

### 來源

2026-11-22 使用者對話：pm 占用太大空間，要求檢查超過 100MB 的票並精簡附件，保持每張票的重點與應看到的內容。

### 驗收條件

- [ ] 列出附件超過 100MB 的票及精簡前後大小。
- [ ] 票內與設計文件引用的影片、截圖、報告連結全部仍可開啟。
- [ ] 證據壓縮檔保留日誌、報告、測試與來源文字，逐格原始畫面與重複錄影移除。
- [ ] 沒有被任何文件、程式或測試引用的散落截圖與日誌移除。
- [ ] 連結驗證與資料驗證通過。

### 測試流程

1. 統計各票附件大小，比對精簡前後。
2. 執行連結驗證，確認票內引用的附件都存在。
3. 抽查壓縮檔內容，確認文字證據仍在。
