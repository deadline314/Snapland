# [ST-8] 修正夜市劇情測試音訊收尾

> 狀態：進行中

## 內文

### 需求

以固定步長執行霓虹夜市劇情驗證時，須確認停止的環境音與背景音樂資源已釋放，再離開測試。資源未能在時限內釋放時，測試須明確回報失敗。

### 來源

2026-11-26 Linux CI 的夜市劇情驗證曾在結束時回報三個音訊資源仍使用中。以相同版本與固定步長在隔離 Linux 專案重現。

### 驗收條件

- [ ] Linux 的固定步長夜市劇情測試正常結束，背景音樂和環境音的播放資源均已釋放。
- [ ] 刻意保留播放資源時，驗證會在預定時限回報失敗。
- [ ] 夜市入口、劇情略過、實景取景、拍貼保存及相簿重播的既有驗證通過。

### 測試流程

1. 在獨立 Linux 存檔路徑重現原錯誤，再以相同方式執行更新後的驗證。
2. 保留一個播放資源，以現有回歸測試確認會有限時錯誤並可釋放回復。
