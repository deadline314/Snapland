# [ST-8] 修正夜市劇情測試音訊收尾

> 狀態：完成

## 內文

### 需求

以固定步長執行霓虹夜市劇情驗證時，須確認停止的環境音與背景音樂資源已釋放，再離開測試。資源未能在時限內釋放時，測試須明確回報失敗。

### 來源

2026-11-26 Linux CI 的夜市劇情驗證曾在結束時回報三個音訊資源仍使用中。以相同版本與固定步長在隔離 Linux 專案重現。

### 驗收條件

- [x] Linux 的固定步長夜市劇情測試正常結束，背景音樂和環境音的播放資源均已釋放。
- [x] 刻意保留播放資源時，驗證會在預定時限回報失敗。
- [x] 夜市入口、劇情略過、實景取景、拍貼保存及相簿重播的既有驗證通過。

### 測試流程

1. 在獨立 Linux 存檔路徑重現原錯誤，再以相同方式執行更新後的驗證。
2. 保留一個播放資源，以現有回歸測試確認會有限時錯誤並可釋放回復。

# Commit-1

## 內文

夜市劇情測試會等停止的音訊播放資源釋放，再結束引擎。固定步長不再提前結束音訊收尾，若超時仍會回報失敗。

| 項目 | 結果 |
|---|---|
| 原本的 Linux 固定步長 | 8 次中有 4 次重現背景樂與環境音的三個資源仍使用中 |
| 修正後的 Linux | 固定步長 8 次與增加音訊延遲 3 次均通過，沒有資源錯誤 |
| 播放資源與 Windows 回歸 | Linux 與 Windows 均驗證刻意持有播放資源會限時失敗，放開後可回復。Windows 的夜市劇情驗證也通過 |
