# [ART-2] 建立遊園介面與操作引導

> 狀態：完成

## 內文

### 需求

用清楚的繁中介面引導探索、任務、對話、遊戲、收藏與設定。

### 來源

使用者於 2026-10-11（Asia/Taipei）要求從上島開始實作主區域、迎賓大道全部小遊戲及共用系統；其他園區先做路口。每項實作前研究業界實例並保存圖例；本票是可執行第一版，品質以實際驗收為準。

### 驗收條件

- [x] 介面可用鍵盤與滑鼠操作，互動提示清楚且沒有文字截斷。
- [x] 對話、暫停、結算與設定有明確返回方式；遊戲期間不穿透操作。
- [x] 實作前提供 UIUX 參考圖與實際採用理由。

### 測試流程

1. 啟動遊戲，進入本票內容，依畫面提示實際操作。
2. 核對本票每項驗收條件，測試返回、重試、重開與輔助情境。
3. 保存原生畫面截圖與局部測試摘要；無法確認的項目保持未勾選。

# 2026-10-20 現行介面結案

已由ART-23～26的當前旅券、分類收藏、換裝／設定與小遊戲HUD取代舊版基礎UI。這一輪99張原生圖已逐頁看過，實際Escape／Tab與滑鼠事件核對焦點、返回、確認及互動隔離；14項UI／核心／故事回歸通過。圖中照片與練習結算是合成資料，未當自然通關。

本輪三尺寸為800×450、1280×720及1920×1080，文字1.25倍；最大尺寸核對實際夜間與降低動態。要求值、Window、後端、viewport縮放與PNG尺寸一致；只改後端而Window未變的反例已拒絕。舊Windows／800×600圖保留為歷史，不能冒稱本輪驗過。現行paper與wardrobe來源最新提交82a6f38已在main；不將無法解析的舊feature連結當合入證明。
