# [ART-8] 提供服飾店與衣櫃預覽

> 狀態：進行中

## 內文

### 需求
玩家遊園時可打開服飾店與衣櫃，分辨免費基礎外觀、已收藏穿搭及可購買商品。試穿先看結果，再決定購買與穿戴；提供清楚餘額與短提示。

### 來源
2026-10-11 使用者要求購買並自訂服飾、帽子。Disney Dreamlight Valley 2024-08-21 官方衣櫃更新提供分類與整套穿搭預設；本作採海港裁縫店與試衣鏡的原創呈現。

### 驗收條件
- [x] 遊園介面有衣櫃入口，滑鼠和鍵盤可操作並正常返回。
- [x] 預覽可看衣服與帽子，試穿不先扣款或自動保存。
- [x] 免費外觀和購買價格清楚，已擁有及餘額不足有正確狀態。
- [x] 穿戴後島上外觀同步，關閉或取消試穿保留原有穿搭。
- [x] 800×600 與 1280×720 核對尺寸下衣櫃／設定控制項有界且回應原生鍵鼠輸入，原生截圖完成。

### 測試流程
1. 開衣櫃切換免費外觀與商品，觀察預覽與價格。
2. 取消、購買、穿戴與關閉，各自核對島上角色和餘額。
3. 重啟後檢查穿搭保留，縮放視窗檢查操作。
