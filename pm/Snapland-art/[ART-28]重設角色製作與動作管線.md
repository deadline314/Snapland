# [ART-28] 重設角色製作與動作管線

> 狀態：完成

## 內文

### 需求
部件與人物動作有一致、可反覆修訂的製作方式，能解釋頭髮、身體、服飾和道具如何一起運動。先比較成熟作品與工具的實際方法，再提出涵蓋生成、綁定、換裝、走路及人物行為的完整設計。

### 來源
2026-10-15 使用者指出部件綁定與生成方法存在很多問題，要求先上網研究業界做法，再重新設計整套角色與動作處理。

### 驗收條件
- [x] 至少六方一手來源有可核對連結、實際閱讀與圖像檢視狀態，以及採用理由。
- [x] 比較不同製作方案的成本、像素畫風、八方向與換裝限制，提出推薦方向。
- [x] 設計說明部件原件、人物一致性、遮擋、走路、互動和人物行為如何協作。
- [x] 列出轉換順序與可觀察的驗收門檻，明確區分提案、候選素材與已批准成果。

### 測試流程
1. 對照來源頁面與研究紀錄，核對實際閱讀、參考圖和推論範圍。
2. 以換髮、穿帽、長外套、雙手持相機及走路起停轉向逐項檢查設計。
3. 核對移行與驗收條件，確認文件檢查沒有被描述成遊戲試玩。

設計見[角色製作、換裝與行為管線重設](../../design/runtime/character-production-pipeline-v2.md)。

# Commit-1

## 內文

人物部件的生成、綁定與行走方式缺少一致的製作前提，局部修補容易牽動臉、頭髮、服裝和道具。

交付八方一手方法核對、三條路線比較，以及涵蓋人物原件、部件、遮擋、換裝、走路、互動和 NPC 行為的完整設計提案。建議優先評估共用製作骨架、離線輸出像素畫姿，並以一位角色的小型樣本作為採用門檻。

已逐項檢查換髮、戴帽、長外套、雙手持相機、起停轉向、暫停與缺素材情境；研究事實、提案推論和實際製作成果有分開標示。此次驗收是研究與設計審閱，不是遊戲試玩。

### 測試結果

| 項目 | 結果 |
|---|---|
| 一手來源與方案核對 | 八方，含閱讀及圖像檢視範圍 |
| 參考截圖 | 三張靜態檢視，圖檔可讀與雜湊已記錄 |
| 設計連結與交付差異檢查 | 通過 |
| 全域設計檢查 | 園區通過後因既有小遊戲目錄缺檔中止 |
| 設計一致性審閱 | 已收窄可選 NPC 巡路敘述，並釐清程式與研究提交基準 |
