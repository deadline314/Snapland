# [ART-21] 重整小遊戲操作畫面

> 狀態：完成

開始基準：`64fcf8cbd313ba350c7165a2e4ec914398a8f943`；分支：`feature/island-first-park`。

## 內文

### 需求
重設十二款小遊戲的遊玩和結算畫面。背景、操作主體、當前目標、成績和時間有明確主次；從玩法需要選擇資訊，不用大量長句提示和厚重橫條覆蓋場景。

2026-10-12 使用者追加建議 UI 採 3D 或偽 3D。操作資訊與結算可用材質厚度、投影及凸起控制建立深度；效果不遮擋玩法、不晃動關鍵數字，降低動態時仍清楚。

2026-10-12 使用者追加：同一園區維持共同主題，每款小遊戲須依玩法選擇自己的 2D、2.5D、HD-2D 或 3D 表現。不能沿用同一場地、構圖與動畫再換規則；鏡頭、空間、操作節奏和成功演出須帶來可辨認的新體驗。

### 來源
2026-10-12（Asia/Taipei）使用者要求全面重新審閱 UI 和小遊戲，提升目標、計分及操作手感；先廣泛 survey，減少遊戲當下提示，提供含截圖的完整教學。使用者授權自行決定設計，強調循序完善、細節有主次且不雜亂，以可面向大眾的品質驗收。

### 驗收條件
- [x] 十二款玩法有各自的鏡頭、空間、媒材與演出設計；比較總覽不能呈現同一背景和構圖的十二種換皮。
- [x] 參考至少六個不同來源的遊戲畫面與計分回饋，保存實際閱讀與圖例並形成自己的設計。
- [x] 十二款操作畫面有清楚主體與必要的當前目標、時間和成績，裝飾與文字不干擾操作區。
- [x] 命中、失誤、連續成功及結算可看懂，分數與成就條件不互相矛盾；支持重試、退出及教學入口。
- [x] 十二款原生鍵鼠畫面、不同時段及降低動態實際檢視通過，保存前後截圖及影片。

### 參考資料與實際觀察

介面調查見[十項來源研究紀錄](../../design/runtime/ui-quality-survey.md)，玩法、操作與計分的一手文字來源見[首區玩法比較](../../design/runtime/first-park-gameplay-quality.md)。本次另實際查看六張經核准的遊戲畫面，逐一閱讀官方來源文字；鏡頭、物件與資訊位置的觀察、採用／不採用原則及仍看不到的內容都記在[小遊戲視覺多樣性檢視](../../design/runtime/minigame-visual-diversity-review.md)。

# Commit-1

## 問題
操作畫面把規則長句、成績與玩法提示混在一起；結算未能解釋得分來源，短回合的收藏縮圖也可能拍到結算畫面。

## 改動
整理小遊戲的目標、進度、計時與得分；暫停後可查看明細、重試或切換練習，離開前確認。結算列出實際得分來源，練習不寫入收藏；拍貼保存遊玩畫面。噴泉跳拍同步改成三個可辨認評級，最後一次落地完成後再結算，相關完整玩法驗收追蹤 SG-18。

## 驗收
共享操作與計分檢查 52 項通過。以獨立存檔及實際鍵鼠完成噴泉標準、失誤、輔助及 900 分回合，原生影片與拍貼證據追蹤 SG-18。其餘十一款的獨立場景、美術、手感與成功演出仍須逐款驗收，未將共用介面檢查視為十二款精品完成。

### 測試結果
- 共用回合與計分：52 項通過，0 腳本或引擎錯誤。
- 獨立候選版本的主流程通過；實際按下教學／返回，確認暫停與恢復不重置本局。
- 獨立候選版本原生噴泉鍵鼠完成兩中一失誤及三次完美 900 分；實際打開相簿與成就核對收藏。影片與動作專項證據追蹤 SG-18。
- 原生檢視發現首次教學提示壓住標題，已移到操作區上緣並限制文字寬度；其餘場景仍逐款驗收。
- 跨票改動：短回合的拍贴截取與結算接入；噴泉評級及動作時機是共用回合的一部分，SG-18 留存專項測試與影片。
- [多元玩法與表現研究](../../design/runtime/minigame-diversity-survey.md)：九個一手來源，明確區分文字閱讀與未看過的影片。
- 分支：`feature/island-first-park`；[遠端提交 9645e6b](https://github.com/deadline314/Snapland/commit/9645e6b)。

# Commit-4

## 問題

遊戲畫面上方的共用資訊區曾以長句和大面板遮住玩法；縮小視窗後，操作按鈕也可能太小，切回標準視窗時面板高度偶爾沒有恢復。鍵盤焦點下的主要按鈕文字亦不夠清楚。

## 改動

把目標長文移到標題提示與既有教學入口，遊玩時只保留標題、進度、分數、時間和必要操作。面板改為左右角落的紙質小卡，中央留給玩法畫面；縮放後重新調整尺寸，讓操作按鈕仍易於點選，焦點文字保持清楚。分數明細、暫停、教學、練習和結算入口沿用既有流程。

## 驗收

HUD 專項檢查 69 項通過，Main 整合檢查通過。隔離存檔的原生視窗流程完成 57 張畫面、零引擎或腳本錯誤：經 Main 實際路徑開啟十二款回合介面並操作暫停／恢復、明細、教學及離開確認；005、010、012 另於 800×600 操作後切回 1280×720，再檢查暫停畫面。遊戲 006 的表演者缺漏另屬該遊戲內容問題，不在本次 HUD 範圍內。切回後三款面板均恢復為 84 像素高，按鈕符合至少 44 個實體像素的目標。此流程沒有進行遊戲回合或測試結果；它驗收的是共用介面，不代表十二款玩法與美術已全部完成。

# Commit-5

## 問題

後續 renderer 已改變部分遊戲的實際媒材，但票內舊比較圖與視覺摘要仍使用較早的分類；「3D renderer」也容易被誤讀為自由 3D 操作或已完成原生驗收。

## 改動

新增依 HEAD 程式與目錄核對的十二款現況文件，並更新視覺回顧中的媒材摘要：目前五款 renderer 使用 3D 場景（001、003、004、008、009），同時區分固定投影、2D Sprite3D 主角與模型驅動場景物件。舊十二款靜格與媒材清單仍保留為歷史基線；玩家指南新增兩句概括各款操作動詞和目前媒材。帽子救援的近／中／遠接物帶仍是待評估提案，沒有記成已實作。

## 驗收

本次僅核對靜態 HEAD 程式、資料目錄及文件連結，沒有執行遊戲、GPU 擷取、十二款原生操作或畫質驗收。主 Session 另實際讀取 Nintendo、Playdate、Obra Dinn、Thumper、Donut County 與 Lumines 的六個官方頁面，核對不同操作、鏡頭及資訊節奏；沒有把頁面文字當成遊玩體驗或影片觀察。本次未新增來源圖片。所有玩法、介面和原生畫面驗收勾選狀態維持原樣。

# Commit-6

## 問題

既有共用介面驗收、逐款遊玩影片和後續美術交付分散，缺少現行十二款在四時段及降低動態下的同版比較。

## 改動

完成現行十二款的整體操作畫面驗收。各款分別使用海港投送、海岸風箏、噴泉節拍、路口指揮、碼頭接帽、雙人舞台、水路工作板、立體招牌、影戲投影、攝影取景、候客室排座及樂器記憶；不共用一套場地構圖。共用角落資訊保留目標、進度、分數、時間與暫停入口，把中心留給操作主體；完整規則由可重看的教學承接。

## 驗收

本輪實際經 Main 開啟十二款，逐款用時段面板切換凌晨、中午、傍晚、晚上，再用真正設定開啟降低動態，完成 60 張原生畫面與 12 張對照圖的視覺檢查。主體、目標及必要操作可辨，未見資訊遮住操作區。時段面板內計時、成績和失誤保持不變，返回接續同一局；逐款經暫停及確認離開，收藏與任務等保護資料不變。

完整鍵鼠回合、命中／失誤、普通／精準資格、私人練習、重試和結果頁已由同輪 [SG-14](../Snapland-small-game/[SG-14]完善十二款遊戲動作回饋.md) 與各 SG-16～27 原生專項交付，現行畫面與兩項最後修整見 [ART-5](./[ART-5]重製十二款小遊戲美術.md)。本次沒有變更玩法與玩家素材；以既有完整回合及本輪時段矩陣合併核對原條件，不將 60 張靜格當成 60 次通關。
