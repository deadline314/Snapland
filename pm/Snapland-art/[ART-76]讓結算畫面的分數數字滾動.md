# [ART-76] 讓結算畫面的分數數字滾動

> 狀態：完成

## 內文

### 需求

小遊戲結束後的結算頁，街機遊戲的總分用內文字、一般小遊戲的成績混在一行說明裡直接出現，拿到分數的那一刻沒有感覺。要讓結算頁的分數使用 ART-64 的圓胖數字並從零滾到最終分數，獎牌名稱用標題字。

### 來源

2026-11-28 字體與文字演出後續（ART-64 收尾盤點）；協作 session 指派。

### 驗收條件

- [x] 街機結算頁的總分使用圓胖數字並從零滾動到最終分數，獎牌名稱使用標題字。
- [x] 一般小遊戲結算頁的本次成績行出現時彈跳強調，文字從第一格就是完整紀錄，練習與輔助的說明保留。
- [x] 減少動態或無畫面時直接顯示最終分數，讀取分數的測試不受影響。

### 測試流程

1. 玩一款街機小遊戲與一款一般小遊戲到結算。
2. 看分數從零滾到最終分數。
3. 開啟減少動態再看一次。
