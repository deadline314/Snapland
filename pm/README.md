## 本輪需求
- MAIN-1：重整園區與收藏玩法。
- SG-1：重設小遊戲樂趣目錄。
- ST-1：重整主線與園區支線。
- MAIN-2：建立設計驗證與定時CI。

設計內容由 [設計入口](../design/README.md) 閱讀；完成票只代表其驗收範圍完成，不代表遊戲已實作。
